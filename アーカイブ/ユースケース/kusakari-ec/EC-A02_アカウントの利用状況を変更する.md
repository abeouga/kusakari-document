#### EC-A02 アカウントの利用状況を変更する

| 記述項目 | 記述内容 |
| --- | --- |
| ユースケース概要 | アカウントを利用停止または利用再開する。 |
| アクター | 運営者 |
| 事前条件 | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。<br>対象のアカウントが登録されている。 |
| 事後条件 | 対象アカウントの利用状態が変更され、利用停止または利用可能として表示されている。 |
| 基本フロー | 1. 運営者が運営者画面のメニュー「会員管理」を開く(画面ID: EC-C02)。<br>2. システムが「会員管理」画面に会員の一覧と利用状態を表示する。<br>3. 運営者が対象アカウントの「利用を停止」または「利用を再開」ボタンをクリックする(現在の利用状態に応じて、どちらか一方のみ表示される)。<br>4. システムが対象アカウントと変更内容を示した「利用状況変更の確認」ダイアログを表示する。<br>5. 運営者が「利用停止を確定」または「利用再開を確定」ボタンをクリックする。<br>6. システムがアカウント状態を更新し、「利用を停止しました。」または「利用を再開しました。」と更新後の利用状態を表示する。 |
| 代替フロー | 5a. 確定を取り消した場合<br>5a-1. 運営者が「利用状況変更の確認」ダイアログの「取消」ボタンをクリックする。<br>5a-2. システムがダイアログを閉じ、アカウント状態を変更せず「会員管理」画面を表示する。<br>5a-3. ユースケースを終了する。<br><br>6a. 対象が運営者アカウントまたは退会済みのアカウントの場合<br>6a-1. システムが「管理者または退会済み会員の状態は変更できません。」を表示し、アカウント状態を変更しない。<br>6a-2. ユースケースを終了する。 |
| 関連情報 | ・共通代替フロー \*b を適用する。<br>・利用停止中のアカウントはログインできない(EC-B01)。<br>・店舗側のアカウント(オーナー・担当者)を利用停止しても、店舗と商品の公開状態は変わらない。店舗を止める場合は「店舗管理」(EC-A11)、組織ごと止める場合は「組織管理」で行う。<br>・すでに確定した注文はキャンセルせず、そのまま受け渡しを続ける。<br>・利用停止中はログインできず通知を確認できないため、対象者への通知は送らない。 |
