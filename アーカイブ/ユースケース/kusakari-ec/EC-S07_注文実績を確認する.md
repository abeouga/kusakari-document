#### EC-S07 注文実績を確認する

| 記述項目     | 記述内容                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 店舗の注文件数・キャンセル件数と、注文金額・販売手数料・差引額の合計、注文ごとの手数料を確認する。 |
| アクター     | 出店者(オーナー、MANAGER(店長)、STAFF)                                                                                                                                       |
| 事前条件     | 出店者のアカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 「注文実績」画面に選んだ店舗の注文実績が表示されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「注文実績」を開く(EC-C03)。<br>2. システムが選択中の店舗の注文実績を取得する。<br>3. システムが「注文実績」画面に、店舗名、件数(「注文数」「支払い待ち」「キャンセル」「キャンセル申請中」)、合計(「注文金額」「販売手数料」「差引額」)、販売手数料の計算方法の説明、注文ごとの一覧(注文番号、注文日時、状態、支払方法、注文金額、手数料率、販売手数料、差引額)を表示する。<br>4. 出店者が注文実績を確認する。 |
| 代替フロー    | 1a. 複数の店舗を扱う場合<br>1a-1. 出店者が画面上部の選択欄で、確認する店舗を選択する(EC-C03)。<br>1a-2. 基本フロー2へ進む。<br><br>2a. 閉鎖済みの店舗の注文実績を確認する場合(オーナー・ORG_ADMIN)<br>2a-1. 出店者が「表示する店舗」の一覧の「閉鎖した店舗」から店舗を選択する。<br>2a-2. システムがその店舗の注文実績を、店舗名の横の「閉鎖済み」と、「(日時)に閉鎖した店舗です。注文実績は読み取り専用で、期限なく確認できます。」とともに表示する。<br>2a-3. 基本フロー4へ進む。<br><br>2b. 選択中の店舗の注文実績を見る権限がない場合(ロールのない店舗など)<br>2b-1. システムが「選択中の店舗の注文実績を見る権限がありません。」と表示する。閉鎖した店舗を選べる場合は「閉鎖した店舗は上の欄から選べます。」も表示する。<br>2b-2. ユースケースを終了する。<br><br>3a. 注文がない場合<br>3a-1. システムが件数と合計を0で表示し、注文の一覧の代わりに「この店舗の注文はまだありません。」と表示する。<br>3a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・販売手数料は、注文したときの率(現在は全店舗一律8%)で注文ごとに計算し、1円未満を切り捨てた額である。率を変えても、過去の注文は注文したときの率と額のまま表示する。<br>・販売手数料は表示するだけで、請求・精算は行わない。差引額は注文金額から販売手数料を引いた額である。<br>・キャンセルの注文は「手数料なし」と表示し、合計に含めない。支払い待ちの注文も、支払われるまで合計に含めない。<br>・この画面は読み取りだけで、注文を変える操作はない。<br>・見られる店舗は次のとおり。営業中・閉鎖中の店舗はオーナー・MANAGER・STAFF(ORG_ADMINは店舗のロールがある場合だけ)、閉鎖済みの店舗はオーナーとORG_ADMINが見られる。閉鎖済みの店舗は担当者が外れるため、MANAGER・STAFFは見られない。<br>・運営者は「店舗管理」画面から各店舗の注文実績を見られる(EC-A05)。 |
