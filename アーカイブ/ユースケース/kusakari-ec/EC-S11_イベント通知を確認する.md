#### EC-S11 通知一覧を確認する

| 記述項目     | 記述内容                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者向けのイベント通知一覧を確認する。 |
| アクター     | 出店者                                                                                                                                                                             |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 通知が画面上に表示されている。                                                                                                                                                                 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「出店者通知」を開く(EC-C03)。<br>2. システムが「出店者通知」画面に、担当する店舗に関する通知ごとのタイトル、本文、日時と既読状態を表示する。<br>3. 出店者が通知内容を確認する。<br>4. 出店者が必要に応じて対象通知の「既読にする」ボタンをクリックする。<br>5. システムが通知を既読にし、「既読」と表示する。 |
| 代替フロー    | 2a. 通知がない場合<br>2a-1. システムが通知なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・通知される主な出来事は次のとおり。<br>　- 注文：「新しい注文が届きました」(カードの注文は支払いが確認できた時点)、「キャンセル申請が届きました」。対応は「店舗受け取り」画面(EC-S08、EC-S13)で行う。<br>　- 運営者による商品への操作(EC-A10)：「商品に運営から警告がありました」「商品への運営の警告が解除されました」「商品の公開を停止しました」「商品の公開停止を解除しました」。商品名と理由を含む。<br>　- 運営者による店舗への操作(EC-A11)：「店舗に運営から警告がありました」「店舗への運営の警告が解除されました」「店舗の利用が停止されました」「店舗の利用停止が解除されました」。店舗名と理由を含む。<br>　- 店舗の閉鎖：「店舗の閉鎖を始めました」「店舗の閉鎖を取り消しました」「店舗の閉鎖が完了しました」。<br>　- 運営者による組織の受付停止・停止・再開と、まとめてキャンセル(「運営が注文をキャンセルしました」)。<br>・通知は、組織のオーナーと、その店舗でロールを割り振られた担当者それぞれに届く。 |
