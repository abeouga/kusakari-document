#### EC-B17 出店の申請をする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 出店申請画面で必要な情報を入力し出店の申請をする。                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 出店を検討する事業者(出店申請用アカウント)                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 出店申請用アカウント(EC-B16で「企業様向け」を選んで登録したアカウント)でログインしている。<br>出店申請をしていない、または前回の申請が却下・取り下げ済みである。<br>「メイン」画面が表示されている。 |
| 事後条件     | 出店申請情報が出店審査状態「審査中」として保存され、「出店申請を受け付けました」が表示されている。 |
| 基本フロー    | 1. 事業者がアカウントのメニュー「出店申請」を開く(EC-C01)。<br>2. システムが「出店申請」画面に、手順(「事業者情報」「担当者・連絡先」「事業確認書類」「入力内容の確認」)と、「ステップ 1 / 4：事業者情報」の入力欄を表示する。<br>3. 事業者が「会社・事業者名」「所在地」を入力し、「次へ」ボタンをクリックする。<br>4. システムが入力内容を検証し、「担当者・連絡先」の入力欄を表示する。<br>5. 事業者が「担当者名」「連絡先メール」「電話番号」を入力し、「次へ」ボタンをクリックする。<br>6. システムが入力内容を検証し、「事業確認書類」の入力欄を表示する。<br>7. 事業者が「事業確認書類（PDF・PNG・JPEG、5MB以内）」で書類のファイルを選択し、「確認画面へ」ボタンをクリックする。<br>8. システムが入力内容を検証し、「入力内容の確認」に入力した出店申請情報を表示する。<br>9. 事業者が入力情報を確認する。<br>10. 事業者が「申請する」ボタンをクリックする。<br>11. システムが出店申請情報を保存し、「出店申請を受け付けました」と「審査結果は通知でお知らせします。」、「出店申請状況を確認する」リンクを表示する。<br>12. システムがサイト内通知「出店申請を受け付けました」を事業者に送る。 |
| 代替フロー    | 4a. 必須項目が不足する場合(基本フロー4・6・8)<br>4a-1. システムが「未入力の項目があります：(不足項目)」と表示し、次の手順へ進まない。<br>4a-2. 事業者が入力内容を直し、同じ手順の「次へ」(または「確認画面へ」)ボタンをクリックする。<br><br>4b. 入力形式が不正な場合(基本フロー6・8)<br>4b-1. システムが入力エラー(「連絡先メールの形式が正しくありません。」「電話番号は数字・＋・括弧・ハイフンで入力してください。」「事業確認書類は5MB以内のファイルを選択してください。」)を表示し、次の手順へ進まない。<br>4b-2. 事業者が入力内容を直し、同じ手順の「次へ」(または「確認画面へ」)ボタンをクリックする。<br><br>5a. 前の手順に戻る場合<br>5a-1. 事業者が「戻る」ボタンをクリックする。<br>5a-2. システムが入力内容を残したまま、前の手順の入力欄を表示する。<br><br>10a. 入力内容を修正する場合<br>10a-1. 事業者が「入力内容の確認」で「事業者情報を修正」「担当者・連絡先を修正」「事業確認書類を修正」のいずれかのボタンをクリックする。<br>10a-2. システムが入力内容を残したまま、その手順の入力欄を表示する。<br>10a-3. 事業者が入力内容を直し、「確認画面へ」まで進めて基本フロー9へ戻る。<br><br>11a. 審査中の申請がすでにある場合<br>11a-1. システムが「審査中の申請があります。」と表示し、申請を保存しない。<br>11a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・出店を申請できるのは、出店申請用アカウントだけである。ほかのアカウントで「出店申請」画面を開くと、「出店申請は、企業様向けに登録したアカウントで行います。新規登録の画面で「企業様向け」を選んで登録してください。」と表示する。<br>・出店プランの選択はない(料金プランは設けない。販売手数料はEC-S07を参照)。<br>・サイドバーのリンクの表示(「出店申請」／「出店申請状況」)はEC-B18の関連情報を参照。<br>・再申請の場合は「出店申請状況」画面の「再申請する」から基本フロー2に入り、「前回の申請内容を入力しています。事業確認書類はもう一度選択してください。」と、前回の申請内容が入った状態で「出店申請」画面を表示する。<br>・承認されると、出店者(オーナー)のアカウントになり、組織が作成される(EC-A03)。店舗は承認後にオーナーが作成する。 |
