#### EC-B05 販売店舗の情報を確認する

| 記述項目     | 記述内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| ユースケース概要 | 商品を販売する店舗の詳細情報を確認する。                                                 |
| アクター     | 購入者                                                             |
| 事前条件     | 「植物について」ダイアログに「販売店舗の紹介を見る」リンクが表示されている。                                              |
| 事後条件     | 取得できた店舗情報または情報がない状態が表示されている。                                         |
| 基本フロー    | 1. 購入者が「植物について」ダイアログの「販売店舗の紹介を見る」リンクをクリックする。<br>2. システムが「店舗紹介」画面に店舗名・所在地・営業時間・店舗紹介・営業状態(「営業中」または「閉店予定」)を表示する。 |
| 代替フロー    | 2a. 店舗が見つからない場合(非公開、運営者による利用停止中、閉鎖済みの店舗を含む)<br>2a-1. システムが「店舗が見つかりません。」と「再取得」ボタンを表示し、再取得を可能にする。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・購入者・未ログインの利用者に表示するのは、公開中の店舗と閉鎖中の店舗だけである。閉鎖中の店舗は、受け取り前の注文がある購入者が受取先を確かめられるように、「閉店予定」と表示する。<br>・出店者(オーナー・担当者)と運営者は、自分が扱える店舗を状態にかかわらず表示できる。 |
