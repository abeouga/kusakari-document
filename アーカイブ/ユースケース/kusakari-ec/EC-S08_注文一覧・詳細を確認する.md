#### EC-S08 注文一覧・詳細を確認する

| 記述項目     | 記述内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| ユースケース概要 | 店舗の注文の一覧と、注文ごとの明細・受取情報・支払いの状態を確認する。 |
| アクター     | 出店者(オーナー、MANAGER(店長)、STAFF)                                                                                  |
| 事前条件     | 出店者のアカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 注文の一覧と、各注文の内容が表示されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗受け取り」を開く(EC-C03)。<br>2. システムが「店舗受け取り」画面に、選択中の店舗の注文一覧(注文番号、注文状態、注文明細、合計、受取連絡先、お支払い方法と支払い・返金の状態、キャンセル申請状態)を、対応が必要な注文を先にして表示する。<br>3. 出店者が必要に応じて注文状態の絞り込みボタン(「準備待ち」「受け取り待ち」「キャンセル申請」「引き渡し完了」「キャンセル」「すべて」。それぞれ件数つき)をクリックするか、「注文番号・受取人で検索」欄に注文番号または受取人名を入力する。<br>4. システムが条件に合う注文だけを一覧に表示する。<br>5. 出店者が引き渡し完了・キャンセルの注文を確認する場合は、対象注文の「詳細」をクリックする。<br>6. システムが対象注文の注文明細と受取連絡先を表示する。<br>7. 出店者が対象注文の内容を確認する。 |
| 代替フロー    | 1a. 複数の店舗を扱う場合<br>1a-1. 出店者が画面上部の選択欄で、確認する店舗を選択する(EC-C03)。<br>1a-2. 基本フロー2へ進む。<br><br>2a. 注文がない場合、または条件に合う注文がない場合<br>2a-1. システムが「該当する注文はありません。」を表示する。<br>2a-2. ユースケースを終了する。<br><br>6a. 運営者がキャンセルした注文の場合(店舗の閉鎖・組織の停止によるまとめてキャンセル)<br>6a-1. システムが「運営がキャンセルしました：(理由)」を表示する。<br>6a-2. 基本フロー7へ進む。<br><br>6b. 返金に失敗した注文の場合<br>6b-1. システムが「返金に失敗しました。Stripe の管理画面で返金の状態を確認し、購入者に連絡してください。」を表示する。<br>6b-2. 基本フロー7へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・ロールのない担当者は注文を見られない。<br>・お支払い方法は「クレジットカード」または「店舗でお支払い」。カードの注文には支払いの状態(「支払い待ち」「支払い済み」「支払いの失敗」「期限切れ」)を、返金がある注文には返金の状態(「返金の処理中」「返金済み」「返金の失敗」)を表示する。<br>・受取準備完了・引き渡し完了への更新はEC-S09・EC-S10、キャンセル申請の処理はEC-S13で、同じ画面から行う。<br>・運営者は運営者画面の「全注文管理」で、全店舗の注文と販売手数料を同じ形式で確認できる(状態の更新はできない)。 |
