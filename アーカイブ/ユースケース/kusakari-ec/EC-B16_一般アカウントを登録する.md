#### EC-B16 一般アカウントを登録する

| 記述項目     | 記述内容                                                                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | メールアドレス・パスワードを入力し、購入者のアカウントを登録する。企業様向けの出店申請用アカウントと、招待キーを使った店舗の担当者のアカウントも、同じ画面で登録する。 |
| アクター     | 購入者(出店を検討する事業者、店舗の担当者を含む)                                                                                                                                                                                    |
| 事前条件     | ログアウト状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | アカウントが保存され、登録したアカウントでログイン状態になっている。                                                                                                                                                     |
| 基本フロー    | 1. 購入者が「メイン」画面から共通ヘッダーの「ログイン」をクリックする。<br>2. システムが「ログイン」画面を表示する。<br>3. 購入者が「新規登録」ボタンをクリックする。<br>4. システムが「ログイン」画面に、新規登録の入力欄(「メールアドレス」「パスワード（8文字以上）」「パスワード（確認）」)と「企業様向け：出店を申請するアカウントとして登録する」チェックボックスを表示する。<br>5. 購入者がメールアドレスを入力する。<br>6. 購入者がパスワードと確認用のパスワードを入力する。<br>7. 購入者が「確認コードを送信」ボタンをクリックする。<br>8. システムが入力形式(パスワードは8文字以上、確認用と一致)とメールアドレスの重複を確認する。<br>9. システムが入力されたメールアドレスに確認コードを送信し、「確認コード」の入力欄を表示する。<br>10. 購入者がメールに届いた確認コードを入力する。<br>11. 購入者が「確認して登録を完了」ボタンをクリックする。<br>12. システムが確認コードを照合してアカウントを登録し、ログイン状態にして元の画面を表示する。 |
| 代替フロー    | 3a. 店舗の担当者として招待キーで登録する場合<br>3a-1. 購入者が「招待キーで登録（店舗の担当者）」ボタンをクリックする。または、店舗から受け取った登録用のURLを開く。<br>3a-2. システムが「企業様向け」チェックボックスの代わりに「招待キー」の入力欄を表示する。登録用のURLを開いた場合は、招待キーを入力した状態で表示する。<br>3a-3. 購入者が招待キーを入力し、基本フロー5へ進む。登録すると、招待キーを発行した店舗の担当者のアカウント(ロールなし)になる。<br><br>6a. 企業様向けの登録をする場合<br>6a-1. 購入者が「企業様向け：出店を申請するアカウントとして登録する」チェックボックスにチェックを付ける。<br>6a-2. 基本フロー7へ進む。登録すると、出店申請用アカウントになる(EC-B17)。<br><br>8a. 無効な値または重複がある場合<br>8a-1. システムが「パスワードが条件を満たしていません。8文字以上で入力してください。」「パスワードと確認用パスワードが一致しません。」「このメールアドレスは既に登録されています。ログインしてください。」などのエラーを表示し、登録しない。<br>8a-2. 基本フロー5へ戻る。<br><br>8b. 招待キーが使えない場合(期限切れ・取り消し済み・使用済み、店舗の停止・閉鎖済みなど)<br>8b-1. システムが「招待キーが無効です。期限切れ・取り消し済み・使用済みのキーは使えません。店舗の管理者に新しいキーを依頼してください。」と表示し、登録しない。<br>8b-2. 代替フロー3a-3へ戻る。<br><br>11a. 確認コードが無効または有効期限切れの場合<br>11a-1. システムが「確認コードが正しくありません。」または「確認コードの有効期限が切れています。コードを再送してください。」と表示する。<br>11a-2. 購入者が必要に応じて「確認コードを再送する」をクリックすると、システムが確認コードを再送し、「確認コードを再送しました。」と表示する。<br>11a-3. 基本フロー10へ戻る。 |
| 関連情報     | ・アカウントの登録・確認コードの入力は、「ログイン」画面の中で行う。「アカウントをお持ちの方はログイン」「ログインに戻る」でログインの入力欄に戻れる。<br>・お名前は登録しない。画面上の表示名にはメールアドレスを使う。<br>・メールアドレスの確認が済むまでは、ECにログインできない(EC-B01)。<br>・アカウントの種類は登録の方法で決まる。通常の登録は購入者、企業様向けの登録は出店申請用アカウント、招待キーでの登録は店舗の担当者である。出店申請用アカウントと店舗の担当者は購入できない(EC-B07)。<br>・招待キーは新規登録のときだけ使える。ログイン中に登録用のURLを開くと、「招待キーは新規登録のときだけ使えます。ログアウトしてから、新しいアカウントとして登録してください。」と表示する。<br>・招待キーの発行と、登録後のロールの割り振りは、出店者画面の「招待キー」「アカウント」で行う。<br>・招待キーと企業様向けの登録は同時にできない。 |
