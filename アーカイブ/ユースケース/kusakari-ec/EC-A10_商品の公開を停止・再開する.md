#### EC-A10 商品の公開を停止・再開する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者が不適切な商品の出店者に警告し、必要に応じて商品の公開を停止する。問題が解消したら、警告を解除し、公開を再開する。 |
| アクター     | 運営者                                                                                                                                                                                                                                                                                                                                                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。<br>対象の商品が登録されている。 |
| 事後条件     | 対象商品の公開状態が「公開停止中」または「公開可能」として保存され、操作の履歴が残り、出店者に理由が通知されている。 |
| 基本フロー    | 1. 運営者が運営者画面のメニュー「商品管理」を開く(EC-C02)。<br>2. システムが「商品管理」画面に商品の一覧と公開状態を表示する(EC-A06)。公開停止中でない商品には、「警告する」ボタンと、「デンジャーエリア」に「公開を停止」ボタンを表示する。<br>3. 運営者が対象商品の「デンジャーエリア」の「公開を停止」ボタンをクリックする。<br>4. システムが「公開停止の確認」ダイアログに、対象の商品名、停止すると購入者向けの画面に表示されずカートに入っていても購入できなくなること、「理由(必須・出店者に通知します)」入力欄を表示する。<br>5. 運営者が「理由」入力欄に理由を入力する。<br>6. 運営者が「公開停止を確定」ボタンをクリックする。<br>7. システムが商品の公開状態を「公開停止中」に更新し、操作の履歴を記録する。<br>8. システムが出店者向けのイベント通知(EC-S11)で、「商品の公開を停止しました」と商品名・理由を通知する。<br>9. システムが「停止しました。出店者に通知しました。」と更新後の公開状態を表示し、「公開を停止」ボタンの代わりに「公開停止を解除」ボタンを表示する。 |
| 代替フロー    | 3a. 停止せずに警告する場合<br>3a-1. 運営者が対象商品の「警告する」ボタン(警告中の場合は「もう一度警告する」ボタン)をクリックする。<br>3a-2. システムが「警告の確認」ダイアログに、対象の商品名、公開の状態は変わらないこと、「理由(必須・出店者に通知します)」入力欄を表示する。<br>3a-3. 運営者が理由を入力し、「警告する」ボタンをクリックする。<br>3a-4. システムが警告を履歴に記録し、出店者向けのイベント通知(EC-S11)で「商品に運営から警告がありました」と商品名・理由を通知する。<br>3a-5. システムが「警告しました。出店者に通知しました。」と表示し、商品に「警告中」のバッジと理由を表示する。<br>3a-6. ユースケースを終了する。<br><br>3b. 警告を解除する場合<br>3b-1. 運営者が警告中の商品の「警告を解除」ボタンをクリックする。<br>3b-2. システムが「警告の解除の確認」ダイアログに、対象の商品名と「理由(任意・出店者に通知します)」入力欄を表示する。<br>3b-3. 運営者が必要に応じて理由を入力し、「警告を解除する」ボタンをクリックする。<br>3b-4. システムが警告の解除を履歴に記録し、出店者向けのイベント通知(EC-S11)で「商品への運営の警告が解除されました」と通知する。<br>3b-5. システムが「警告を解除しました。出店者に通知しました。」と表示し、「警告中」のバッジを消す。<br>3b-6. ユースケースを終了する。<br><br>3c. 公開停止を解除する場合<br>3c-1. 運営者が公開停止中の商品の「公開停止を解除」ボタンをクリックする。<br>3c-2. システムが「公開停止の解除の確認」ダイアログに、対象の商品名、出店者が非表示にしていなければ購入者向けの画面に再び表示されること、「理由(任意・出店者に通知します)」入力欄を表示する。<br>3c-3. 運営者が必要に応じて理由を入力し、「公開停止の解除を確定」ボタンをクリックする。<br>3c-4. システムが商品の公開状態を「公開可能」に更新して履歴に記録し、出店者向けのイベント通知(EC-S11)で「商品の公開停止を解除しました」と通知する。<br>3c-5. システムが「再開しました。出店者に通知しました。」と更新後の公開状態を表示する。<br>3c-6. ユースケースを終了する。<br><br>5a. 理由が必須の操作(公開停止・警告)で、理由が未入力のまま確定した場合<br>5a-1. システムが「理由を入力してください。」を表示し、公開状態を変更しない。<br>5a-2. 基本フロー5へ戻る。<br><br>6a. 確認ダイアログで「取消」ボタンをクリックした場合<br>6a-1. システムがダイアログを閉じ、公開状態を変更せず「商品管理」画面を表示する。<br>6a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・出店者が登録した商品(EC-S03)は事前の審査なしで公開される。運営者は公開後に商品を確認し、必要に応じて警告・公開停止を行う。<br>・警告は公開停止の前に行ってもよい段階で、必ず行う必要はない。警告しても公開状態は変わらず、購入者への表示も注文の受付も続く。期限はなく、期限が来ても自動では停止しない。<br>・警告中の商品にもう一度警告できる。警告を解除できるのは運営者だけで、出店者が商品を編集しても警告は解除されない。公開停止・解除をしても警告は自動では解除されない。<br>・公開停止中の商品は、出店者が「公開中」にしていても購入者向けの画面に表示しない。カートに入っていても購入できない(EC-B12)。<br>・公開停止の解除は運営者だけが行える。出店者が商品を編集しても公開停止は解除されない。<br>・理由は500文字まで入力できる。<br>・警告・公開停止の状態と理由は、出店者の「商品管理」画面(EC-S04〜EC-S06)にも表示される。購入者向けの画面には表示しない。<br>・すでに公開停止中の商品の停止、公開停止していない商品の解除、警告していない商品の警告の解除は、何もせず、履歴も通知も残さない。 |
