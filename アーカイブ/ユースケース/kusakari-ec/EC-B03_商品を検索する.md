#### EC-B03 商品を検索する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品名・商品番号・生産者名で商品を探し、条件で絞り込む。                                                                                                                                                                                                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                               |
| 事前条件     | 共通ヘッダーのある画面(「トップ」画面など)が表示されている。<br>ログインは不要である。                                                                                                                                                                                                                                                                                                    |
| 事後条件     | 条件に合う商品一覧または選択した商品が表示されている。                                                                                                                                                                                                                                                                                                                       |
| 基本フロー    | 1. 購入者が共通ヘッダーの「商品を探す」リンクをクリックする。<br>2. システムが「メイン」画面の商品一覧を表示する。<br>3. 購入者が必要に応じて、「名前・品番・生産者で検索」欄に商品名・商品番号・生産者名のいずれかを入力する。<br>4. 購入者が必要に応じて、カテゴリーのボタン(「すべて」など)をクリックするか、「絞り込み条件」の「日照条件」「用途・植栽場所」「手入れレベル」「出店者・ナーセリー」を一覧から選択するか、「価格上限（円）」欄に金額を入力するか、「在庫ありのみ」にチェックを入れる。<br>5. 購入者が必要に応じて、並び順の一覧(初期表示「おすすめ順」)から「価格が安い順」などを選択する。<br>6. システムが条件に合う商品を表示する。 |
| 代替フロー    | 6a. 該当商品がない場合<br>6a-1. システムが「条件に合う植物が見つかりません。」と「条件をリセット」ボタンを表示し、検索条件の変更を可能にする。<br>6a-2. 基本フロー3へ戻る。                                                                                                                                                                                                                                                |
| 関連情報     | ・購入者向けの画面には、購入可能な商品だけを表示する。購入可能な商品とは、次をすべて満たす商品を指す。<br>　- 出店者が「公開中」にしている(EC-S06)。<br>　- 運営者に公開停止されていない(EC-A10)。<br>　- 商品の店舗が公開中で、運営者に利用停止されておらず(EC-A11)、閉鎖中・閉鎖済みでない。<br>　- 店舗の組織が、運営者による受付停止中・停止になっていない。<br>・在庫が0の商品も一覧には表示する(「在庫ありのみ」で除外できる)。<br>・全店舗の商品をまとめて表示する。商品はそれぞれ1つの店舗に属し、その店舗が受取店舗になる。<br>・「絞り込みを解除」ボタンで、「絞り込み条件」をまとめて解除できる。 |
