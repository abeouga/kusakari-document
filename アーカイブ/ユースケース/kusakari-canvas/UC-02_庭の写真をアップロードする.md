#### UC-02 庭の写真をアップロードする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | シミュレーションの土台にするため、実際の庭の写真を1枚アップロードする。                                                                                                                                                                                                                                                                                                                                     |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                      |
| 事前条件     | 庭プロジェクトが作成されている。<br>庭プロジェクトを開き、庭シミュレーション画面に「庭の写真から設計する」エリアが表示されている。                                                                                                                                                                                                                                                                                                      |
| 事後条件     | 庭写真が庭シミュレーション画面に表示され、施工範囲の指定が始まっている。                                                                                                                                                                                                                                                                                                                                     |
| 基本フロー    | 1. 購入者が庭シミュレーション画面の「庭の写真から設計する」エリアをクリックする。<br>2. システムがファイル選択ダイアログを表示する。<br>3. 購入者がファイル選択ダイアログで庭の写真ファイルを選択する。<br>4. システムが写真の形式・サイズを検証する。<br>5. システムが庭写真を画面に表示する。<br>6. システムが施工範囲の指定を開始する。                                                                                                                                                                                 |
| 代替フロー    | 1a. 写真をドラッグ＆ドロップする場合<br>1a-1. 購入者が庭の写真ファイルを「庭の写真から設計する」エリアにドラッグ＆ドロップする。<br>1a-2. 基本フロー4へ進む。<br><br>4a. 写真の形式やサイズが不正な場合<br>4a-1. システムが対応形式・容量上限を示すエラーメッセージ(「JPEGまたはPNGを5MB以内で選択してください。」)を表示し、写真を表示しない。<br>4a-2. 基本フロー1へ戻る。 <br><br>4b. 写真の画素数が大きすぎる場合<br>4b-1.システムにエラーメッセージ（「画像は各辺6000px、総画素数2500万以下にしてください。」）を表示し、写真を表示しない。<br>4b-2.基本フロー1へ戻る。<br><br>4c.写真を読み込めない場合<br>4c-1.システムがエラーメッセージ（「画像を読み込めません。」）を表示し、写真を表示しない。<br>4c-2.基本フロー1へ戻る。                                                                                                                                               |
| 関連情報     | ・登録できる庭写真は1プロジェクトにつき1枚とする。<br>・対応形式はJPEG・PNG、容量は5MB以下<br>・庭写真は、施工範囲を確定したときに庭プロジェクトと一緒に保存される。施工範囲を確定する前に画面を閉じると、写真は保存されない。<br>・写真ツールバーの「写真を変更」ボタンをクリックすると、別の写真に差し替えられる。<br>・写真ツールバーの「写真を外す」ボタンをクリックすると写真が外れて、再度写真のアップロードが可能になる。<br>・写真を外したり差し替えたりすると施工範囲と実寸補正はリセットされるが、庭オブジェクトの配置は残る。新しい施工範囲を確定したあと、範囲外になった庭オブジェクトには範囲外であることを表示する。範囲外の庭オブジェクトを移動または削除するまで、庭プロジェクトは保存されない。 |
