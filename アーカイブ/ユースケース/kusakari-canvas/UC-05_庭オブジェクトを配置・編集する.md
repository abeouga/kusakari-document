#### UC-05 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 事前条件     | 庭プロジェクトを開き、庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 基本フロー    | 1. 購入者がサイドバーの「商品一覧」タブの商品を、庭写真上(3D表示では庭の土台上)の設置したい位置へドラッグ＆ドロップする。<br>2. システムがドロップ位置を庭の地面の位置に変換し、施工範囲の内側であることを確認する。<br>3. システムが庭オブジェクトを庭シミュレーションに表示し、「配置したもの」一覧に追加する(「n / 200」の個数も更新する)。変更は自動保存される(UC-07)。。<br>4. 購入者が設置済みの庭オブジェクト(または「配置したもの」一覧の行)をクリックして選択する。<br>5. 購入者が移動・回転・拡大縮小のいずれかを行う(移動は庭オブジェクトをドラッグする。3D表示では「回転」「拡縮」ボタンをクリックして、回転リングや拡縮のハンドルをドラッグする)。<br>6. システムが操作結果を庭シミュレーションに反映し、「配置したもの」一覧の位置(X・Z)を更新する。変更は自動保存される。<br>7. 購入者が不要な庭オブジェクトをクリックして選択する(基本フロー4と同じ)。<br>8. 購入者が「削除」ボタンをクリックする(Delete キーまたは Backspace キーでも削除できる)<br>9. システムが庭オブジェクトを庭シミュレーションと「配置したもの」一覧から取り除く。変更は自動保存される。                                                                                                                                                                                     |
| 代替フロー    | 1a. ECから商品を指定して開いた場合(URL に productId を付けて開いた場合)<br>1a-1. システムがその商品を選択した状態にする。<br>1a-2.  購入者が庭写真上の設置したい位置をクリックする。<br>1a-3.基本フロー2へ進む。<br><br>1b. 庭写真がアップロードされていない場合<br>1b-1. システムが「庭写真が未アップロードのため配置できません。…」と表示し、設置しない。<br>1b-2. ユースケースを終了する。<br><br>2a. 施工範囲の外に設置しようとした場合<br>2a-1. システムが設置を反映せず、範囲内への配置を促す(ドロップした場合は「庭の地面の範囲内へドロップしてください。」と表示する)。<br>2a-2. 基本フロー1へ戻る。<br><br>3a. 配置数が上限に達している場合<br>3a-1.システムが「配置数の上限に達したか、配置位置が範囲外です。」と表示し、設置しない。<br>3a-2. 基本フロー4へ進む。<br><br>5a. ドラッグで施工範囲の外へ移動しようとした場合<br>5a-1. システムが範囲内で最後にあった位置に庭オブジェクトをとどめ、「施工範囲の外へは移動できません。」と表示する。<br>5a-2. 基本フロー5へ戻る。<br><br>5b. . 移動・回転・拡大縮小の結果が制限を超えた場合(位置が施工範囲の外、回転がY軸以外、倍率が範囲外)<br>5b-1. システムがエラーメッセージ(「庭の範囲、回転軸、拡大縮小の制限内で入力してください。」)を表示し、変更前の位置・向き・大きさに戻す。<br>5b-2. 基本フロー5へ戻る。<br><br>5c. 3D表示で「拡縮」のハンドルをドラッグし、上限・下限に達した場合<br>5c-1. システムが上限・下限の大きさ(倍率0.25〜3)で止めて反映する。<br>5c-2. 基本フロー6へ進む。 |
| 関連情報     | ・商品と庭オブジェクトは1対1で紐づいている。<br>・庭オブジェクトは3Dモデルとして庭写真の上に配置する。<br>・1つの庭プロジェクトに設置できる庭オブジェクトは200個までとする。<br>・回転・拡大縮小で庭オブジェクトの一部が施工範囲の外に出ても、設置位置が範囲内であれば許可する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
