# UC-04 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                               |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                                                                                    |
| 事前条件     | 庭シミュレーション画面が表示されている。庭写真がアップロードされ、施工範囲が設定されている。                                                                                                                                                                                                                                                                              |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映される。                                                                                                                                                                                                                                                                                      |
| 基本フロー    | 1. 利用者が設置したい庭オブジェクトを選ぶ。<br>2. 利用者が庭写真上の位置を指定して設置する。<br>3. システムが庭オブジェクトを庭シミュレーションに表示する。<br>施工範囲の外に設置した場合は => 代替フロー1へ<br>4. 利用者が設置済みオブジェクトを選び、移動・回転・拡大縮小のいずれかを行う。<br>5. システムが操作結果を庭シミュレーションに反映する。<br>移動・拡大縮小で上限・下限を超える場合 -> 代替フロー3へ<br>6. 利用者が不要なオブジェクトを選び、削除する。<br>7. システムが庭オブジェクトを庭シミュレーションから取り除く。<br>通信に失敗した場合は => 代替フロー2へ |
| 代替フロー    | 1. 施工範囲の外に設置・移動した場合<br>1-1. システムが範囲外であることを表示し、範囲内への配置を促す。<br><br>2. 通信に失敗した場合(オブジェクト情報の取得など)<br>2-1. システムが通信エラーを表示し、再実行を可能にする。<br><br>3. 移動・拡大縮小で上限・下限を超える場合<br>3-1. システムが上限・下限の位置・大きさに制限する。                                                                                                                                |
