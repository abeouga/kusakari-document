# UC-08 購入リストを表示する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭に配置した庭オブジェクトに対応する商品を、購入リストとして一覧で表示する。                                                                                                                                                                                                                                                                                                                |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                                                                                                              |
| 事前条件     | 庭プロジェクトが開かれている。                                                                                                                                                                                                                                                                                                                                       |
| 事後条件     | 配置されている庭オブジェクトに対応する商品が、購入リストに表示される。                                                                                                                                                                                                                                                                                                                   |
| 基本フロー    | 1. 利用者が購入リストの表示を選ぶ。<br>2. システムが庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>配置されたオブジェクトがない場合は => 代替フロー1へ<br>3. システムが各庭オブジェクトに紐づいた商品の情報を取得する。<br>庭オブジェクトに紐づく商品が存在しない場合は => 代替フロー2へ<br>通信に失敗した場合は => 代替フロー4へ<br>4. システムが商品ごとに、配置数を数量として購入リストに表示する(商品画像、商品名、価格、出店者名、在庫状況、数量)。<br>商品が販売停止中または在庫不足の場合は => 代替フロー3へ<br>5. 利用者が購入リストを確認する。                            |
| 代替フロー    | 1. 配置されたオブジェクトがない場合<br>1-1. システムが購入リストが空であることを表示し、オブジェクトの配置(UC-04)を案内する。<br><br>2. 庭オブジェクトに紐づく商品が存在しない場合(商品が削除された、紐づけが解除されたなど)<br>2-1. システムがその庭オブジェクトに対応する商品がないことを表示する。<br><br>3. 紐づいた商品が販売停止中または在庫不足の場合  <br>3-1. システムがその商品を購入リストに表示し、販売停止または在庫不足であることを示す。 <br>3-2. システムがその商品をカートへ登録できないようにする。<br><br>4. 通信に失敗した場合<br>4-1. システムが通信エラーを表示し、再取得を可能にする。 |
| 関連情報     | 庭オブジェクトと商品は1対1で紐づく。 / 数量は配置されているオブジェクトの個数とする                                                                                                                                                                                                                                                                                                          |
