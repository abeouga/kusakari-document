#### UC-04 施工範囲の実寸を定義する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 施工範囲のすべての辺の実際の長さを入力し、写真の遠近を考慮したシミュレーション上の縮尺(実寸)に補正する。                                                                                                                                                                                                                                                                                                                    |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                      |
| 事前条件     | 庭プロジェクトを開き(UC-C01)、庭シミュレーション画面が表示されている。<br>施工範囲が確定している。                                                                                                                                                                                                                                                                                                                                     |
| 事後条件     | 各辺の実際の長さと、そこから求めた実寸補正の情報が庭プロジェクトに保存され、庭の大きさと庭オブジェクトの位置が補正後の縮尺で表示されている。                                                                                                                                                                                                                                                                                                   |
| 基本フロー    | 1. 購入者が写真ツールバーの「輪郭と寸法」ボタンをクリックする(施工範囲の確定直後は、システムがこの編集を自動で開くため不要)。<br>2. システムが施工範囲の各辺と長さの目安、入力済みの辺の数(「0/4辺入力済み」など)を表示する。<br>3. 購入者が施工範囲の辺を1本クリックする。<br>4. システムが「辺Nの長さ」ポップアップを表示する。<br>5. 購入者がポップアップの入力欄にその辺の実際の長さ(m)を入力する。<br>6. 購入者が「適用」ボタンをクリックする。<br>7. システムが入力値を検証し、その辺の長さとして記録する。<br>8. 未入力の辺が残っている場合、システムが「辺Nを記録しました。残りM辺を入力すると、写真のパースを求めます。」と表示し、ポップアップを次の未入力の辺に切り替える。<br>9. 購入者がすべての辺について5〜8を繰り返す。<br>10. すべての辺の長さがそろうと、システムが辺の長さから写真の撮影位置と向きを求め、写真の遠近を考慮して縮尺を補正する。<br>11. システムが補正後の庭の大きさ(幅・奥行き)と庭オブジェクトの位置を庭シミュレーションに反映し、庭プロジェクトに保存する。 |
| 代替フロー    | 2a. 実寸補正を行わない場合<br>2a-1. 購入者が辺の長さを入力せずに「完了」ボタンをクリックする。<br>2a-2. システムは実寸補正の情報を保存せず、施工範囲を囲む長方形を庭の幅×奥行き(土台寸法)に当てはめて写真と庭を対応付ける。<br>2a-3. ユースケースを終了する。<br><br>7a. 長さが無効な場合(0.01m未満、100mを超える、数値以外)<br>7a-1. システムが入力エラーメッセージ(「辺の長さは0より大きい数値で入力してください。」または「辺の長さは0.01〜100mで入力してください。」)を表示し、再入力を求める。<br>7a-2. 基本フロー5へ戻る。<br><br>10a. 入力した長さで補正できない場合(長さの組み合わせが写真の形と合わない、補正後の庭の幅・奥行きが1〜50mに収まらない、配置済みの庭オブジェクトが施工範囲の外に出るなど)<br>10a-1. システムが補正できない理由(「写真上の輪郭からパースを求められません。輪郭を確認してください。」「変更後の庭の幅・奥行きが1〜50mに収まる長さを指定してください。」「配置物が庭の外に出るため変更できません。」など)を表示し、縮尺を変更しない。<br>10a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・すべての辺の長さがそろうまでは、入力した長さは記録されるだけで縮尺は変わらない。                                                                                                                                                                                                                                                                                                                                |
