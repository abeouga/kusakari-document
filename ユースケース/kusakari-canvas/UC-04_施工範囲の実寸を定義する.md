#### UC-04 施工範囲の実寸を定義する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 施工範囲のすべての辺の実際の長さを入力し、写真の遠近を考慮したシミュレーション上の縮尺(実寸)に補正する。 |
| アクター     | 購入者                                                                                                                                                                                                                                                                            |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>施工範囲が確定している。                                                                                                                                                                                                                                                |
| 事後条件     | 各辺の実際の長さと、そこから求めた実寸補正の情報が庭プロジェクトに保存され、庭の大きさと庭オブジェクトの位置が補正後の縮尺で表示されている。 |
| 基本フロー    | 1. システムが施工範囲の確定後に実寸の入力を案内する(または、購入者が「輪郭と寸法」を選ぶ)。<br>2. 購入者が施工範囲の辺を1本選ぶ。<br>3. 購入者がその辺の実際の長さを入力する。<br>4. システムが入力値を検証し、その辺の長さとして記録する。<br>5. 購入者がすべての辺について2〜4を繰り返す。<br>6. すべての辺の長さがそろうと、システムが辺の長さから写真の撮影位置と向きを求め、写真の遠近を考慮して縮尺を補正する。<br>7. システムが補正後の庭の大きさ(幅・奥行き)と庭オブジェクトの位置を庭シミュレーションに反映し、庭プロジェクトに保存する。 |
| 代替フロー    | 1a. 実寸補正を行わない場合<br>1a-1. システムは実寸補正の情報を保存せず、施工範囲を囲む長方形を庭の幅×奥行き(土台寸法)に当てはめて写真と庭を対応付ける。<br>1a-2. ユースケースを終了する。<br><br>4a. 長さが無効な場合(0.01m未満、100mを超える、数値以外)<br>4a-1. システムが入力エラーメッセージを表示し、再入力を求める。<br>4a-2. 基本フロー3へ戻る。<br><br>6a. 入力した長さで補正できない場合(長さの組み合わせが写真の形と合わない、補正後の庭の幅・奥行きが1〜50mに収まらない、配置済みの庭オブジェクトが施工範囲の外に出るなど)<br>6a-1. システムが補正できない理由を表示し、縮尺を変更しない。<br>6a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・長さの単位はメートルとする。<br>・すべての辺の長さがそろうまでは、入力した長さは記録されるだけで縮尺は変わらない。<br>・補正未設定の場合は、庭オブジェクトの大きさが実寸と合わない可能性がある。<br>・補正なしの場合は写真の遠近(奥ほど小さく写ること)を考慮しないため、面積や長さは「カメラ未設定・土台寸法からの概算」、写真の表示では「概算」と表示する。<br>・実寸定義は後からやり直せる。<br>・全辺入力後に点を動かすと、縮尺はそのままで、各辺の長さが新しい形に合わせて計算し直される(入力値は置き換わる)。<br>・辺の長さの代わりに、「写真のカメラを設定」から写真上の長方形を基準にして撮影位置と向きを合わせることもできる。 |
