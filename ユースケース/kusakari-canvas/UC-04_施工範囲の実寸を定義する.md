#### UC-04 施工範囲の実寸を定義する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 施工範囲の辺の長さを入力し、シミュレーション上の縮尺(実寸)を補正する。                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                            |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>施工範囲が確定している。                                                                                                                                                                                                                                                |
| 事後条件     | 実寸補正の情報(基準にした辺と長さ、算出した縮尺)が庭プロジェクトに保存されている。                                                                                                                                                                                                                                          |
| 基本フロー    | 1. システムが施工範囲の確定後に実寸の入力を案内する(または、購入者が実寸の定義を選ぶ)。<br>2. 購入者が施工範囲の辺を1本選ぶ。<br>3. 購入者がその辺の実際の長さを入力する。<br>4. システムが入力値を検証する。<br>5. システムが入力値から写真の縮尺を算出し、庭プロジェクトに保存する。<br>6. システムが補正後の縮尺を庭シミュレーションに反映する。                                                                                      |
| 代替フロー    | 1a. 実寸補正を行わない場合<br>1a-1. システムは実寸補正の情報を保存せず、施工範囲を囲む長方形を庭の幅×奥行き（土台寸法）に当てはめて写真と庭を対応付ける。<br>1a-2. ユースケースを終了する。<br><br>4a. 長さが無効な場合(0以下、数値以外、上限超過)<br>4a-1. システムが入力エラーメッセージを表示し、再入力を求める。<br>4a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・補正未設定の場合は、庭オブジェクトの大きさが実寸と合わない可能性がある。<br>・実寸定義は後からやり直せる。<br>・長さの単位はメートルとする。<br>・補正なしの場合は写真の遠近(奥ほど小さく写ること)を考慮しないため、面積や長さは「カメラ未設定・土台寸法からの概算」、写真の表示では「概算」と表示する。<br>・全辺入力後に点を動かすと、縮尺はそのままで、各辺の長さが新しい形に合わせて計算し直される（入力値は置き換わる）。 |
