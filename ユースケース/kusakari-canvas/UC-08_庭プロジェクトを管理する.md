#### UC-08 庭プロジェクトを管理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 作成した庭プロジェクトを一覧で確認し、複製して別案を作ったり、不要なプロジェクトを削除したりする。                                                                                                                                                                                                                                    |
| アクター     | 購入者                                                                                                                                                                                                                                                                                  |
| 事前条件     | 購入者がログイン済みである。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。 |
| 事後条件     | 複製した場合は新しい庭プロジェクトが追加され、削除した場合は対象が「庭プロジェクト一覧」画面から消えている。 |
| 基本フロー    | 1. 購入者が共通ヘッダーの「Canvas」リンクをクリックする。<br>2. システムが「庭プロジェクト一覧」画面の「保存した庭」に、購入者の庭プロジェクトを更新が新しい順に一覧表示する。<br>3. 購入者が対象の庭プロジェクトのカードのオプションボタン(「…」)をクリックする。<br>4. システムが「複製」「削除」のメニューを表示する。<br>5. 購入者が「複製」または「削除」をクリックする。<br>6. 「複製」の場合、システムが「庭を複製しています…」と表示し、選択したプロジェクトの内容を複製して「元の名前（複製）」という名前で新規プロジェクトを作成し、一覧に追加する。<br>7. 「削除」の場合、システムが「この庭を削除しますか？」ダイアログを表示する。<br>8. 購入者が「庭を削除」ボタンをクリックする。<br>9. システムがプロジェクトを削除し、一覧から取り除く。 |
| 代替フロー    | 2a. 庭プロジェクトがない場合<br>2a-1. システムが「保存した庭はまだありません。上のフォームから最初の庭を作成できます。」と表示し、新規作成(UC-01)を案内する。<br>2a-2. ユースケースを終了する。<br><br>6a. 複製に失敗した場合<br>6a-1. システムがエラー(「庭を複製できませんでした。…」)と「複製を再試行」ボタンを表示し、新しいプロジェクトを作成しない。<br>6a-2. 基本フロー3へ戻る。<br><br>8a. 削除を取り消した場合<br>8a-1. 購入者が「取消」ボタンをクリックする。<br>8a-2. システムが削除せず、一覧表示に戻る。<br>8a-3. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・庭プロジェクトのカードをクリックして開く操作はUC-C01で行う。<br>・複製は別案の比較に使う。複製では庭写真・施工範囲・実寸補正・庭オブジェクトの配置を引き継ぎ、完成イメージの生成履歴は引き継がない。<br>・複製の名前が長い場合は、元の名前を短くしてから「（複製）」を付ける。<br>・削除の確認では、「庭の写真、輪郭、配置したすべての素材と生成履歴を削除します。」と表示する。<br>・削除したプロジェクトの復元はしない。 |
