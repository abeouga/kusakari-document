#### UC-08 庭プロジェクトを管理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 作成した庭プロジェクトを一覧で確認し、複製して別案を作ったり、不要なプロジェクトを削除したりする。                                                                                                                                                                                                                                    |
| アクター     | 購入者                                                                                                                                                                                                                                                                                  |
| 事前条件     | 購入者がログイン済みである。                                                                                                                                                                                                                                                                       |
| 事後条件     | 複製した場合は新しい庭プロジェクトが追加され、削除した場合は対象が庭プロジェクト一覧から消えている。                                                                                                                                                                                                                                   |
| 基本フロー    | 1. 購入者が庭プロジェクト一覧画面を開く。<br>2. システムが購入者の庭プロジェクトを一覧表示する。<br>3. 購入者がプロジェクトを選び、操作(「開く」「複製」「削除」)を選ぶ。<br>4. 「開く」の場合、システムが選択したプロジェクトの庭シミュレーション画面を表示する。<br>5. 「複製」の場合、システムが選択したプロジェクトの内容を複製し、「元の名前(コピー)」という名前で新規プロジェクトを作成して一覧に追加する。<br>6. 「削除」の場合、システムが削除の確認を表示する。購入者が確定すると、システムがプロジェクトを削除する。 |
| 代替フロー    | 2a. 庭プロジェクトがない場合<br>2a-1. システムが新規作成(UC-01)を案内する。<br>2a-2. ユースケースを終了する。<br><br>6a. 削除を取り消した場合<br>6a-1. システムが削除せず、一覧表示に戻る。<br>6a-2. 基本フロー3へ戻る。                                                                                                                                         |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・複製は別案の比較に使う。<br>・削除したプロジェクトの復元はしない。                                                                                                                                                                                                                           |
