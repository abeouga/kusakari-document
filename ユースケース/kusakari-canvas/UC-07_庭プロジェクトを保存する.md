#### UC-07 庭プロジェクトを保存する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報を庭プロジェクトとして保存する。                                                                                                                                                                                                                                                                                                                                                                   |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | ログイン状態である。<br>庭シミュレーション画面が表示されている。 |
| 事後条件     | 庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報が保存され、次回以降に再開できる状態になっている。                                                                                                                                                                                                                                                                                                                                                          |
| 基本フロー    | 1. 購入者が庭オブジェクトの配置・編集や施工範囲の修正・実寸定義の操作を行う。<br>2. システムが庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報を取得する。<br>3. 操作が止まると、システムが取得した内容を庭プロジェクトとして自動保存する。<br>4. システムが保存完了を表すアイコンを表示する。 |
| 代替フロー    | 3a. 保存できない状態の場合(施工範囲の指定中・カメラの設定中、施工範囲の外に庭オブジェクトがある、施工範囲が未確定の庭写真がある)<br>3a-1. システムが自動保存を行わず、保存するために必要な操作を表示する。<br>3a-2. 購入者が操作を確定する、または庭オブジェクトを範囲内へ移動・削除すると、基本フロー2へ進む。<br><br>3b. 通信に失敗した場合<br>3b-1. システムが通信エラーを表示し、保存されていないことを伝える。<br>3b-2. システムが編集内容を保持したまま、再保存を可能にする。<br>3b-3. 基本フロー3へ戻る。<br><br>3c. 別の画面で同じ庭プロジェクトが先に保存されていた場合<br>3c-1. システムが上書きせず、別の保存結果と競合したことを表示する。<br>3c-2. システムが編集内容を保持したまま、変更内容の確認を促す。<br>3c-3. ユースケースを終了する。<br><br>3d. ログインの有効期限が切れていた場合<br>3d-1. システムが編集内容を保持したまま、ログインし直すよう表示する。<br>3d-2. 購入者がログインし直す。<br>3d-3. 基本フロー3へ戻る。 |
| 関連情報     | ・保存は自動保存だけとし、「保存」ボタンはない。<br>・保存されていない編集があるまま画面を閉じようとすると、ブラウザの確認メッセージを表示する。<br>・庭シミュレーション画面からほかの画面へ移動するときは、保存が終わるのを待ってから移動する。<br>・保存すると、庭プロジェクト一覧に表示するサムネイルも更新する。 |
