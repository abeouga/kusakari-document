#### UC-07 庭プロジェクトを保存する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報を庭プロジェクトとして保存する。                                                                                                                                                                                                                                                                                                                                                                   |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | 庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                            |
| 事後条件     | 庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報が保存され、次回以降に再開できる状態になっている。                                                                                                                                                                                                                                                                                                                                                          |
| 基本フロー    | 1. 購入者が庭オブジェクトの配置・編集や施工範囲の修正・実寸定義の操作を行う。<br>2. システムが庭写真・施工範囲・実寸補正の情報と、庭オブジェクトの位置・向き・大きさ・個数・商品の情報を取得する。<br>3. システムが取得した内容を庭プロジェクトとして自動保存する。<br>4. システムが保存完了を表すアイコンを表示する。                                                                                                                                                                                                                                                        |
| 代替フロー    | 1a. 未ログイン状態の場合<br>1a-1. システムが自動保存を行わず、「保存」ボタンを表示する。<br>1a-2. 購入者が「保存」ボタンを選ぶ。<br>1a-3. システムがログイン画面を表示する。<br>1a-4. 購入者がログインする。<br>1a-5. システムが編集内容を保持したまま、以降は自動保存を有効にする。<br>1a-6. 基本フロー2へ進む。<br><br>1a-4a. ログインを取り消した場合<br>1a-4a-1. システムが保存せずに庭シミュレーション画面に戻り、編集内容と「保存」ボタンの表示を維持する。<br>1a-4a-2. ユースケースを終了する。<br><br>3a. 通信に失敗した場合<br>3a-1. システムが通信エラーを表示し、保存されていないことを伝える。<br>3a-2. システムが編集内容を保持したまま、再保存を可能にする。<br>3a-3. 基本フロー3へ戻る。 |
| 関連情報     | ・ログイン状態では自動保存、未ログイン状態では「保存」ボタンによる保存とする。<br>・未ログイン時の編集内容は保存されないため、画面を閉じると失われる。<br>・保存せず画面を閉じようとしたら「保存されていません」と警告メッセージを表示する。 |
