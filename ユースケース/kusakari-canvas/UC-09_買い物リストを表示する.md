#### UC-09 買い物リストを表示する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーション画面のサイドバーに、配置した庭オブジェクトに紐づく商品と、ECで買い物リストに追加した商品を表示し、必要に応じてECの買い物リストを開く。 |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 事後条件     | サイドバーに、庭の買い物リストの商品の一覧(商品画像、商品名、必要数、商品小計の目安)が表示されている。 |
| 基本フロー    | 1. システムが庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>2. システムが各庭オブジェクトに紐づく商品と、ECで買い物リストに追加された商品の情報をECから取得する。<br>3. システムが商品ごとに、商品画像、商品名、必要数、商品小計の目安(価格×必要数)をサイドバーの「買い物リスト」に一覧表示する。<br>4. 購入者が庭オブジェクトを設置・削除した場合、システムが買い物リストの必要数・小計を更新する。<br>5. 購入者が「ECで買い物リストを確認」を選ぶ。<br>6. システムが対象の庭プロジェクトを指定して、ECの買い物リスト(EC-B24)を開く。 |
| 代替フロー    | 1a. 配置されたオブジェクトもECで追加した商品もない場合<br>1a-1. システムが買い物リストが空であることを表示し、オブジェクトの配置(UC-05)を案内する。<br>1a-2. 基本フロー4へ進む。<br><br>2a. 紐づく商品が購入可能な商品でない場合(商品が存在しない、販売停止、選択中の店舗で扱っていないなど)<br>2a-1. システムがその商品を購入できないことを一覧上に表示し、小計の計算から除外する。<br>2a-2. 基本フロー3へ進む。<br><br>2b. ECで追加した商品を取得できない場合<br>2b-1. システムがエラーを表示し、再取得を可能にする。<br>2b-2. 基本フロー2へ戻る。<br><br>5a. 庭プロジェクトが保存中の場合<br>5a-1. システムが保存の完了を待ってから、ECの買い物リストを開く。<br>5a-2. 保存に失敗した場合は、ECの買い物リストを開かずにエラーを表示する。 |
| 関連情報     | ・庭オブジェクトと商品は1対1で紐づく。<br>・必要数は配置されている庭オブジェクトの個数とする。ECで追加した商品は、庭に配置していなければ「ECで追加（庭に未配置）」と表示し、必要数を1点とする。<br>・「ECカートを見る」を選ぶと、ECのカートを開く。<br>・Canvasの買い物リストからはカートへ追加できない(カート追加はEC側の買い物リスト(EC-B25)のみ)。<br>・価格・在庫の確定はEC側で行うため、Canvasの小計は目安として表示する。 |
