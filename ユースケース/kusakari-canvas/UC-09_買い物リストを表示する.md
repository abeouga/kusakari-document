#### UC-09 買い物リストを表示する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーション画面のサイドバーに、配置した庭オブジェクトに紐づく商品と、ECで買い物リストに追加した商品を表示し、必要に応じてECの買い物リストを開く。 |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 庭プロジェクトを開き(UC-C01)、庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 事後条件     | サイドバーに、庭の買い物リストの商品の一覧(商品画像、商品名、必要数、商品小計の目安)が表示されている。 |
| 基本フロー    | 1. 購入者がサイドバーの「買い物リスト（N）」タブをクリックする。<br>2. システムが庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>3. システムが各庭オブジェクトに紐づく商品と、ECで買い物リストに追加された商品の情報をECから取得する。<br>4. システムが「(庭の名前)の買い物リスト」に、商品ごとの商品画像、商品名、必要数、商品小計の目安(価格×必要数)を一覧表示する。<br>5. 購入者が庭オブジェクトを設置・削除する(UC-05)。<br>6. システムが買い物リストの必要数・小計を更新する。<br>7. 購入者が「ECで買い物リストを確認」ボタンをクリックする。<br>8. システムが対象の庭プロジェクトを指定して、ECのカート画面の「庭の買い物リスト」タブ(EC-B24)を開く。 |
| 代替フロー    | 3a. 紐づく商品が購入可能な商品でない場合(商品が存在しない、販売停止、選択中の店舗で扱っていないなど)<br>3a-1. システムがその商品の行に「この店舗の販売対象ではないため購入できません。保存済みの配置は維持されます。」と表示し、小計の計算から除外する。<br>3a-2. 基本フロー4へ進む。<br><br>3b. ECで追加した商品を取得できない場合<br>3b-1. システムが「ECで追加した商品を取得できません。」とエラーを表示し、「ECで追加した商品を再取得」ボタンを表示する。<br>3b-2. 購入者が「ECで追加した商品を再取得」ボタンをクリックすると、基本フロー3へ戻る。<br><br>4a. 配置されたオブジェクトもECで追加した商品もない場合<br>4a-1. システムが「庭に商品を配置するか、ECで買い物リストに追加すると、このリストに表示されます。」と表示し、オブジェクトの配置(UC-05)を案内する。<br>4a-2. 基本フロー5へ進む。<br><br>7a. 庭プロジェクトが保存中の場合<br>7a-1. システムが保存の完了を待ってから、ECの「庭の買い物リスト」タブを開く。<br>7a-2. 保存に失敗した場合は、ECの「庭の買い物リスト」タブを開かずにエラーを表示する。 |
| 関連情報     | ・庭オブジェクトと商品は1対1で紐づく。<br>・必要数は配置されている庭オブジェクトの個数とする。ECで追加した商品は、庭に配置していなければ「ECで追加（庭に未配置）」と表示し、必要数を1点とする。<br>・「ECカートを見る」ボタンをクリックすると、ECのカート画面を開く。<br>・Canvasの買い物リストからはカートへ追加できない(カート追加はEC側の買い物リスト(EC-B25)のみ)。<br>・価格・在庫の確定はEC側で行うため、Canvasの小計は目安として表示する。 |
