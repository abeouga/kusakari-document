#### UC-09 買い物リストを表示する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーション画面のサイドバーに、配置した庭オブジェクトに紐づく商品を買い物リストとして表示し、必要に応じてECの買い物リストを開く。                                                                                                                                                                                                                                                                                                                                                                               |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 事後条件     | サイドバーに、配置中の庭オブジェクトに紐づく商品の一覧(商品画像、商品名、数量、小計)が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                |
| 基本フロー    | 1. システムが庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>2. システムが各庭オブジェクトに紐づく商品の情報をECから取得する。<br>3. システムが商品ごとに、商品画像、商品名、数量(配置数)、小計(価格×数量)をサイドバーに一覧表示する。<br>4. 購入者が庭オブジェクトを設置・削除した場合、システムが買い物リストの数量・小計を更新する。<br>5. 購入者が「ECの買い物リストを開く」を選ぶ。<br>6. システムが対象の庭プロジェクトを指定して、ECの買い物リストを開く。                                                                                                                                                                                |
| 代替フロー    | 1a. 配置されたオブジェクトがない場合<br>1a-1. システムが買い物リストが空であることを表示し、オブジェクトの配置(UC-05)を案内する。<br>1a-2. 基本フロー4へ進む。<br><br>2a. 紐づく商品が購入可能な商品でない場合(商品が存在しない、販売停止、審査中など)<br>2a-1. システムがその商品を購入できないことを一覧上に表示し、小計の計算から除外する。<br>2a-2. 基本フロー3へ進む。<br><br>5a. 未ログインの場合<br>5a-1. システムがログインを促す。<br>5a-2. 購入者がログインする。<br>5a-3. 基本フロー5へ戻る。<br><br>5b. 庭プロジェクトが保存中の場合<br>5b-1. システムが「ECの買い物リストを開く」を選べないようにする。<br>5b-2. 自動保存が完了したら、システムが「ECの買い物リストを開く」を選べるようにする。<br>5b-3. 基本フロー5へ戻る。 |
| 関連情報     | ・庭オブジェクトと商品は1対1で紐づく。<br>・数量は配置されている庭オブジェクトの個数とする。<br>・Canvasの買い物リストからはカートへ追加できない(カート追加はEC側の買い物リストのみ)。<br>・未ログインからログインしたとき、まだ保存していない庭プロジェクトは保存される。                                                                                                                                                                                                                                                                                                   |
