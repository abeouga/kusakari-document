#### UC-02 庭の写真をアップロードする

| 記述項目     | 記述内容                                                                                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | シミュレーションの土台にするため、実際の庭の写真を1枚アップロードする。                                                                                                                                                                              |
| アクター     | 購入者                                                                                                                                                                                                          |
| 事前条件     | 庭プロジェクトが作成されている。<br>庭シミュレーション画面が表示されている。                                                                                                                                                                          |
| 事後条件     | 庭写真が庭プロジェクトに紐づいて登録され、庭シミュレーション画面に表示されている。                                                                                                                                                                         |
| 基本フロー    | 1. 購入者が庭シミュレーション画面で写真のアップロードを選ぶ。<br>2. 購入者が庭の写真を選択する。<br>3. システムが写真の形式・サイズを検証する。<br>4. システムが庭写真を庭プロジェクトに登録し、画面に表示する。<br>5. システムが施工範囲の指定を開始する。                                                                     |
| 代替フロー    | 3a. 写真の形式やサイズが不正な場合<br>3a-1. システムが対応形式・容量上限を示すエラーメッセージを表示し、登録しない。<br>3a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・登録できる庭写真は1プロジェクトにつき1枚とする。<br>・「写真を外す」ボタンをクリックすると写真が外れて、再度写真のアップロードが可能になる。<br>・写真を外すと施工範囲と実寸補正はリセットされるが、庭オブジェクトの配置情報は保存される。新しい施工範囲を確定したあと、範囲外になった庭オブジェクトには範囲外であることを表示する。<br>・対応形式・容量上限は別途定める(例: JPEG・PNG、10MB以下)。 |
