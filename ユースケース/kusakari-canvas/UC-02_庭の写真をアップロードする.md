#### UC-02 庭の写真をアップロードする

| 記述項目     | 記述内容                                                                                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | シミュレーションの土台にするため、実際の庭の写真を1枚アップロードする。                                                                                                                                                                              |
| アクター     | 購入者                                                                                                                                                                                                          |
| 事前条件     | 庭プロジェクトが作成されている。<br>庭シミュレーション画面が表示されている。                                                                                                                                                                          |
| 事後条件     | 庭写真が庭シミュレーション画面に表示され、施工範囲の指定(UC-03)が始まっている。 |
| 基本フロー    | 1. 購入者が庭シミュレーション画面で「庭の写真を選択」を選ぶ(または写真を画面にドラッグ＆ドロップする)。<br>2. 購入者が庭の写真を選択する。<br>3. システムが写真の形式・サイズを検証する。<br>4. システムが庭写真を画面に表示する。<br>5. システムが施工範囲の指定(UC-03)を開始する。 |
| 代替フロー    | 3a. 写真の形式やサイズが不正な場合<br>3a-1. システムが対応形式・容量上限を示すエラーメッセージを表示し、写真を表示しない。<br>3a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・登録できる庭写真は1プロジェクトにつき1枚とする。<br>・対応形式はJPEG・PNG、容量は5MB以下、大きさは縦横それぞれ6000ピクセル以下とする。<br>・庭写真は、施工範囲を確定したときに庭プロジェクトと一緒に保存される(UC-07)。施工範囲を確定する前に画面を閉じると、写真は保存されない。<br>・「写真を変更」を選ぶと、別の写真に差し替えられる。<br>・「写真を外す」を選ぶと写真が外れて、再度写真のアップロードが可能になる。<br>・写真を外したり差し替えたりすると施工範囲と実寸補正はリセットされるが、庭オブジェクトの配置は残る。新しい施工範囲を確定したあと、範囲外になった庭オブジェクトには範囲外であることを表示する。範囲外の庭オブジェクトを移動または削除するまで、庭プロジェクトは保存されない。 |
