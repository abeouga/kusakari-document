# UC-02 庭の写真をアップロードし、施工範囲の実寸を補正する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 実際の庭の写真を1枚アップロードし、施工範囲の辺の長さを入力して、シミュレーション上の実寸を補正する。                                                                                                                                                                                                               |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                          |
| 事前条件     | 庭プロジェクトが作成されている。庭シミュレーション画面が表示されている。                                                                                                                                                                                                                              |
| 事後条件     | 庭写真と実寸補正の情報が庭プロジェクトに紐づいて保存される。                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 利用者が庭シミュレーション画面で庭の写真を選択してアップロードする。<br>2. システムが写真の形式・サイズを検証し、庭プロジェクトに登録して表示する。<br>形式やサイズが不正な場合は => 代替フロー1へ<br>通信に失敗した場合は => 代替フロー3へ<br>3. 利用者が施工範囲の辺を指定する。<br>4. 利用者がその辺の実際の長さを入力する。<br>5. システムが入力値を検証し、写真の実寸を算出して保存する。<br>長さが無効な場合は => 代替フロー2へ                 |
| 代替フロー    | 1. 写真の形式やサイズが不正な場合<br>1-1. システムが対応形式・容量上限を示すエラーメッセージを表示し、登録しない。<br><br>2. 長さが無効な場合(0以下、数値以外)<br>2-1. システムが入力エラーメッセージを表示し、再入力を求める。<br><br>3. 通信に失敗した場合<br>3-1. システムが通信エラーを表示し、再実行を可能にする。<br><br>4. 利用者が実寸補正を行わない場合<br>4-1. システムが補正なし(標準縮尺)で進めることを確認し、補正未設定として保存する。 |
| 関連情報     | 補正未設定の場合は、庭オブジェクトの大きさが実寸と合わない可能性がある。                                                                                                                                                                                                                              |
