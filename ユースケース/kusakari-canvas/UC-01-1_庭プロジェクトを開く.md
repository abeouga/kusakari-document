#### UC-01-1 庭プロジェクトを開く

| 記述項目     | 記述内容                                                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 保存した庭プロジェクトを選び、庭シミュレーション画面で開く。                                                                                                                                            |
| アクター     | 購入者                                                                                                                                                                       |
| 事前条件     | ログイン状態である。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。<br>庭プロジェクトが作成されている。                                                                                                         |
| 事後条件     | 選んだ庭プロジェクトの庭シミュレーション画面が表示されている。                                                                                                                                           |
| 基本フロー    | 1. 購入者が共通ヘッダーの「Canvas」リンクをクリックする。<br>2. システムが「庭プロジェクト一覧」画面の「保存した庭」に、購入者の庭プロジェクトを一覧表示する。<br>3. 購入者が開きたい庭プロジェクトのカードをクリックする。<br>4. システムが選択した庭プロジェクトを読み込み、「庭シミュレーション」画面を表示する。 |
| 代替フロー    | 2a. 庭プロジェクトがない場合<br>2a-1. システムが「保存した庭はまだありません。上のフォームから最初の庭を作成できます。」と表示する。<br>2a-2. 購入者が庭プロジェクトを新規作成する。                                                                    |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・庭プロジェクトを新規作成した直後は、システムが作成した庭シミュレーション画面を表示するため、この操作は不要である。<br>・庭プロジェクトの複製・削除は「庭プロジェクトを管理する」ユースケースで行う。                                               |
