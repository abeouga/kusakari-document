#### UC-05 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 事前条件     | 庭プロジェクトを開き(UC-C01)、庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 基本フロー    | 1. 購入者がサイドバーの「商品一覧」タブで、設置したい商品の「庭に配置」ボタンをクリックする。<br>2. 購入者が庭写真上(写真がない場合は3D表示の土台上)の設置したい位置をクリックする。<br>3. システムが庭オブジェクトを庭シミュレーションに表示し、「配置したもの」一覧に追加する。<br>4. 購入者が設置済みの庭オブジェクト(または「配置したもの」一覧の行)をクリックして選択する。<br>5. 購入者が移動・回転・拡大縮小・複製のいずれかを行う(移動は庭オブジェクトをドラッグする。3D表示では「回転」「拡縮」ボタンをクリックしてハンドルをドラッグする。数値で調整する場合は「詳細」をクリックし、「X座標 (m)」「Z座標 (m)」「Y回転 (度)」「倍率 (一様)」欄に入力する。複製は「詳細」をクリックして「複製」ボタンをクリックする)。<br>6. システムが操作結果を庭シミュレーションに反映する。<br>7. 購入者が不要な庭オブジェクトをクリックして選択する。<br>8. 購入者が「詳細」をクリックする。<br>9. システムが選択した庭オブジェクトの詳細を表示する。<br>10. 購入者が「削除」ボタンをクリックする。<br>11. システムが庭オブジェクトを庭シミュレーションから取り除く。 |
| 代替フロー    | 1a. 商品をドラッグして設置する場合<br>1a-1. 購入者が「商品一覧」タブの商品を、庭写真上(写真がない場合は3D表示の土台上)の設置したい位置へドラッグ＆ドロップする。<br>1a-2. 基本フロー3へ進む。<br><br>2a. 施工範囲の外に設置しようとした場合<br>2a-1. システムが設置を反映せず、範囲内への配置を促す(ドロップした場合は「庭の地面の範囲内へドロップしてください。」と表示する)。<br>2a-2. 基本フロー2へ戻る。<br><br>5a. ドラッグで施工範囲の外へ移動しようとした場合<br>5a-1. システムが範囲内で最後にあった位置に庭オブジェクトをとどめ、「施工範囲の外へは移動できません。」と表示する。<br>5a-2. 基本フロー5へ戻る。<br><br>5b. 「詳細」の入力欄に位置・向き・大きさを数値で入力し、上限・下限を超えた場合<br>5b-1. システムがエラーメッセージ(「庭の範囲、回転軸、拡大縮小の制限内で入力してください。」)を表示し、入力を反映しない。<br>5b-2. 基本フロー5へ戻る。<br><br>5c. 3D表示で「拡縮」のハンドルをドラッグし、上限・下限に達した場合<br>5c-1. システムが上限・下限の大きさで止めて反映する。<br>5c-2. 基本フロー6へ進む。<br><br>5d. 配置数が上限に達している場合(設置・複製)<br>5d-1. システムが上限に達したことを表示し(設置では「配置数の上限に達したか、配置位置が範囲外です。」と表示し、複製では「複製」ボタンを押せない状態にする)、設置しない。<br>5d-2. 基本フロー4へ戻る。 |
| 関連情報     | ・商品と庭オブジェクトは1対1で紐づいている。<br>・庭オブジェクトは3Dモデルとして庭写真の上に配置する。<br>・1つの庭プロジェクトに設置できる庭オブジェクトは200個までとする。<br>・回転・拡大縮小で庭オブジェクトの一部が施工範囲の外に出ても、設置位置が範囲内であれば許可する。                                                                                                                                                                                                                                                                                                                                             |
