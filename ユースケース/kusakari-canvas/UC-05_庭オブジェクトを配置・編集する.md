#### UC-05 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                                                                   |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                        |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>庭写真がアップロードされ、施工範囲が設定されている。                                                                                                                                                                                                                                                                                                              |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映されている。                                                                                                                                                                                                                                                                                                                        |
| 基本フロー    | 1. 購入者が設置したい商品を選ぶ。<br>2. 購入者が庭写真上の位置を指定して設置する。<br>3. システムが庭オブジェクトを庭シミュレーションに表示する。<br>4. 購入者が設置済みオブジェクトを選び、移動・回転・拡大縮小のいずれかを行う。<br>5. システムが操作結果を庭シミュレーションに反映する。<br>6. 購入者が不要なオブジェクトを選び、削除する。<br>7. システムが庭オブジェクトを庭シミュレーションから取り除く。                                                                                                                                  |
| 代替フロー    | 2a. 施工範囲の外に設置した場合<br>2a-1. システムが範囲外であることを表示して設置を反映せず、範囲内への配置を促す。<br>2a-2. 基本フロー2へ戻る。<br><br>4a. 施工範囲の外への移動や、上限・下限を超える移動・拡大縮小をした場合<br>4a-1. ドラッグで施工範囲の外に移動した場合は、システムが範囲外であることを表示して移動を反映せず、範囲内への配置を促す。<br>4a-2. ボタン操作で上限・下限を超える場合は、システムが上限・下限の位置・大きさに制限して反映する。<br>4a-3. 基本フロー4へ戻る。 |
| 関連情報     | ・商品と似たモデル(庭オブジェクト)が庭シミュレーション上に設置される。<br>・商品と庭オブジェクトは1対1で紐づいている。<br>・庭オブジェクトは3Dモデルとして庭写真の上に配置する。<br>・庭写真を取り除き、施工範囲部分の3D土台だけを表示するタブがある。<br>・設置できる商品は、購入可能な商品だけとする。<br>・回転・拡大縮小で庭オブジェクトの一部が施工範囲の外に出ても、中心位置(基準位置)が範囲内であれば許可する。 |
