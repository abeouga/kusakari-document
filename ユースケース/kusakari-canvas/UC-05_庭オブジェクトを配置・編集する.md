#### UC-05 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 事前条件     | 庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 基本フロー    | 1. 購入者が商品一覧から設置したい商品を選ぶ。<br>2. 購入者が庭写真上(写真がない場合は3D表示の土台上)の位置を指定して設置する。<br>3. システムが庭オブジェクトを庭シミュレーションに表示する。<br>4. 購入者が設置済みオブジェクトを選び、移動・回転・拡大縮小・複製のいずれかを行う。<br>5. システムが操作結果を庭シミュレーションに反映する。<br>6. 購入者が不要なオブジェクトを選び、削除する。<br>7. システムが庭オブジェクトを庭シミュレーションから取り除く。                                                                                                                                                                                                                                      |
| 代替フロー    | 2a. 施工範囲の外に設置した場合<br>2a-1. システムが範囲外であることを表示して設置を反映せず、範囲内への配置を促す。<br>2a-2. 基本フロー2へ戻る。<br><br>4a. ドラッグで施工範囲の外へ移動しようとした場合<br>4a-1. システムが範囲内で最後にあった位置に庭オブジェクトをとどめ、範囲外であることを表示する。<br>4a-2. 基本フロー4へ戻る。<br><br>4b. 位置・向き・大きさを数値で入力し、上限・下限を超えた場合<br>4b-1. システムが入力できる範囲を示すエラーメッセージを表示し、入力を反映しない。<br>4b-2. 基本フロー4へ戻る。<br><br>4c. 3D表示で拡大縮小をドラッグし、上限・下限に達した場合<br>4c-1. システムが上限・下限の大きさで止めて反映する。<br>4c-2. 基本フロー5へ進む。<br><br>4d. 配置数が上限に達している場合(設置・複製)<br>4d-1. システムが上限に達したことを表示し、設置しない。<br>4d-2. 基本フロー4へ戻る。 |
| 関連情報     | ・商品と庭オブジェクトは1対1で紐づいている。<br>・庭オブジェクトは3Dモデルとして庭写真の上に配置する。<br>・1つの庭プロジェクトに設置できる庭オブジェクトは200個までとする。<br>・回転・拡大縮小で庭オブジェクトの一部が施工範囲の外に出ても、設置位置が範囲内であれば許可する。                                                                                                                                                                                                                                                                                                                                             |
