# UC-06 庭プロジェクトを保存する

| 記述項目     | 記述内容                                                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭オブジェクトの位置・個数・商品の情報を庭プロジェクトとして保存する。                                                                                                                                        |
| アクター     | 利用者(購入者)                                                                                                                                                                   |
| 事前条件     | 庭シミュレーション画面が開かれている                                                                                                                                                         |
| 事後条件     | 庭オブジェクトの位置・個数・商品の情報が保存され、次回以降に再開できる。                                                                                                                                       |
| 基本フロー    | 1. 利用者が庭プロジェクトの保存を選ぶ。<br>保存済みの内容から変更がない場合 -> 代替フロー1へ<br>2. システムが庭オブジェクトの位置・個数・商品の情報を取得する。<br>3. システムが取得した内容を庭プロジェクトとして保存する。<br>通信に失敗した場合は => 代替フロー2へ<br>4. システムが保存完了を表示する。 |
| 代替フロー    | 1. 保存済みの内容から変更がない場合<br>1-1. 保存ボタンを無効化する<br><br>2. 通信に失敗した場合<br>2-1. システムが通信エラーを表示し、保存されていないことを伝える。<br>2-2. システムが編集内容を保持したまま、再保存を可能にする。                                     |
