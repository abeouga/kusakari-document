#### UC-06 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた画像(生成前)をもとに、AIで完成イメージ画像を生成して確認・保存する。                                                                                                                                                                                                                                                                                                                                                                 |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | 庭プロジェクトを開き(UC-C01)、庭シミュレーション画面が表示されている。<br>庭写真がアップロードされ、施工範囲が設定されている。<br>表示モードが「写真」になっている。 |
| 事後条件     | 完成イメージ画像が生成履歴に保存され、購入者が確認・端末への保存をできる状態になっている。                                                                                                                                                                                                                                                                                                                                                                             |
| 基本フロー    | 1. 購入者が庭シミュレーション画面の「AI生成」ボタンをクリックする。<br>2. システムが「完成イメージ」メニューを表示する。<br>3. 購入者が「新しく作成」をクリックする。<br>4. システムが「庭の完成イメージ」ダイアログを開き、元の庭写真に庭オブジェクトを重ねた画像を「生成前」として表示する。<br>5. 購入者が「AIで生成」ボタンをクリックする。<br>6. システムが「完成イメージを生成中…」と表示し、生成前の画像をもとに完成イメージ画像を生成する。<br>7. システムが生成した完成イメージ画像を表示し、生成履歴に保存して「履歴に保存済み」と表示する。<br>8. 購入者が必要に応じて「画像を保存」ボタンをクリックする。<br>9. システムが完成イメージ画像をPNG形式で端末に保存(ダウンロード)する。 |
| 代替フロー    | 4a. 植物が配置されていない場合<br>4a-1. システムが「植物を配置すると生成できます。」と表示し、「AIで生成」ボタンを押せない状態にする。<br>4a-2. ユースケースを終了する。<br><br>6a. 生成に失敗した場合<br>6a-1. システムがエラー(「AI画像を生成できませんでした。接続状態を確認し、手動で再試行してください。」など)を表示し、「AIで生成」ボタンを再び押せる状態にする。<br>6a-2. 基本フロー5へ戻る。<br><br>7a. 生成はできたが生成履歴への保存に失敗した場合<br>7a-1. システムが生成した画像を表示したまま、「画像は生成済みですが、履歴への保存に失敗しました。画像は保持しています。」と表示する。<br>7a-2. 購入者が「履歴へ再保存」ボタンか「画像を保存」ボタンをクリックする。<br>7a-3. 基本フロー8へ進む。<br><br>8a. 生成履歴に保存されていない画像を閉じようとした場合<br>8a-1. 購入者が「庭の完成イメージ」ダイアログの「閉じる」ボタンをクリックする。<br>8a-2. システムが「未保存の画像を破棄して閉じますか？」ダイアログを表示し、閉じると画像を失うことを確認する。<br>8a-3. 購入者が「破棄して閉じる」ボタンをクリックすると画像を閉じ、「画像を保持する」ボタンをクリックすると画像の表示に戻る。 |
| 関連情報     | ・「完成イメージ」メニューの「生成履歴」から、以前に生成した完成イメージ画像を確認(「比較する」)・保存(「Afterを保存」)・削除(「この履歴を削除」)できる。<br>・「詳細」の「Before画像をPNGで保存」から、生成前の画像だけをPNG形式で保存することもできる。<br>・「履歴へ再保存」では、画像を生成し直さない。 |
