#### UC-06 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた画像(生成前)をもとに、AIで完成イメージ画像を生成して確認・保存する。 |
| アクター     | 購入者 |
| 事前条件     | 庭プロジェクトを開き、庭シミュレーション画面が表示されている。<br>庭写真がアップロードされ、施工範囲が設定されている。<br>表示モードが「写真」になっている。 |
| 事後条件     | 完成イメージ画像が生成履歴に保存され、購入者が確認・端末への保存をできる状態になっている。 |
| 基本フロー    | 1. 購入者が庭シミュレーション画面の「AI生成」ボタンをクリックする。<br>2. システムが「完成イメージ」メニュー(「新しく作成」「生成履歴」)を表示する。<br>3. 購入者が「新しく作成」をクリックする。<br>4. システムが「庭の完成イメージ」ダイアログを開き、元の庭写真に庭オブジェクトを重ねた画像を「生成前」として表示する。<br>5. システムが、配置した植物に紐づく商品の登録画像を参考画像として取得する。登録画像を生成に使えない植物があれば、その植物の「参考写真」欄を表示する。<br>6. 購入者が「参考写真」欄の「写真を選択」から植物の参考写真(PNG/JPEG/WebP)を追加する。参考写真が必要な植物がなければ、このステップは省く。<br>7. 購入者が「AIで生成」ボタンをクリックする。<br>8. システムが「完成イメージを生成中…」と表示し、生成前の画像・施工範囲・植物の参考画像をもとに完成イメージ画像を生成する。<br>9. システムが生成前と生成後(After)を比べられる画像を表示し、生成履歴に保存して「履歴に保存済み」と表示する。<br>10. 購入者が必要に応じて「画像を保存」ボタンをクリックする。<br>11. システムが完成イメージ画像(After)をPNG形式で端末に保存(ダウンロード)する。 |
| 代替フロー    | 4a. 画像の作成に失敗した場合<br>4a-1. システムがエラー(「庭の写真を読み込めませんでした。写真を選び直してください。」など)を表示し、ダイアログを開かない。<br>4a-2. ユースケースを終了する。<br><br>5a. 植物が配置されていない場合<br>5a-1. システムが「植物を配置すると生成できます。」と表示し、「AIで生成」ボタンを押せない状態にする。<br>5a-2. ユースケースを終了する。<br><br>5b. 商品に紐づいていない旧モデルがある場合<br>5b-1. システムが「商品に紐づいていない旧モデル（植物名）があります。商品一覧から配置し直してください。」と表示し、「AIで生成」ボタンを押せない状態にする。<br>5b-2. ユースケースを終了する。<br><br>5c. 入力画像が16枚を超える場合<br>5c-1. システムが「画像が16枚を超えています。配置を減らしてください。」と表示し、「AIで生成」ボタンを押せない状態にする。<br>5c-2. ユースケースを終了する。<br><br>5d. 植物の参考画像の取得に失敗した場合<br>5d-1. システムが「植物の参考画像を取得できませんでした。」と表示し、「AIで生成」ボタンを押せない状態にする。<br>5d-2. 購入者が「登録画像を再取得」ボタンをクリックする。<br>5d-3. 基本フロー5へ戻る。<br><br>6a. 選んだ参考写真が使えない場合(形式・容量・画素数が条件外の場合)<br>6a-1. システムがエラー(「参考写真はPNG/JPEG/WebPで選択してください。SVGは使用できません。」など)を表示し、写真を追加しない。<br>6a-2. 基本フロー6へ戻る。<br><br>7a. 参考写真が必要な植物に写真を追加していない場合<br>7a-1. システムが「(植物名)：登録画像を生成に使用できません。PNG/JPEG/WebPの参考写真を追加してください。」と表示し、生成しない。<br>7a-2. 基本フロー6へ戻る。<br><br>8a. 生成に失敗した場合<br>8a-1. システムがエラー(「AI画像を生成できませんでした。接続状態を確認し、手動で再試行してください。」など)を表示し、「AIで生成」ボタンを再び押せる状態にする。<br>8a-2. 基本フロー7へ戻る。<br><br>9a. 生成はできたが、生成履歴への保存に失敗した場合<br>9a-1. システムが生成した画像を表示したまま、「画像は生成済みですが、履歴への保存に失敗しました。画像は保持しています。」と表示する。<br>9a-2. 購入者が「履歴へ再保存」「画像を保存」「未保存の画像を破棄」のいずれかのボタンをクリックする。<br>9a-3. 「履歴へ再保存」が成功すると、システムが「履歴に保存済み」と表示し、基本フロー10へ進む。「画像を保存」の場合は基本フロー11へ進む。「未保存の画像を破棄」の場合は、システムが確認ダイアログを表示する。購入者が「破棄する」をクリックすると生成前の画像の表示に戻り、「画像を保持する」をクリックすると画像の表示に戻る。<br><br>10a. 生成履歴に保存されていない画像を閉じようとした場合<br>10a-1. 購入者が「庭の完成イメージ」ダイアログの「閉じる」ボタンをクリックする。<br>10a-2. システムが「未保存の画像を破棄して閉じますか？」ダイアログを表示し、閉じると画像を失うことを確認する。<br>10a-3. 購入者が「破棄して閉じる」ボタンをクリックすると画像を閉じ、「画像を保持する」ボタンをクリックすると画像の表示に戻る。 |
| 関連情報     | ・「完成イメージ」メニューの「生成履歴」から、以前に生成した完成イメージ画像を確認(「比較する」)・保存(「Afterを保存」)・削除(「この履歴を削除」)できる。<br>・「詳細」の「Before画像をPNGで保存」から、生成前の画像だけをPNG形式で保存することもできる。<br>・生成後にもう一度「AIで生成」をクリックすると別の仕上がりを生成し、新しい履歴として保存する。<br>・「履歴へ再保存」では画像を生成し直さない(生成料金はかからない)。<br>・生成履歴に保存されていない画像がある間は、ページを離れようとするとブラウザーが確認を表示する。<br>・表示モードが「写真」でない場合、ボタンは「完成イメージ」になる。この場合はAI生成を行わず、3Dプレビューの画像をPNGで保存できる。 |
