#### UC-06 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた画像(生成前)をもとに、AIで完成イメージ画像を生成して確認・保存する。 |
| アクター     | 購入者                                                                                                                                                                          |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>庭写真がアップロードされ、施工範囲が設定されている。 |
| 事後条件     | 完成イメージ画像が生成履歴に保存され、購入者が確認・端末への保存をできる状態になっている。 |
| 基本フロー    | 1. 購入者が完成イメージの確認を選ぶ。<br>2. システムが元の庭写真に庭オブジェクトを重ねた画像を「生成前」として表示する。<br>3. 購入者が「AIで生成」を選ぶ。<br>4. システムが生成前の画像をもとに完成イメージ画像を生成して表示し、生成履歴に保存する。<br>5. 購入者が必要に応じて「画像を保存」を選び、完成イメージ画像をPNG形式で端末に保存(ダウンロード)する。 |
| 代替フロー    | 3a. 植物が配置されていない場合<br>3a-1. システムが「植物を配置すると生成できます」と表示し、生成できない状態にする。<br>3a-2. ユースケースを終了する。<br><br>4a. 生成に失敗した場合<br>4a-1. システムがエラーを表示し、再生成を可能にする。<br>4a-2. 基本フロー3へ戻る。<br><br>4b. 生成はできたが生成履歴への保存に失敗した場合<br>4b-1. システムが生成した画像を表示したまま、生成履歴に保存されていないことを伝える。<br>4b-2. 購入者が生成履歴への再保存か「画像を保存」を選ぶ。<br>4b-3. 基本フロー5へ進む。<br><br>5a. 生成履歴に保存されていない画像を閉じようとした場合<br>5a-1. システムが、閉じると画像を失うことを確認する。<br>5a-2. 購入者が破棄を選ぶと画像を閉じ、取り消すと画像の表示に戻る。 |
| 関連情報     | ・「生成履歴」から、以前に生成した完成イメージ画像を確認・保存・削除できる。<br>・生成前の画像だけをPNG形式で保存することもできる。<br>・生成履歴への再保存では、画像を生成し直さない。 |
