#### UC-06 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた、完成イメージ画像を生成して確認・保存する。                                                                                                                                       |
| アクター     | 購入者                                                                                                                                                                          |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>庭オブジェクトが1つ以上配置されている。                                                                                                                                      |
| 事後条件     | 完成イメージ画像が生成され、購入者が確認・保存できる状態になっている。                                                                                                                                               |
| 基本フロー    | 1. 購入者が完成イメージの確認を選ぶ。<br>2. システムが配置情報(位置・向き・大きさ)を取得する。<br>3. システムが元の庭写真に庭オブジェクトを重ねて画像を生成する。<br>4. システムが完成イメージ画像を表示する。<br>5. 購入者が必要に応じて「PNGで保存」を選び、完成イメージ画像をPNG形式で端末に保存(ダウンロード)する。  |
| 代替フロー    | 3a. 生成に失敗した場合(処理エラー、通信失敗)<br>3a-1. システムがエラーを表示し、再生成を可能にする。<br>3a-2. 基本フロー3へ戻る。<br><br>5a. 保存に失敗した場合(ダウンロードできない、容量不足など)<br>5a-1. システムが保存に失敗したことを表示し、再実行を可能にする。<br>5a-2. 基本フロー5へ戻る。 |
