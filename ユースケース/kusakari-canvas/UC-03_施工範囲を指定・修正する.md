#### UC-03 施工範囲を指定・修正する

| 記述項目     | 記述内容                                                                                                                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭写真上で施工したい範囲を線で結んで指定し、必要に応じて修正する。                                                                                                                                                                                                           |
| アクター     | 購入者                                                                                                                                                                                                                                    |
| 事前条件     | 庭シミュレーション画面が表示されている。<br>庭写真がアップロードされている。                                                                                                                                                                                                    |
| 事後条件     | 施工範囲が庭プロジェクトに保存されている。                                                                                                                                                                                                                       |
| 基本フロー    | 1. 庭写真のアップロード後に、システムが施工範囲の指定を始める(または、購入者が施工範囲の指定を選ぶ)。<br>2. 購入者が庭写真上の点を順に指定し、線で結ぶ。<br>3. 購入者が範囲を閉じて確定する。<br>4. システムが範囲の形状を検証し、施工範囲として保存する。<br>5. システムが実寸の定義を案内する。<br>6. 購入者が範囲を修正したい場合、点を移動するか、「施工範囲を指定し直す」を選ぶ。<br>7. システムが修正後の範囲を検証し、更新する。 |
| 代替フロー    | 4a. 範囲が成立しない場合(点が3つ未満、線が交差するなど)<br>4a-1. システムがエラーメッセージを表示し、確定させない。<br>4a-2. 基本フロー2へ戻る。<br><br>7a. 修正後の範囲が成立しない場合(点が3つ未満、線が交差するなど)<br>7a-1. システムがエラーメッセージを表示し、修正を反映しない。<br>7a-2. 基本フロー6へ戻る。 |
