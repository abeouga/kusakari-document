# UC-05 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた、完成イメージ画像を生成して確認・保存する。                                                                                                                                                                             |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                |
| 事前条件     | 庭シミュレーション画面が表示されている。庭オブジェクトが1つ以上配置されている。                                                                                                                                                                                |
| 事後条件     | 完成イメージ画像が生成され、利用者が確認・保存できる状態になる。                                                                                                                                                                                        |
| 基本フロー    | 1. 利用者が完成イメージの確認を選ぶ。<br>2. システムが配置情報(位置・向き・大きさ)を取得する。<br>3. システムが元の庭写真に庭オブジェクトを重ねて画像を生成する。<br>生成に失敗した場合は => 代替フロー1へ<br>4. システムが完成イメージ画像を表示する。<br>5. 利用者が必要に応じて、PNGで保存を選んで、完成イメージ画像をPNG形式で保存する。<br>保存に失敗した場合は -> 代替フロー2へ |
| 代替フロー    | 1. 生成に失敗した場合(処理エラー、通信失敗)<br>1-1. システムがエラーを表示し、再生成を可能にする。<br><br>2. 保存に失敗した場合(通信失敗)<br>2-1. システムが通信エラーを表示し、再実行を可能にする。                                                                                                    |
