#### UC-01 庭プロジェクトを新規作成する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーションを始めるために、新しい庭プロジェクトを作成する。                                                                                                                                                                                                                                            |
| アクター     | 購入者                                                                                                                                                                                                                                                                          |
| 事前条件     | ログイン状態である。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。                                                                                                                                                                                                                                |
| 事後条件     | 新しい庭プロジェクトが作成され、庭シミュレーション画面が表示されている。                                                                                                                                                                                                                                         |
| 基本フロー    | 1. 購入者が共通ヘッダーの「Canvas」リンクをクリックする。<br>2. システムが「庭プロジェクト一覧」画面を表示する。<br>3. 購入者が「新しい庭をつくる」フォームの「庭の名前」欄に庭プロジェクト名を入力する。<br>4. システムが入力された名前を検証し、「庭を作成」ボタンを押せる状態にする。<br>5. 購入者が「庭を作成」ボタンをクリックする。<br>6. システムが「庭を作成しています…」と表示し、庭プロジェクトを作成する。<br>7. システムが作成した庭プロジェクトの「庭シミュレーション」画面を表示する。 |
| 代替フロー    | 4a. 庭プロジェクト名が空の場合<br>4a-1. システムが「庭を作成」ボタンを押せない状態にする。<br>4a-2. 基本フロー3へ戻る。<br><br>6a. 作成できなかった場合<br>6a-1. システムが「新しい庭をつくる」フォームにエラーメッセージ(「庭を作成できませんでした。」など)を表示し、入力した名前を残したままプロジェクトを作成しない。<br>6a-2. 基本フロー3へ戻る。                                                                    |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・「庭の名前」欄は60文字までとし、それを超える文字は入力できない。<br>・庭プロジェクトは作成した購入者だけが「庭プロジェクト一覧」画面で確認・編集できる。                                                                                                                                                                       |
