#### UC-01 庭プロジェクトを新規作成する

| 記述項目     | 記述内容                                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーションを始めるために、新しい庭プロジェクトを作成する。                                                                                                                                   |
| アクター     | 購入者                                                                                                                                                                 |
| 事前条件     | ログイン状態である。<br>庭プロジェクト一覧画面が表示されている。                                                                                                                                  |
| 事後条件     | 新しい庭プロジェクトが作成され、庭シミュレーション画面が表示されている。                                                                                                                                |
| 基本フロー    | 1. 購入者が庭プロジェクト一覧画面で庭プロジェクトの新規作成を選ぶ。<br>2. 購入者が庭プロジェクト名を入力する。<br>3. システムが入力内容を検証し、庭プロジェクトを作成する。<br>4. システムが作成した庭シミュレーション画面を表示する。                                     |
| 代替フロー    | 2a. 庭プロジェクト名が空の場合<br>2a-1. システムが作成ボタンを押せない状態にする。<br>2a-2. 基本フロー2へ戻る。<br><br>3a. 作成できなかった場合<br>3a-1. システムがエラーメッセージを表示し、入力した名前を残したままプロジェクトを作成しない。<br>3a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・庭プロジェクト名は60文字までとし、それを超える文字は入力できない。<br>・庭プロジェクトは作成した購入者だけが一覧で確認・編集できる。                                                                        |
