#### UC-01 庭プロジェクトを新規作成する

| 記述項目     | 記述内容                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭シミュレーションを始めるために、新しい庭プロジェクトを作成する。                                                                                                                                                 |
| アクター     | 利用者(購入者)                                                                                                                                                                          |
| 事前条件     | 庭プロジェクト一覧画面が表示されている。                                                                                                                                                              |
| 事後条件     | 新しい庭プロジェクトが作成され、庭一覧に表示される。                                                                                                                                                        |
| 基本フロー    | 1. 利用者が庭プロジェクト一覧画面で庭プロジェクトの新規作成を選ぶ。<br>2. 利用者が庭プロジェクト名を入力する。<br>3. システムが入力内容を検証し、庭プロジェクトを作成する。<br>入力内容が無効の場合は => 代替フロー1へ<br>通信に失敗した場合は => 代替フロー2へ<br>4. システムが作成した庭シミュレーション画面を表示する |
| 代替フロー    | 1. 入力内容が無効の場合(名前が空、文字数超過など)<br>1-1. システムが入力エラーメッセージを表示し、プロジェクトを作成しない。<br><br>2. 通信に失敗した場合<br>2-1. システムが通信エラーを表示し、再実行を可能にする。                                                       |
| 関連情報     | 作成した庭プロジェクトを保存するときはログイン必須。                                                                                                                                                        |

#### UC-02 庭の写真をアップロードし、施工範囲の実寸を補正する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 実際の庭の写真を1枚アップロードし、施工範囲の辺の長さを入力して、シミュレーション上の実寸を補正する。                                                                                                                                                                                                               |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                          |
| 事前条件     | 庭プロジェクトが作成されている。庭シミュレーション画面が表示されている。                                                                                                                                                                                                                              |
| 事後条件     | 庭写真と実寸補正の情報が庭プロジェクトに紐づいて保存される。                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 利用者が庭シミュレーション画面で庭の写真を選択してアップロードする。<br>2. システムが写真の形式・サイズを検証し、庭プロジェクトに登録して表示する。<br>形式やサイズが不正な場合は => 代替フロー1へ<br>通信に失敗した場合は => 代替フロー3へ<br>3. 利用者が施工範囲の辺を指定する。<br>4. 利用者がその辺の実際の長さを入力する。<br>5. システムが入力値を検証し、写真の実寸を算出して保存する。<br>長さが無効な場合は => 代替フロー2へ                 |
| 代替フロー    | 1. 写真の形式やサイズが不正な場合<br>1-1. システムが対応形式・容量上限を示すエラーメッセージを表示し、登録しない。<br><br>2. 長さが無効な場合(0以下、数値以外)<br>2-1. システムが入力エラーメッセージを表示し、再入力を求める。<br><br>3. 通信に失敗した場合<br>3-1. システムが通信エラーを表示し、再実行を可能にする。<br><br>4. 利用者が実寸補正を行わない場合<br>4-1. システムが補正なし(標準縮尺)で進めることを確認し、補正未設定として保存する。 |
| 関連情報     | 補正未設定の場合は、庭オブジェクトの大きさが実寸と合わない可能性がある。                                                                                                                                                                                                                              |

#### UC-03 施工範囲を指定・修正する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭写真上で施工したい範囲を線で結んで指定し、必要に応じて修正する。                                                                                                                                                                                                                                     |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                              |
| 事前条件     | 庭シミュレーション画面が表示されている。庭写真がアップロードされている。                                                                                                                                                                                                                                  |
| 事後条件     | 施工範囲が庭プロジェクトに保存される。                                                                                                                                                                                                                                                   |
| 基本フロー    | 1. 利用者が庭写真をアップロード後、システムが施工範囲の指定を始める。（または、施工範囲の指定を選ぶ。）<br>2. 利用者が庭写真上の点を順に指定し、線で結ぶ。<br>3. 利用者が範囲を閉じて確定する。<br>4. システムが範囲の形状を検証し、施工範囲として保存する。<br>範囲が成立しない場合は => 代替フロー1へ<br>通信に失敗した場合は => 代替フロー3へ<br>5. 利用者が範囲を修正したい場合、点を移動または、施工範囲を指定し直すを選ぶ。<br>6. システムが修正後の範囲を検証し、更新する。 |
| 代替フロー    | 1. 範囲が成立しない場合(点が3つ未満、線が交差するなど)<br>1-1. システムがエラーメッセージを表示し、確定させない。<br><br>2. 実寸補正が未設定の場合<br>2-1. システムが面積が概算になることを表示し、指定を続行できるようにする。<br><br>3. 通信に失敗した場合<br>3-1. システムが通信エラーを表示し、再実行を可能にする。                                                                               |
| 関連情報     |                                                                                                                                                                                                                                                                       |

#### UC-04 庭オブジェクトを配置・編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 植物や庭用品などの庭オブジェクトを庭に設置し、移動・回転・拡大縮小・削除して配置を考える。                                                                                                                                                                                                                                                                               |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                                                                                    |
| 事前条件     | 庭シミュレーション画面が表示されている。庭写真がアップロードされ、施工範囲が設定されている。                                                                                                                                                                                                                                                                              |
| 事後条件     | 庭オブジェクトの位置・向き・大きさ・個数が庭シミュレーション上に反映される。                                                                                                                                                                                                                                                                                      |
| 基本フロー    | 1. 利用者が設置したい庭オブジェクトを選ぶ。<br>2. 利用者が庭写真上の位置を指定して設置する。<br>3. システムが庭オブジェクトを庭シミュレーションに表示する。<br>施工範囲の外に設置した場合は => 代替フロー1へ<br>4. 利用者が設置済みオブジェクトを選び、移動・回転・拡大縮小のいずれかを行う。<br>5. システムが操作結果を庭シミュレーションに反映する。<br>移動・拡大縮小で上限・下限を超える場合 -> 代替フロー3へ<br>6. 利用者が不要なオブジェクトを選び、削除する。<br>7. システムが庭オブジェクトを庭シミュレーションから取り除く。<br>通信に失敗した場合は => 代替フロー2へ |
| 代替フロー    | 1. 施工範囲の外に設置・移動した場合<br>1-1. システムが範囲外であることを表示し、範囲内への配置を促す。<br><br>2. 通信に失敗した場合(オブジェクト情報の取得など)<br>2-1. システムが通信エラーを表示し、再実行を可能にする。<br><br>3. 移動・拡大縮小で上限・下限を超える場合<br>3-1. システムが上限・下限の位置・大きさに制限する。                                                                                                                                |
| 関連情報     |                                                                                                                                                                                                                                                                                                                             |

#### UC-05 完成イメージ画像を生成・保存する

| 記述項目     | 記述内容                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 配置した庭オブジェクトを元の庭写真に重ねた、完成イメージ画像を生成して確認・保存する。                                                                                                                                                                             |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                |
| 事前条件     | 庭シミュレーション画面が表示されている。庭オブジェクトが1つ以上配置されている。                                                                                                                                                                                |
| 事後条件     | 完成イメージ画像が生成され、利用者が確認・保存できる状態になる。                                                                                                                                                                                        |
| 基本フロー    | 1. 利用者が完成イメージの確認を選ぶ。<br>2. システムが配置情報(位置・向き・大きさ)を取得する。<br>3. システムが元の庭写真に庭オブジェクトを重ねて画像を生成する。<br>生成に失敗した場合は => 代替フロー1へ<br>4. システムが完成イメージ画像を表示する。<br>5. 利用者が必要に応じて、PNGで保存を選んで、完成イメージ画像をPNG形式で保存する。<br>保存に失敗した場合は -> 代替フロー2へ |
| 代替フロー    | 1. 生成に失敗した場合(処理エラー、通信失敗)<br>1-1. システムがエラーを表示し、再生成を可能にする。<br><br>2. 保存に失敗した場合(通信失敗)<br>2-1. システムが通信エラーを表示し、再実行を可能にする。                                                                                                    |
| 関連情報     |                                                                                                                                                                                                                         |

#### UC-06 庭プロジェクトを保存する

| 記述項目     | 記述内容                                                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭オブジェクトの位置・個数・商品の情報を庭プロジェクトとして保存する。                                                                                                                                        |
| アクター     | 利用者(購入者)                                                                                                                                                                   |
| 事前条件     | 庭シミュレーション画面が開かれている                                                                                                                                                         |
| 事後条件     | 庭オブジェクトの位置・個数・商品の情報が保存され、次回以降に再開できる。                                                                                                                                       |
| 基本フロー    | 1. 利用者が庭プロジェクトの保存を選ぶ。<br>保存済みの内容から変更がない場合 -> 代替フロー1へ<br>2. システムが庭オブジェクトの位置・個数・商品の情報を取得する。<br>3. システムが取得した内容を庭プロジェクトとして保存する。<br>通信に失敗した場合は => 代替フロー2へ<br>4. システムが保存完了を表示する。 |
| 代替フロー    | 1. 保存済みの内容から変更がない場合<br>1-1. 保存ボタンを無効化する<br><br>2. 通信に失敗した場合<br>2-1. システムが通信エラーを表示し、保存されていないことを伝える。<br>2-2. システムが編集内容を保持したまま、再保存を可能にする。                                     |

#### UC-07 庭プロジェクトを管理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 作成した庭プロジェクトを一覧で確認し、複製して別案を作ったり、不要なプロジェクトを削除したりする。                                                                                                                                                                                                                                              |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                                                       |
| 事前条件     | 利用者がログイン済みである。                                                                                                                                                                                                                                                                                 |
| 事後条件     | 複製した場合は新しい庭プロジェクトが追加され、削除した場合は対象が庭一覧から消える。                                                                                                                                                                                                                                                     |
| 基本フロー    | 1. 利用者が庭プロジェクト一覧画面を開く。<br>2. システムが利用者の庭プロジェクトを一覧表示する。<br>庭プロジェクトがない場合は => 代替フロー1へ<br>3. 利用者がプロジェクトを選び、操作(開く・複製・削除)を選ぶ。<br>4. 複製の場合、システムが選択したプロジェクトの内容を複製して新規プロジェクトを作成し、一覧に追加する。<br>5. 削除の場合、システムが削除の確認を表示する。利用者が確定すると、システムがプロジェクトを削除する。<br>利用者が削除を取り消した場合は => 代替フロー2へ<br>通信に失敗した場合は => 代替フロー3へ |
| 代替フロー    | 1. 庭プロジェクトがない場合<br>1-1. システムが新規作成(UC-01)を案内する。<br><br>2. 削除を取り消した場合<br>2-1. システムが削除せず、一覧表示に戻る。<br><br>3. 通信に失敗した場合<br>3-1. システムが通信エラーを表示し、再実行を可能にする。                                                                                                                                           |
| 関連情報     | 複製は別案の比較に使う / 削除したプロジェクトの復元はしない(要確認)                                                                                                                                                                                                                                                           |

#### UC-08 購入リストを表示する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭に配置した庭オブジェクトに対応する商品を、購入リストとして一覧で表示する。                                                                                                                                                                                                                                                                                                                |
| アクター     | 利用者(購入者)                                                                                                                                                                                                                                                                                                                                              |
| 事前条件     | 庭プロジェクトが開かれている。                                                                                                                                                                                                                                                                                                                                       |
| 事後条件     | 配置されている庭オブジェクトに対応する商品が、購入リストに表示される。                                                                                                                                                                                                                                                                                                                   |
| 基本フロー    | 1. 利用者が購入リストの表示を選ぶ。<br>2. システムが庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>配置されたオブジェクトがない場合は => 代替フロー1へ<br>3. システムが各庭オブジェクトに紐づいた商品の情報を取得する。<br>庭オブジェクトに紐づく商品が存在しない場合は => 代替フロー2へ<br>通信に失敗した場合は => 代替フロー4へ<br>4. システムが商品ごとに、配置数を数量として購入リストに表示する(商品画像、商品名、価格、出店者名、在庫状況、数量)。<br>商品が販売停止中または在庫不足の場合は => 代替フロー3へ<br>5. 利用者が購入リストを確認する。                            |
| 代替フロー    | 1. 配置されたオブジェクトがない場合<br>1-1. システムが購入リストが空であることを表示し、オブジェクトの配置(UC-04)を案内する。<br><br>2. 庭オブジェクトに紐づく商品が存在しない場合(商品が削除された、紐づけが解除されたなど)<br>2-1. システムがその庭オブジェクトに対応する商品がないことを表示する。<br><br>3. 紐づいた商品が販売停止中または在庫不足の場合  <br>3-1. システムがその商品を購入リストに表示し、販売停止または在庫不足であることを示す。 <br>3-2. システムがその商品をカートへ登録できないようにする。<br><br>4. 通信に失敗した場合<br>4-1. システムが通信エラーを表示し、再取得を可能にする。 |
| 関連情報     | 庭オブジェクトと商品は1対1で紐づく。 / 数量は配置されているオブジェクトの個数とする                                                                                                                                                                                                                                                                                                          |
