# EC-A07 商品カテゴリを追加する

| 記述項目     | 記述内容                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 管理者がカテゴリを追加する。                                                                                                        |
| アクター     | 管理者（運営者）                                                                                                              |
| 事前条件     | カテゴリ管理画面を利用できる。                                                                                                       |
| 事後条件     | カテゴリ一覧に新しいカテゴリが追加される。                                                                                                 |
| 基本フロー    | 1. 管理者がカテゴリ追加を選ぶ。<br>2. システムが入力欄を表示する。<br>3. 管理者がカテゴリ情報を入力して確定する。<br>必須項目が不足する場合は => 代替フロー1へ。<br>4. システムがカテゴリ一覧を更新する。 |
| 代替フロー    | 1. 必須項目が不足する場合<br>1-1. システムが入力エラーを表示し、カテゴリを追加しない。                                                                     |
