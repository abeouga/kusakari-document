#### EC-A07 商品カテゴリを追加する

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者がカテゴリを追加する。                                                                            |
| アクター     | 運営者                                                                                  |
| 事前条件     | 運営者アカウントでログインしている。<br>カテゴリ管理画面を利用できる。                                                                           |
| 事後条件     | カテゴリ一覧に新しいカテゴリが追加されている。                                                                   |
| 基本フロー    | 1. 運営者がカテゴリ追加を選ぶ。<br>2. システムが入力欄を表示する。<br>3. 運営者がカテゴリ情報を入力して確定する。<br>4. システムがカテゴリ一覧を更新する。 |
| 代替フロー    | 3a. 必須項目が不足する場合<br>3a-1. システムが入力エラーを表示し、カテゴリを追加しない。<br>3a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
