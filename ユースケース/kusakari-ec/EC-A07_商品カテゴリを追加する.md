#### EC-A07 商品カテゴリを追加する

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者がカテゴリを追加する。                                                                            |
| アクター     | 運営者                                                                                  |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件     | カテゴリ一覧に新しいカテゴリが追加されている。                                                                   |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「カテゴリ管理」を開く(EC-C02)。<br>2. システムが「カテゴリ管理」画面にカテゴリ一覧と「カテゴリ名」入力欄を表示する。<br>3. 運営者が「カテゴリ名」入力欄にカテゴリ名を入力する。<br>4. 運営者が「保存」ボタンをクリックする。<br>5. システムがカテゴリ名を検証する。<br>6. システムがカテゴリを追加し、「保存しました。」を表示してカテゴリ一覧を更新する。 |
| 代替フロー    | 5a. カテゴリ名が空、または30文字を超える場合<br>5a-1. システムが入力エラー(空白のみの場合は「カテゴリ名を入力してください。」)を表示し、カテゴリを追加しない。<br>5a-2. 基本フロー3へ戻る。<br><br>5b. 同じ名前のカテゴリがすでにある場合<br>5b-1. システムが「同じカテゴリがあります。」を表示し、カテゴリを追加しない。<br>5b-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
