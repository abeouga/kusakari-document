#### EC-A07 商品カテゴリを追加する

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 運営者が商品カテゴリを追加する。 |
| アクター     | 運営者 |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件     | カテゴリ一覧に新しいカテゴリが追加されている。 |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「カテゴリ管理」を開く(EC-C02)。<br>2. システムが「カテゴリ管理」画面に「カテゴリ名」入力欄、「保存」「編集を取消」ボタン、名前順のカテゴリ一覧を表示する。<br>3. 運営者が「カテゴリ名」入力欄にカテゴリ名を入力する。<br>4. 運営者が「保存」ボタンをクリックする。<br>5. システムがカテゴリ名を検証する。<br>6. システムがカテゴリを追加し、「保存しました。」を表示して、入力欄を空にし、カテゴリ一覧を更新する。 |
| 代替フロー    | 4a. カテゴリ名が未入力の場合<br>4a-1. ブラウザーが入力欄に必須入力のメッセージを表示し、保存しない。<br>4a-2. 基本フロー3へ戻る。<br><br>5a. カテゴリ名が空白だけの場合<br>5a-1. システムが「入力内容・文字数・数値の範囲を確認してください。」を表示し、カテゴリを追加しない。<br>5a-2. 基本フロー3へ戻る。<br><br>5b. 同じ名前のカテゴリがすでにある場合<br>5b-1. システムが「同じカテゴリがあります。」を表示し、カテゴリを追加しない。<br>5b-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・「カテゴリ名」入力欄には30文字までしか入力できない。<br>・カテゴリ名は前後の空白を取り除いて保存する。 |
