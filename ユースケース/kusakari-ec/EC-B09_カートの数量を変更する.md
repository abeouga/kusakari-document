#### EC-B09 カートの数量を変更する

| 記述項目     | 記述内容                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | カート内商品の購入数量を変更する。                                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                                    |
| 事前条件     | 「ショッピングカート」画面に対象商品が表示されている。                                                                                                                                                           |
| 事後条件     | 変更後の数量と税込合計が保存・表示されている。                                                                                                                                                |
| 基本フロー    | 1. 購入者が対象商品の「＋」ボタンまたは「−」ボタンをクリックする。<br>2. システムが数量と在庫を検証する。<br>3. システムが変更を保存し、数量と税込合計を更新して「カートを更新しました。」と表示する。 |
| 代替フロー    | 2a. 数量が無効または在庫不足の場合<br>2a-1. システムが「受取店舗の在庫が不足しています。」などの数量または在庫のエラーを表示し、変更前の内容を維持する。<br>2a-2. 基本フロー1へ戻る。<br><br>3a. 保存に失敗した場合<br>3a-1. システムがエラーメッセージ(「別の操作でカートが更新されました。最新の内容を確認してください。」など)を表示し、最新のカートを再取得して表示し、購入者に再確認を求める。<br>3a-2. 基本フロー1へ戻る。 |
| 関連情報     | ・在庫は、商品の店舗(受取店舗)の在庫を使う。<br>・数量は在庫数または99点を上限とし、上限に達すると「＋」ボタンをクリックできない。数量が1点のときは「−」ボタンをクリックできない(削除はEC-B10)。 |
