# EC-B09 カートの数量を変更する

| 記述項目 | 記述内容 |
|---|---|
| ユースケース概要 | カート内商品の購入数量を変更する。 |
| アクター | 利用者（購入者） |
| 事前条件 | カートに対象商品がある。 |
| 事後条件 | 変更後の数量と税込合計が保存・表示される。 |
| 基本フロー | 1. 利用者が対象商品の数量を変更する。<br>2. システムが数量と在庫を検証する。<br>数量が無効または在庫不足の場合は => 代替フロー1へ。<br>3. システムが変更を保存し、税込合計を更新する。<br>保存に失敗した場合は => 代替フロー2へ。 |
| 代替フロー | 1. 数量が無効または在庫不足の場合<br>1-1. システムが数量または在庫のエラーを表示し、変更前の内容を維持する。<br><br>2. 保存に失敗した場合<br>2-1. システムが最新のカートを再取得して表示し、利用者に再確認を求める。 |
