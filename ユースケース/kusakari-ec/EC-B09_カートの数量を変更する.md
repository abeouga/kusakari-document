#### EC-B09 カートの数量を変更する

| 記述項目     | 記述内容                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | カート内商品の購入数量を変更する。                                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                                    |
| 事前条件     | カートに対象商品がある。                                                                                                                                                           |
| 事後条件     | 変更後の数量と税込合計が保存・表示されている。                                                                                                                                                |
| 基本フロー    | 1. 購入者が対象商品の数量を変更する。<br>2. システムが数量と在庫を検証する。<br>3. システムが変更を保存し、税込合計を更新する。                                                                                               |
| 代替フロー    | 2a. 数量が無効または在庫不足の場合<br>2a-1. システムが数量または在庫のエラーを表示し、変更前の内容を維持する。<br>2a-2. 基本フロー1へ戻る。<br><br>3a. 保存に失敗した場合<br>3a-1. システムが最新のカートを再取得して表示し、購入者に再確認を求める。<br>3a-2. 基本フロー1へ戻る。 |
| 関連情報     | ・在庫は地理的に近い店舗から取得する                                                                                                                                                     |
