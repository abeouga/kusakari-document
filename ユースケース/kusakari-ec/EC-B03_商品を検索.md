# EC-B03 商品を検索

| 記述項目     | 記述内容                                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 商品名・品番などで商品を探し、条件で絞り込む。                                                                                                                    |
| アクター     | 利用者(購入者)                                                                                                                                   |
| 事前条件     | 商品一覧を利用できる。<br>ログインは不要。                                                                                                                    |
| 事後条件     | 条件に合う商品一覧または選択した商品が表示される。                                                                                                                  |
| 基本フロー    | 1. 利用者が商品名・品番などを入力するか、カテゴリ・絞り込み条件を指定する。<br>2. 必要に応じて価格順などで並べ替える。<br>3. システムが条件に合う商品を表示する。<br>=> 該当商品がない場合は代替フロー1へ<br>=> 通信に失敗した場合は代替フロー2へ。 |
| 代替フロー    | 1. 該当商品がない場合<br>1-1. システムが該当商品なしと表示し、検索条件の変更を可能にする。<br><br>2. 通信に失敗した場合<br>2-1. システムが通信エラーを表示し、利用者が再試行できるようにする。 |
