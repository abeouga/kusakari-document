# EC-S05 店舗在庫数を更新する

| 記述項目 | 記述内容                                                                                                                             |
|---|---|
| ユースケース概要 | 商品・店舗ごとの在庫数を変更する。                                                                                                                |
| アクター | 出店者（画面上の役割）                                                                                                                      |
| 事前条件 | 在庫管理画面で商品と店舗を選択できる。                                                                                                              |
| 事後条件 | 更新した在庫数がデータベースに保存される。                                                                                                            |
| 基本フロー | 1. 出店者が在庫管理を開く。<br>2. システムが商品・店舗別の在庫を表示する。<br>3. 出店者が在庫数を変更する。<br>整数0〜10000の範囲外など入力が無効な場合は => 代替フロー1へ。<br>4. システムが検証して保存結果を表示する。 |
| 代替フロー | 1. 整数0〜10000の範囲外など入力が無効な場合<br>1-1. システムが入力エラーを表示し、在庫数を更新しない。                                                                     |
