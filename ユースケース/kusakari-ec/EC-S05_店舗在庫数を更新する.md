#### EC-S05 店舗在庫数を更新する

| 記述項目     | 記述内容                                                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 所属店舗の商品ごとの在庫数を変更する。 |
| アクター     | 出店者                                                                                                                                                                                                      |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。<br>在庫数を更新する商品と店舗が登録されている。 |
| 事後条件     | 更新した在庫数が保存されている。                                                                                                                                                                                         |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面を表示し、所属店舗の商品別の在庫数を表示する。<br>3. 出店者が対象商品の行の「在庫を編集」ボタンをクリックする。<br>4. システムが変更前の在庫数と「在庫数」の入力欄を表示する。<br>5. 出店者が「在庫数」の入力欄に新しい在庫数を入力する。<br>6. 出店者が「在庫を保存」ボタンをクリックする。<br>7. システムが入力値を検証する。<br>8. システムが在庫数を保存し、更新後の在庫数を表示する。 |
| 代替フロー    | 7a. 整数0〜10000の範囲外など入力が無効な場合<br>7a-1. システムが入力エラーを表示し、在庫数を更新しない。<br>7a-2. 基本フロー5へ戻る。<br><br>8a. 在庫数の表示後に在庫が変わっていた場合(注文による引き当て、キャンセルによる戻しなど)<br>8a-1. システムが在庫数を更新せず、最新の在庫数を表示して再確認を求める。<br>8a-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・在庫数の変更は商品登録・編集のフォームとは別に「商品管理」画面の商品一覧から行い、同じ一覧で販売状態の変更(EC-S06)も行える。<br>・在庫数を変更しても、商品名や価格などの商品情報は変わらない。 |
