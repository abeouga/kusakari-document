#### EC-S05 店舗在庫数を更新する

| 記述項目     | 記述内容                                                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 所属店舗の商品ごとの在庫数を変更する。 |
| アクター     | 出店者                                                                                                                                                                                                      |
| 事前条件     | 出店者アカウントでログインしている。<br>在庫数を更新する商品と店舗が登録されている。                                                                                                                                                             |
| 事後条件     | 更新した在庫数が保存されている。                                                                                                                                                                                         |
| 基本フロー    | 1. 出店者が「在庫・販売状態」を選ぶ。<br>2. システムが所属店舗の商品別の在庫を表示する。<br>3. 出店者が在庫数を変更する。<br>4. システムが検証して保存結果を表示する。 |
| 代替フロー    | 4a. 整数0〜10000の範囲外など入力が無効な場合<br>4a-1. システムが入力エラーを表示し、在庫数を更新しない。<br>4a-2. 基本フロー3へ戻る。<br><br>4b. 在庫数の表示後に在庫が変わっていた場合(注文による引き当て、キャンセルによる戻しなど)<br>4b-1. システムが在庫数を更新せず、最新の在庫数を表示して再確認を求める。<br>4b-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・在庫管理画面は商品登録の画面とは別の画面で、販売状態の変更(EC-S06)も行える。<br>・在庫数を変更しても、商品名や価格などの商品情報は変わらない。 |
