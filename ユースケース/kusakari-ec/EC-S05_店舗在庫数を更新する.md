#### EC-S05 店舗在庫数を更新する

| 記述項目     | 記述内容                                                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品・店舗ごとの在庫数を変更する。                                                                                                                                                                                        |
| アクター     | 出店者                                                                                                                                                                                                      |
| 事前条件     | 出店者アカウントでログインしている。<br>在庫数を更新する商品と店舗が登録されている。                                                                                                                                                             |
| 事後条件     | 更新した在庫数が保存されている。                                                                                                                                                                                         |
| 基本フロー    | 1. 出店者が在庫管理を選ぶ。<br>2. 出店者が管理する店舗を選ぶ。<br>3. システムが選んだ店舗の商品別の在庫を表示する。<br>4. 出店者が在庫数を変更する。<br>5. システムが検証して保存結果を表示する。                                                                                         |
| 代替フロー    | 5a. 整数0〜10000の範囲外など入力が無効な場合<br>5a-1. システムが入力エラーを表示し、在庫数を更新しない。<br>5a-2. 基本フロー4へ戻る。<br><br>5b. 在庫数の表示後に在庫が変わっていた場合(注文による引き当て、キャンセルによる戻しなど)<br>5b-1. システムが在庫数を更新せず、最新の在庫数を表示して再確認を求める。<br>5b-2. 基本フロー4へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・在庫管理画面は商品管理画面とは別の画面。<br>・在庫管理画面では、最初に管理する店舗を選ぶ。                                                                                                                                   |
