# EC-S01 出店を申請する

| 記述項目     | 記述内容                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店希望者が出店申請フォームを入力し、申請状態を確認する。                                                                                              |
| アクター     | 出店希望者                                                                                                                      |
| 事前条件     | 出店申請フォームを利用できる。                                                                                                            |
| 事後条件     | 申請状態が表示される。                                                                                                                |
| 基本フロー    | 1. 出店希望者が申請フォームを開く。<br>2. システムが入力欄を表示する。<br>3. 出店希望者が事業者情報などを入力して提出する。<br>必須項目が不足している場合は => 代替フロー1へ。<br>4. システムが申請状態を表示する。 |
| 代替フロー    | 1. 必須項目が不足している場合<br>1-1. システムが不足項目を示し、申請を受け付けない。                                                                           |
