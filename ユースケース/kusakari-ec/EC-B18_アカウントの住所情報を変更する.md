# EC-B18 アカウントの住所情報を変更する

| 記述項目     | 記述内容                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 住所管理画面で受取人、郵便番号、住所を入力し、画面上の住所情報を更新する。                                                                      |
| アクター     | 利用者（購入者）                                                                                                   |
| 事前条件     | 住所情報を表示できる。                                                                                                |
| 事後条件     | 住所欄が更新される。                                                                                                 |
| 基本フロー    | 1. 利用者が受取人・郵便番号・住所を確認する。<br>2. 利用者が必要な項目を編集して送信する。<br>3. システムが住所を更新し、完了メッセージを表示する。<br>入力不足の場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 入力不足の場合<br>1-1. 不足項目を示し、住所を更新しない。                                                                       |
