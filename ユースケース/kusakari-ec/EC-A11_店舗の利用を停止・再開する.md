#### EC-A11 店舗の利用を停止・再開する

| 記述項目 | 記述内容 |
| -------- | -------- |
| ユースケース概要 | 運営者が店舗の利用を停止・再開する。 |
| アクター | 運営者 |
| 事前条件 | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。<br>対象の店舗が登録されている。 |
| 事後条件 | 対象店舗が利用停止または利用可能として表示されている。 |
| 基本フロー | 1. 運営者が管理者画面のメニュー「店舗管理」を開く(EC-C02)。<br>2. システムが「店舗管理」画面に店舗の一覧と利用状態を表示する。<br>3. 運営者が対象店舗の「利用を停止」または「利用を再開」ボタンをクリックする。<br>4. システムが「利用状況変更の確認」ダイアログを表示する。<br>5. 運営者が「利用停止を確定」または「利用再開を確定」ボタンをクリックする。<br>6. システムが店舗の利用状態を更新し、「利用を停止しました。」または「利用を再開しました。」と更新後の利用状態を表示する。 |
| 代替フロー | 5a. 確定を取り消した場合<br>5a-1. 運営者が「利用状況変更の確認」ダイアログの「取消」ボタンをクリックする。<br>5a-2. システムがダイアログを閉じ、店舗の利用状態を変更せず「店舗管理」画面を表示する。<br>5a-3. ユースケースを終了する。 |
| 関連情報 | ・共通代替フロー *b を適用する。<br>・利用停止中の店舗の商品は購入者向けの画面に表示せず、受取店舗としても選べない。新しい注文も受け付けない(EC-B12)。<br>・利用停止中の店舗の出店者は、商品・在庫・注文などの出店者向けの操作ができない。<br>・すでに確定した注文はキャンセルしない。利用停止中は注文の状態も更新できないため、受け渡しは利用を再開してから続ける。<br>・店舗の利用停止・再開は出店者に通知しない。 |
