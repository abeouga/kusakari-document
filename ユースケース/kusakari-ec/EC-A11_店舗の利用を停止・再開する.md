#### EC-A11 店舗の利用を停止・再開する

| 記述項目 | 記述内容 |
| -------- | -------- |
| ユースケース概要 | 運営者が店舗の利用を停止・再開する。 |
| アクター | 運営者 |
| 事前条件 | 運営者アカウントでログインしている。<br>店舗管理画面に対象の店舗が表示されている。 |
| 事後条件 | 対象店舗が利用停止または利用可能として表示されている。 |
| 基本フロー | 1. 運営者が「店舗管理」で対象店舗を選ぶ。<br>2. 運営者が「利用を停止」または「利用を再開」を選ぶ。<br>3. システムが確認メッセージを表示する。<br>4. 運営者が確定する。<br>5. システムが店舗の利用状態を更新して表示する。 |
| 代替フロー | 4a. 確定を取り消した場合<br>4a-1. システムが店舗の利用状態を変更せず、店舗管理画面を表示する。<br>4a-2. ユースケースを終了する。 |
| 関連情報 | ・共通代替フロー *b を適用する。<br>・利用停止中の店舗の商品は購入者向けの画面に表示せず、受取店舗としても選べない。新しい注文も受け付けない(EC-B12)。<br>・利用停止中の店舗の出店者は、商品・在庫・注文などの出店者向けの操作ができない。<br>・すでに確定した注文はキャンセルしない。利用停止中は注文の状態も更新できないため、受け渡しは利用を再開してから続ける。<br>・店舗の利用停止・再開は出店者に通知しない。 |
