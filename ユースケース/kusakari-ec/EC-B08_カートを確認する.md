#### EC-B08 カートを確認する

| 記述項目     | 記述内容                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | カートにある商品・数量・受取店舗・税込合計を確認する。 |
| アクター     | 購入者                                                                                                                                                   |
| 事前条件     | 購入者アカウントでログインしている。<br>共通ヘッダーのある画面(「トップ」画面など)が表示されている。                                                                                                                                               |
| 事後条件     | 現在のカート内容または空の状態が表示されている。                                                                                                                                   |
| 基本フロー    | 1. 購入者が共通ヘッダーの「カート」リンクをクリックする。<br>2. システムが「ショッピングカート」画面に、商品ごとの商品画像・商品名・価格・受取店舗・数量・金額と、「ご請求内容」(商品小計、うち消費税、合計)を表示する。商品の一覧の下には「庭に設置したものから追加」(EC-B24)を表示する。<br>3. 購入者が表示内容を確認する。 |
| 代替フロー    | 2a. カートが空の場合<br>2a-1. システムが「まだ商品が入っていません。」と表示し、商品一覧へ進む「商品を探す」ボタンと「庭に設置したものから追加」を表示する。<br>2a-2. ユースケースを終了する。<br><br>2b. 購入できなくなった商品がカートにあった場合(店舗の閉鎖済み・利用停止、組織の停止、商品の削除)<br>2b-1. システムがその商品をカートから外し、「(商品名)は購入できなくなったためカートから外しました。」と表示する。<br>2b-2. 購入者が「閉じる」ボタンをクリックすると、システムが表示を消す。<br>2b-3. 基本フロー3へ進む。<br><br>2c. 一時的に購入できない商品がある場合(出店者による非表示、運営者による公開停止、店舗の非公開・閉鎖中、組織の受付停止中など)<br>2c-1. システムがその商品をカートに残したまま、「現在は購入できません」と表示する。<br>2c-2. 基本フロー3へ進む。<br><br>2d. 在庫が不足している商品がある場合<br>2d-1. システムがその商品に「在庫不足（現在 N 点）」と表示する。<br>2d-2. 基本フロー3へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。未ログインで「ショッピングカート」画面を開いた場合は、「ログイン」画面へ移動する。<br>・店舗側のアカウント(出店者のオーナー・担当者)と出店申請用アカウントには、カートの内容の代わりに「店舗・出店申請用のアカウントでは購入できません。購入は購入者のアカウントでご利用ください。」と「商品を探す」ボタンを表示する。<br>・購入できない商品・在庫不足の商品がある間は、「注文内容を確認する」ボタンを押せない(EC-B12)。<br>・カートから外した商品は、店舗や組織が再開してもカートに戻らない。 |
