#### EC-B08 カートを確認する

| 記述項目     | 記述内容                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | カートにある商品・数量・受取店舗・税込合計を確認する。 |
| アクター     | 購入者                                                                                                                                                   |
| 事前条件     | ECカートを利用できる。                                                                                                                                               |
| 事後条件     | 現在のカート内容または空の状態が表示されている。                                                                                                                                   |
| 基本フロー    | 1. 購入者がカートを開く。<br>2. システムが商品・数量・受取店舗・税込合計を表示する。カート画面には「庭の買い物リスト」タブ(EC-B24)も表示する。<br>3. 購入者が表示内容を確認する。 |
| 代替フロー    | 2a. カートが空の場合<br>2a-1. システムがカートは空であることを表示し、商品一覧へ進めるようにする。<br>2a-2. ユースケースを終了する。 |
