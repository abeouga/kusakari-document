# EC-B08 カートを確認する

| 記述項目     | 記述内容                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | カートにある商品・数量・受取情報・税込合計を確認する。                                                                                     |
| アクター     | 利用者（購入者）                                                                                                        |
| 事前条件     | ECカートを利用できる。                                                                                                    |
| 事後条件     | 現在のカート内容または空の状態が表示される。                                                                                          |
| 基本フロー    | 1. 利用者がカートを開く。<br>2. システムが商品・数量・受取情報・税込合計を表示する。<br>カートが空の場合は => 代替フロー1へ、<br>取得に失敗した場合は => 代替フロー2へ。<br>3. 利用者が表示内容を確認する。 |
| 代替フロー    | 1. カートが空の場合<br>1-1. システムがカートは空であることを表示し、商品一覧へ進めるようにする。<br><br>2. 取得に失敗した場合<br>2-1. システムが取得エラーを表示し、再取得を可能にする。 |
