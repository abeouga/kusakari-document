#### EC-S13 注文キャンセル申請を処理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者が購入者からの注文キャンセル申請の内容と注文状態を確認し、承認または却下する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 出店者(オーナー、MANAGER(店長))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | 出店者(オーナー、または対象店舗のMANAGER)のアカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | キャンセル申請状態が「承認」または「却下」として保存され、購入者にサイト内通知で結果が通知されている。<br>承認した場合は、注文状態が「キャンセル」になり、引き当てた在庫が戻されている。カードで支払い済みの注文は、返金を始めている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗受け取り」を開く(EC-C03)。<br>2. システムが「店舗受け取り」画面に選択中の店舗の注文一覧を表示し、キャンセル申請中の注文に「キャンセル申請中」と「キャンセル申請があります：(キャンセル理由)」、「キャンセル回答」の入力欄、「キャンセルを承認」「キャンセルを却下」ボタンを表示する。<br>3. 出店者が申請の内容(注文内容、合計、キャンセル理由)を確認する。<br>4. 却下する場合、出店者が「キャンセル回答」の入力欄に却下理由を入力する。<br>5. 出店者が「キャンセルを承認」または「キャンセルを却下」ボタンをクリックする。<br>6. システムがキャンセル申請状態を、選ばれた結果(「承認」/「却下」)に更新する。承認の場合は、注文状態を「キャンセル」に更新し、引き当てた在庫を戻す。カードで支払い済みの注文は、その注文の金額の返金を決済会社に依頼する。<br>7. システムがサイト内通知で購入者に処理結果(承認は「注文をキャンセルしました」、却下は「キャンセル申請の結果」)を通知する。キャンセル回答を入力した場合は回答も通知に含める。<br>8. システムが「保存しました。」と処理結果を注文一覧に表示する。 |
| 代替フロー    | 2a. キャンセル申請中の注文がない場合<br>2a-1. システムがキャンセル申請中の表示をしない。<br>2a-2. ユースケースを終了する。<br><br>6a. 「キャンセル回答」が未入力のまま「キャンセルを却下」ボタンをクリックした場合<br>6a-1. システムが「却下理由を入力してください。」と表示し、キャンセル申請状態を変更しない。<br>6a-2. 基本フロー4へ戻る。<br><br>6b. 申請がすでに処理されている場合(他の担当者が処理したなど)<br>6b-1. システムが「注文状態が変わりました。最新の状態を確認してください。」と表示し、変更しない。<br>6b-2. システムが最新の注文一覧を表示する。<br>6b-3. ユースケースを終了する。<br><br>6c. 更新に失敗した場合<br>6c-1. システムが更新エラーを表示し、キャンセル申請状態・注文状態・在庫を処理前の状態のままにする。<br>6c-2. 基本フロー4へ戻る。<br><br>6d. キャンセル申請に回答する権限がない場合(STAFF)<br>6d-1. システムが「この操作の権限がありません。」と表示し、変更しない。<br>6d-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・キャンセル申請は購入者がEC-B14で行う。申請されると出店者向けのイベント通知(EC-S11)で知らせる。<br>・キャンセル申請ができるのは注文状態が「注文受付」の注文だけのため、受取準備完了・引き渡し完了の注文に申請が届くことはない。<br>・却下した場合、注文状態は申請前のまま変わらず、そのまま受け渡しを続ける。購入者は同じ注文について再び申請できる。<br>・処理結果は購入者が利用者通知(EC-B15)で確認できる。<br>・キャンセル申請中の注文はEC-S09・EC-S10による状態の更新をしない。<br>・出店者が一定期間処理しなかったキャンセル申請はその状態を継続する。<br>・返金は承認に伴って自動で行う。単独の返金の操作はない。店舗でお支払いの注文は支払い前のため返金しない。返金の結果は決済会社からの連絡で反映し、注文に「返金の処理中」「返金済み」「返金の失敗」を表示する(EC-S08)。<br>・閉鎖中の店舗・受付停止中の組織では、承認によって未完了の注文がなくなると、店舗が閉鎖済み・組織が停止になる。 |
