#### EC-S13 注文キャンセル申請を処理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者が購入者からの注文キャンセル申請の内容と注文状態を確認し、承認または却下する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 出店者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。<br>受注・店舗受け取りの画面を利用できる。 |
| 事後条件     | キャンセル申請状態が「承認」または「却下」として保存され、購入者にサイト内通知で結果が通知されている。<br>承認した場合は、注文状態が「キャンセル済み」になり、引き当てた在庫が戻されている。 |
| 基本フロー    | 1. 出店者が「受注・店舗受け取り」を選択する。<br>2. システムが所属店舗の注文一覧を表示し、キャンセル申請中の注文に申請中であることとキャンセル理由を表示する。<br>3. 出店者が申請の内容(注文内容、合計、キャンセル理由)を確認する。<br>4. 出店者が「承認」または「却下」を選ぶ。却下する場合は、キャンセル回答(却下理由)を入力してから「却下」を選ぶ。<br>5. システムがキャンセル申請状態を、選ばれた結果(「承認」/「却下」)に更新する。承認の場合は、注文状態を「キャンセル済み」に更新し、引き当てた在庫を戻す。<br>6. システムがサイト内通知で購入者に処理結果を通知する。却下の場合は却下理由も通知に含める。<br>7. システムが処理結果を注文一覧に表示する。 |
| 代替フロー    | 2a. キャンセル申請中の注文がない場合<br>2a-1. システムがキャンセル申請中の表示をしない。<br>2a-2. ユースケースを終了する。<br><br>4a. キャンセル回答が未入力のまま「却下」を選んだ場合<br>4a-1. システムが「却下理由を入力してください」と表示し、キャンセル申請状態を変更しない。<br>4a-2. 基本フロー4へ戻る。<br><br>5a. 申請がすでに処理されている場合(他の担当者が処理したなど)<br>5a-1. システムが申請がすでに処理されていることを表示し、変更しない。<br>5a-2. システムが最新の注文一覧を表示する。<br>5a-3. ユースケースを終了する。<br><br>5b. 更新に失敗した場合<br>5b-1. システムが更新エラーを表示し、キャンセル申請状態・注文状態・在庫を処理前の状態のままにする。<br>5b-2. 基本フロー4へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・キャンセル申請は購入者がEC-B14で行う。申請されると出店者向けのイベント通知(EC-S11)で知らせる。<br>・キャンセル申請ができるのは注文状態が「注文受付」の注文だけのため、受取準備完了・引き渡し完了の注文に申請が届くことはない。<br>・却下した場合、注文状態は申請前のまま変わらず、そのまま受け渡しを続ける。購入者は同じ注文について再び申請できる。<br>・処理結果は購入者が利用者通知(EC-B15)で確認できる。<br>・キャンセル申請中の注文はEC-S09・EC-S10による状態の更新をしない。<br>・出店者が一定期間処理しなかったキャンセル申請はその状態を継続する。 |
