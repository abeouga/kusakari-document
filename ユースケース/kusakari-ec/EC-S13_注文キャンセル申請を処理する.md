#### EC-S13 注文キャンセル申請を処理する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者が購入者からの注文キャンセル申請の内容と注文状態を確認し、承認または却下する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| アクター     | 出店者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 事前条件     | 出店者アカウントでログインしている。<br>キャンセル申請画面を利用できる。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 事後条件     | キャンセル申請状態が「承認」または「却下」として保存され、購入者にサイト内通知とメールで結果が通知されている。<br>承認した場合は、注文状態が「キャンセル済み」になり、引き当てた在庫が戻され、決済が取り消されている。                                                                                                                                                                                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 出店者が「キャンセル申請」を選択し、管理する店舗を選ぶ。<br>2. システムが選んだ店舗の注文に対する、キャンセル申請状態が「申請中」のキャンセル申請を取得する。<br>3. システムがキャンセル申請一覧(注文番号、購入者名、申請日、受取希望日、注文状態)を表示する。<br>4. 出店者が処理する申請を選ぶ。<br>5. システムが申請の詳細(注文内容、支払合計、キャンセル理由、注文状態)、却下理由の入力欄、「承認する」「却下する」を表示する。<br>6. 出店者が申請内容と注文状態を確認し、「承認する」または「却下する」を選ぶ。却下する場合は、却下理由を入力してから「却下する」を選ぶ。<br>7. システムがキャンセル申請状態を、選ばれた結果(「承認」/「却下」)に更新する。承認の場合は、注文状態を「キャンセル済み」に更新し、引き当てた在庫を戻し、決済を取り消す。<br>8. システムがサイト内通知とメールで購入者に処理結果を通知する。却下の場合は却下理由も通知に含める。<br>9. システムが処理完了メッセージを表示し、キャンセル申請一覧を再表示する。                    |
| 代替フロー    | 3a. 申請中のキャンセル申請がない場合<br>3a-1. システムが「処理待ちのキャンセル申請はありません」と表示する。<br>3a-2. ユースケースを終了する。<br><br>5a. 注文状態が「引き渡し完了」になっている場合<br>5a-1. システムが「引き渡し済みの注文のため承認できません」と表示し、「承認する」を表示しない。<br>5a-2. 出店者が却下理由を入力して「却下する」を選ぶ。<br>5a-3. 基本フロー7へ進む。<br><br>6a. 却下理由が未入力のまま「却下する」を選んだ場合<br>6a-1. システムが却下理由の入力を求めるエラーメッセージを表示し、キャンセル申請状態を変更しない。<br>6a-2. 基本フロー6へ戻る。<br><br>7a. 更新または決済の取り消しに失敗した場合<br>7a-1. システムが更新エラーを表示し、キャンセル申請状態・注文状態・在庫・決済を処理前の状態のままにする。<br>7a-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・キャンセル申請は購入者がEC-B14で行う。申請されると出店者向けのイベント通知(EC-S11)で知らせる。<br>・却下した場合、注文状態は申請前のまま変わらず、そのまま受け渡しを続ける。<br>・処理結果は購入者が利用者通知(EC-B15)で確認できる。<br>・キャンセル申請中の注文をEC-S09・EC-S10で更新できるかは未定。(要確認)<br>・出店者が一定期間(○日)処理しなかった申請の扱い(自動承認／自動却下／運営者が対応)は未定。(要確認)<br>・キャンセル申請画面では、最初に管理する店舗を選ぶ。 |
