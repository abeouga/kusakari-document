#### EC-B18 出店申請状況を確認する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者が自分の出店申請の審査状況と申請内容を確認する。                                                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                                           |
| 事前条件     | 購入者アカウントでログインしている。<br>アカウント管理画面が表示されている。<br>出店申請をしている(出店審査状態が「審査中」または「却下」)。                                                                                                                                                                                                                                   |
| 事後条件     | 出店申請状況画面に審査状況と申請内容が表示されている。                                                                                                                                                                                                                                                                        |
| 基本フロー    | 1. 購入者がアカウント管理画面にある「出店申請状況」を選択する。<br>2. システムが購入者の出店申請情報を取得する。<br>3. システムが出店申請状況画面を表示する。画面には審査状況(「審査中」)、申請日、申請内容(閲覧のみ)、「審査結果は通知でお知らせします」というメッセージを表示する。<br>4. 購入者が審査状況と申請内容を確認する。                                                                                                                    |
| 代替フロー    | 3a. 申請が却下されている場合<br>3a-1. システムが審査状況(「却下」)、却下理由、申請内容、「再申請する」を表示する。<br>3a-2. 購入者が「再申請する」を選択する。<br>3a-3. システムが前回の申請内容を入力した状態で出店申請画面を表示する。<br>3a-4. EC-B17の基本フロー3へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・アカウント管理画面のリンクは、購入者アカウントにだけ表示する。申請前は「出店申請」、申請後は「出店申請状況」と表示する。却下されても「出店申請状況」のままで、再申請すると出店審査状態は「審査中」に戻る。承認されて出店者アカウントになったら表示しない。<br>・審査結果(承認・却下)は利用者通知で知らせる。<br>・審査中の申請内容は閲覧のみとし、修正はできない。<br>・出店申請状況画面のURLに直接アクセスした場合、未ログインならログイン画面へ、出店者アカウントなら商品管理画面へ、未申請の購入者なら出店申請画面へ移動する。<br>・却下理由は運営者が入力したものを表示する。 |
