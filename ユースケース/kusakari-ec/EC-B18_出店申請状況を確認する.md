#### EC-B18 出店申請状況を確認する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店を検討する事業者が自分の出店申請の審査状況と申請内容を確認し、必要に応じて申請を取り下げる。                                                                                                                                                                                                                                                                        |
| アクター     | 出店を検討する事業者(出店申請用アカウント)                                                                                                                                                                                                                                                                                           |
| 事前条件     | 出店申請用アカウントでログインしている。<br>「メイン」画面が表示されている。<br>出店申請をしている。 |
| 事後条件     | 「出店申請状況」画面に審査状況と申請内容が表示されている。 |
| 基本フロー    | 1. 事業者がアカウントのメニュー「出店申請状況」を開く(EC-C01)。<br>2. システムが事業者の出店申請情報を取得する。<br>3. システムが「出店申請状況」画面を表示する。画面には「審査状況：審査中」、「申請日」、「申請内容」(閲覧のみ)、「提出書類を確認」リンク、「審査結果は通知でお知らせします。」というメッセージ、「申請を取り下げる」ボタンを表示する。<br>4. 事業者が審査状況と申請内容を確認する。 |
| 代替フロー    | 3a. 申請が却下されている場合<br>3a-1. システムが「審査状況：却下」、「却下理由」、「申請内容」、「再申請する」ボタンを表示する。<br>3a-2. 事業者が「再申請する」ボタンをクリックする。<br>3a-3. システムが前回の申請内容を入力した状態で「出店申請」画面を表示する。<br>3a-4. EC-B17の基本フロー2へ進む。<br><br>3b. 申請を取り下げている場合<br>3b-1. システムが「審査状況：取り下げ済み」、「申請内容」、「再申請する」ボタンを表示する。<br>3b-2. 代替フロー3a-2へ進む。<br><br>3c. 申請が承認されている場合<br>3c-1. システムが「審査状況：承認」と「承認されました。ページを再読み込みすると、出店者メニューから店舗を作成できます。」を表示する。<br>3c-2. ユースケースを終了する。<br><br>4a. 審査中の申請を取り下げる場合<br>4a-1. 事業者が「申請を取り下げる」ボタンをクリックする。<br>4a-2. システムが申請を取り下げ済みにし、「申請を取り下げました。」と表示する。<br>4a-3. 代替フロー3bへ進む。<br><br>4b. 取り下げる前に審査が終わっていた場合<br>4b-1. システムが「この申請は取り下げできません。」と表示し、申請を変更しない。<br>4b-2. 基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・サイドバーの「出店をご検討の方」のリンクは、出店申請用アカウントにだけ表示する。申請前は「出店申請」、申請後は「出店申請状況」と表示する。却下・取り下げ後も「出店申請状況」のままで、再申請すると出店審査状態は「審査中」に戻る。承認されて出店者(オーナー)のアカウントになったら表示しない。<br>・審査結果(承認・却下)は利用者通知で知らせる。<br>・審査中の申請内容は閲覧のみとし、修正はできない。修正したい場合は、取り下げてから再申請する。<br>・表示するのは最新の申請である。再申請すると、前回の申請(却下・取り下げ済み)を1件だけ残し、それより前の申請は消す。<br>・「出店申請状況」画面のURLに直接アクセスした場合、未ログインならログイン画面へ、出店者(オーナー・担当者)のアカウントなら「商品管理」画面へ、未申請の出店申請用アカウントなら「出店申請」画面へ移動する。<br>・却下理由は運営者が入力したものを表示する。 |
