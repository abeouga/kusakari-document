# EC-S09 商品の受渡状況登録

| 記述項目     | 記述内容                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品の受渡状況をシステムに登録し、注文者に通知する                                                                                                                                                                           |
| アクター     | 出店者                                                                                                                                                                                                 |
| 事前条件     | 出店者専用画面に「受渡状況」ボタンが表示されている。                                                                                                                                                                          |
| 事後条件     | 入力した登録情報がユーザにSNSで通知される                                                                                                                                                                              |
| 基本フロー    | 1. 出店者がヘッダーの出店者を押す<br>2. システムが出店者専用画面を表示する<br>1. 出店者がサイドバーの「受渡状況登録」を押す<br>4. システムが受渡状況を入力する画面を表示する<br>4. 出店者が注文票に受渡状況を入力して保存する。<br>入力不備がある場合は => 代替フロー1へ。<br>4. システムが入力内容をもとに 受渡状況を反映し、SNSで注文者に通知する |
| 代替フロー    | 1. 入力不備がある場合<br>1-1. システムが入力エラーを表示し、受け渡し情報を確定しない。                                                                                                                                                   |
