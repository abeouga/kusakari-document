# EC-B20 パスワードを再設定する

| 記述項目 | 記述内容 |
|---|---|
| ユースケース概要 | メールアドレスと新しいパスワードを入力し、再設定フォームを操作する。 |
| アクター | 利用者（購入者・事業者） |
| 事前条件 | パスワード再設定フォームを利用できる。 |
| 事後条件 | 再設定フォームまたは入力確認メッセージが表示される。 |
| 基本フロー | 1. 利用者がメールアドレスを入力し、再設定メールの送信を選ぶ。<br>2. システムが同じ画面内に新しいパスワードの入力欄を表示する。<br>3. 利用者が新しいパスワードと確認用パスワードを入力する。<br>4. システムが形式と一致を確認し、入力確認メッセージを表示する。<br>無効な入力の場合は => 代替フロー1へ。 |
| 代替フロー | 1. 無効な入力の場合<br>1-1. システムがメールアドレスまたはパスワードの入力エラーを表示する。 |
