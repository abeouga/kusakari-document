#### EC-B20 パスワードを再設定する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | メールアドレスを入力し、メールに届いた確認コードを入力してパスワードを再設定する。                                                                                                                                                                                                                                                                                                                                                                                   |
| アクター     | 利用者(購入者・出店者)                                                                                                                                                                                                                                                                                                                                                                                                                |
| 事前条件     | ログアウト状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | ログイン画面と完了メッセージが表示されている。                                                                                                                                                                                                                                                                                                                                                                                                     |
| 基本フロー    | 1. 利用者が「メイン」画面から共通ヘッダーの「ログイン」をクリックする。<br>2. システムが「ログイン」画面を表示する。<br>3. 利用者が「パスワードを忘れた方・追加の本人確認」リンクをクリックする。<br>4. システムが認証サービスの画面を表示する。<br>5. 利用者が認証サービスの画面でパスワード再設定の申請へ進む。<br>6. システムがパスワード再設定申請画面を表示する。<br>7. 利用者がパスワード再設定申請画面でメールアドレスを入力する。<br>8. 利用者が確認コードの送信ボタンをクリックする。<br>9. システムが入力されたメールアドレスに確認コードを送信し、確認コード入力画面を表示する。<br>10. 利用者がメールに届いた確認コードを入力する。<br>11. システムが新パスワード設定画面を表示する。<br>12. 利用者が新しいパスワードを入力する。<br>13. 利用者が確認用パスワードを入力する。<br>14. 利用者が新パスワード設定画面の送信ボタンをクリックする。<br>15. システムが形式と一致を確認し、パスワードを更新する。<br>16. システムがログイン画面と一緒に完了メッセージを表示する。 |
| 代替フロー    | 8a. 無効な入力の場合<br>8a-1. システムがメールアドレスの入力エラーを表示する。<br>8a-2. 基本フロー7へ戻る。<br><br>9a. 登録されていないメールアドレスの場合<br>9a-1. システムが確認コードを送信せず、登録済みのときと同じ確認コード入力画面を表示する。<br>9a-2. 基本フロー10へ進む。<br><br>10a. 確認コードが無効または有効期限切れの場合<br>10a-1. システムが「確認コードが無効か、有効期限が切れています。もう一度再設定を申請してください」と表示する。<br>10a-2. システムがパスワード再設定申請画面へのリンクを表示する。<br>10a-3. 利用者がリンクをクリックする。<br>10a-4. 基本フロー7へ戻る。<br><br>15a. 無効な入力の場合<br>15a-1. システムがパスワードの入力エラーを表示する。<br>15a-2. 基本フロー12へ戻る。 |
| 関連情報     | ・アカウントの有無が分からないように、登録されていないメールアドレスでもエラーは表示しない。<br>・「ログイン」画面の「パスワードを忘れた方・追加の本人確認」から始める。再設定の各画面は認証サービスの画面で行い、表示される文言はその画面に従う。 |
