#### EC-B20 パスワードを再設定する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | メールアドレスを入力し、メールに届いた確認コードを入力してパスワードを再設定する。                                                                                                                                                                                                                                                                                                                                                                                   |
| アクター     | 利用者(購入者・出店者)                                                                                                                                                                                                                                                                                                                                                                                                                |
| 事前条件     | パスワード再設定申請画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                        |
| 事後条件     | ログイン画面と完了メッセージが表示されている。                                                                                                                                                                                                                                                                                                                                                                                                     |
| 基本フロー    | 1. 利用者がパスワード再設定申請画面でメールアドレスを入力し、確認コードの送信を選ぶ。<br>2. システムが入力されたメールアドレスに確認コードを送信し、確認コード入力画面を表示する。<br>3. 利用者がメールに届いた確認コードを入力する。<br>4. システムが新パスワード設定画面を表示する。<br>5. 利用者が新しいパスワードと確認用パスワードを入力して送信する。<br>6. システムが形式と一致を確認し、パスワードを更新する。<br>7. システムがログイン画面と一緒に完了メッセージを表示する。                                                                                                                                                           |
| 代替フロー    | 1a. 無効な入力の場合<br>1a-1. システムがメールアドレスの入力エラーを表示する。<br>1a-2. 基本フロー1へ戻る。<br><br>2a. 登録されていないメールアドレスの場合<br>2a-1. システムが確認コードを送信せず、登録済みのときと同じ確認コード入力画面を表示する。<br>2a-2. 基本フロー3へ進む。<br><br>3a. 確認コードが無効または有効期限切れの場合<br>3a-1. システムが「確認コードが無効か、有効期限が切れています。もう一度再設定を申請してください」と表示する。<br>3a-2. システムがパスワード再設定申請画面へのリンクを表示する。<br>3a-3. 利用者がリンクを選ぶ。<br>3a-4. 基本フロー1へ戻る。<br><br>6a. 無効な入力の場合<br>6a-1. システムがパスワードの入力エラーを表示する。<br>6a-2. 基本フロー5へ戻る。 |
| 関連情報     | ・アカウントの有無が分からないように、登録されていないメールアドレスでもエラーは表示しない。<br>・ログイン画面の「パスワードを忘れた場合」から始める。再設定の各画面は認証サービスの画面で行い、表示される文言はその画面に従う。 |
