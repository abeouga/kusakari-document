#### EC-C03 出店者画面のメニューを開く(子ユースケース)

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 共通ヘッダーの「出店者」から、サイドバーのメニューで指定した画面(「商品管理」「注文管理」など)を開く。EC-S02〜EC-S13から呼び出す。 |
| アクター     | 出店者 |
| 事前条件     | 出店者アカウントでログインしている。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。 |
| 事後条件     | 呼び出し元で指定したメニューの画面が表示されている。 |
| 基本フロー    | 1. 出店者が共通ヘッダーの「出店者」リンクをクリックする。<br>2. システムが「ダッシュボード」画面と、サイドバーの出店者メニュー(「ダッシュボード」「商品管理」「注文管理」「注文実績」「店舗プロフィール」「出店者通知」)を表示する。<br>3. 出店者がサイドバーの対象のメニューをクリックする。 |
| 代替フロー    | なし |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象の画面に表示する内容は、呼び出し元のユースケースの次のステップで記述する。<br>・出店者・運営者アカウント以外では、共通ヘッダーに「出店者」リンクを表示しない。 |
