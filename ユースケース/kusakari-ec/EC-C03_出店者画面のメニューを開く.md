#### EC-C03 出店者画面のメニューを開く(子ユースケース)

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 共通ヘッダーの「出店者」から、サイドバーのメニューで指定した画面(「商品管理」「店舗受け取り」など)を開く。EC-S02〜EC-S13から呼び出す。 |
| アクター     | 出店者(組織のオーナー、店舗の担当者) |
| 事前条件     | 出店者(オーナー・担当者)のアカウントでログインしている。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。 |
| 事後条件     | 呼び出し元で指定したメニューの画面が表示されている。 |
| 基本フロー    | 1. 出店者が共通ヘッダーの「出店者」リンクをクリックする。<br>2. システムが「商品管理」画面と、サイドバーの出店者メニュー(「商品管理」「店舗受け取り」「注文実績」「店舗一覧」「店舗プロフィール」「出店者通知」)を表示する。オーナー、ORG_ADMIN、いずれかの店舗のMANAGER(店長)には、「アカウント」「招待キー」も表示する。<br>3. 出店者がサイドバーの対象のメニューをクリックする。 |
| 代替フロー    | 3a. 複数の店舗を扱う場合<br>3a-1. システムが店舗ごとの画面(「商品管理」「店舗受け取り」「注文実績」「店舗プロフィール」「招待キー」)の上に、管理する店舗の選択欄を表示する。<br>3a-2. 出店者が管理する店舗を選択する。<br>3a-3. システムが選択した店舗の内容で画面を表示する。<br><br>3b. 管理できる店舗がまだない場合(承認直後のオーナー、担当の店舗がない担当者)<br>3b-1. システムが店舗ごとの画面に「管理できる店舗がまだありません。」と「店舗一覧を開く」リンクを表示する。<br>3b-2. ユースケースを終了する。<br><br>3c. 選択した店舗で担当のロールがない場合(ORG_ADMINがロールのない店舗を選んだ場合)<br>3c-1. システムが「商品管理」「店舗受け取り」「注文実績」「店舗プロフィール」の代わりに、「(店舗名)では担当のロールがないため、人事（アカウント・招待キー）の画面だけを使えます。」と表示する。<br>3c-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象の画面に表示する内容は、呼び出し元のユースケースの次のステップで記述する。<br>・出店者(オーナー・担当者)・運営者アカウント以外では、共通ヘッダーに「出店者」リンクを表示しない。ほかのアカウントで出店者画面のURLを開くと、「この画面を利用する権限がありません。」と表示する。<br>・出店者画面の入口は「商品管理」画面とする(「ダッシュボード」画面はない)。<br>・選択した店舗は、ブラウザーに保存し、再読み込みしても同じ店舗を選ぶ。<br>・出店者画面のサイドバーは折りたためる。<br>・出店者側のロールと、できる操作は次のとおり。<br>　- オーナー：組織のすべての店舗のすべての操作。店舗の作成・公開・閉鎖も行う。<br>　- MANAGER(店長)：担当する店舗の商品の登録・削除、店舗プロフィールの編集、キャンセル申請への回答と、STAFFの操作。<br>　- STAFF：担当する店舗の商品の編集・公開状態・在庫の変更、注文の受け渡し、注文実績の確認。<br>　- ロールなし：所属する店舗の店舗情報と商品一覧・在庫を見るだけ。注文は見られない。<br>　- ORG_ADMIN：組織の人事(アカウント・招待キー)の担当。商品・在庫・注文は店舗のロールに従う。<br>・権限のない操作をすると、「この操作の権限がありません。」と表示する。 |
