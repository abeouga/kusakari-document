#### EC-B17 出店の申請をする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 出店申請画面で必要な情報を入力し出店の申請をする。                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 購入者アカウントでログインしている。<br>出店申請をしていない、または前回の申請が却下されている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 出店申請情報が出店審査状態「審査中」として保存され、「出店申請を受け付けました」が表示されている。 |
| 基本フロー    | 1. 購入者がアカウントのメニュー「出店申請」を開く(EC-C01)。<br>2. システムが「出店申請」画面に、手順(「事業者情報」「担当者・連絡先」「出店プラン」「事業確認書類」「入力内容の確認」)と現在のステップ(ステップ 1 / 5)を表示し、「事業者情報」の入力欄を表示する。<br>3. 購入者が「会社・事業者名」「所在地」を入力し、「次へ」ボタンをクリックする。<br>4. システムがこのステップの入力内容を検証し、「担当者・連絡先」の入力欄を表示する。<br>5. 購入者が「担当者名」「連絡先メール」「電話番号」を入力し、「次へ」ボタンをクリックする。<br>6. システムがこのステップの入力内容を検証し、「出店プラン」の入力欄を表示する。<br>7. 購入者が「希望出店プラン」から「スタンダード」または「生産者直販」を選択し、「次へ」ボタンをクリックする。<br>8. システムが「事業確認書類」の入力欄を表示する。<br>9. 購入者が「事業確認書類（PDF・PNG・JPEG、5MB以内）」で書類のファイルを選択し、「確認画面へ」ボタンをクリックする。<br>10. システムがこのステップの入力内容を検証し、「入力内容の確認」に入力した出店申請情報を表示する。<br>11. 購入者が入力情報を確認する。<br>12. 購入者が「申請する」ボタンをクリックする。<br>13. システムが出店申請情報を保存し、「出店申請を受け付けました」と「審査結果は通知でお知らせします。」を表示する。 |
| 代替フロー    | 4a・6a・10a. 表示中のステップの必須項目が不足する場合<br>4a-1. システムが「未入力の項目があります：(不足項目)」と表示し、次のステップへ進まない。<br>4a-2. システムが入力内容を残したまま同じステップの入力欄を表示する。<br>4a-3. 購入者がそのステップの入力からやり直す。<br><br>6b・10b. 表示中のステップの入力形式が不正な場合<br>6b-1. システムが入力エラー(「担当者・連絡先」では「連絡先メールの形式が正しくありません。」「電話番号は数字・＋・括弧・ハイフンで入力してください。」、「事業確認書類」では「事業確認書類は5MB以内のファイルを選択してください。」)を表示し、次のステップへ進まない。<br>6b-2. システムが入力内容を残したまま同じステップの入力欄を表示する。<br>6b-3. 購入者がそのステップの入力からやり直す。<br><br>3a. 前のステップへ戻る場合(基本フロー3〜9の間)<br>3a-1. 購入者が「戻る」ボタンをクリックする。<br>3a-2. システムが入力内容を残したまま1つ前のステップを表示する。<br><br>12a. 入力内容を修正する場合<br>12a-1. 購入者が「入力内容の確認」で修正したいステップの「(ステップ名)を修正」ボタンをクリックする。<br>12a-2. システムが入力内容(選択した書類を含む)を残したまま、そのステップの入力欄を表示する。<br>12a-3. 購入者が修正し、「次へ」「確認画面へ」で「入力内容の確認」まで進む(基本フロー10へ)。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・サイドバーのリンクの表示(「出店申請」／「出店申請状況」)はEC-B18の関連情報を参照。<br>・再申請の場合は「出店申請状況」画面の「再申請する」から基本フロー2に入り、前回の申請内容が入った状態で同じステップ形式の「出店申請」画面を表示する。事業確認書類はもう一度選択する。<br>・保存(申請情報の送信)は「申請する」ボタンのときだけ行い、途中のステップでは保存しない。入力途中の内容は保存されない。 |
