#### EC-B17 出店の申請をする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 出店申請画面で必要な情報を入力し出店の申請をする。                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 購入者アカウントでログインしている。<br>出店申請をしていない、または前回の申請が却下されている。 |
| 事後条件     | 出店申請情報が出店審査状態「審査中」として保存され、申請完了メッセージが表示されている。                                                                                                                                                                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 購入者がサイドバーの「出店申請」を選択する。<br>2. システムが出店申請画面を表示する。<br>3. 購入者が出店申請情報(会社名、担当者、連絡先、出店プラン、事業確認書類など)を入力し、確認画面へ進む。<br>4. システムが入力内容を検証する。<br>5. システムが入力情報確認画面を表示する。<br>6. 購入者が入力情報を確認して、問題がないなら「申請する」を選択する。<br>7. システムが出店申請情報を保存し、申請完了メッセージを表示する。 |
| 代替フロー    | 4a. 必須項目が不足する場合<br>4a-1. システムが不足項目を表示し、申請を受け付けない。<br>4a-2. システムが入力内容を残したまま出店申請画面を表示する。<br>4a-3. 基本フロー3へ戻る。<br><br>4b. 入力形式が不正な場合<br>4b-1. システムが入力エラーを表示する。<br>4b-2. システムが入力内容を残したまま出店申請画面を表示する。<br>4b-3. 基本フロー3へ戻る。<br><br>6a. 入力内容を修正する場合<br>6a-1. 購入者が確認画面で「修正する」を選ぶ。<br>6a-2. システムが入力内容を残したまま出店申請画面を表示する。<br>6a-3. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・リンクの表示(「出店申請」／「出店申請状況」)はEC-B18の関連情報を参照。<br>・再申請の場合は出店申請状況画面の「再申請する」から基本フロー3に入り、前回の申請内容が入った状態で出店申請画面を表示する。事業確認書類はもう一度選択する。 |
