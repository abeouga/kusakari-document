# EC-B21 アカウントを退会する

| 記述項目     | 記述内容                                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 退会画面で削除確認を行い、アカウントを削除する。                                                                                                                             |
| アクター     | 利用者（購入者・事業者）                                                                                                                                         |
| 事前条件     | ログイン状態である。                                                                                                                                           |
| 事後条件     | ログイン状態が削除される。                                                                                                                                        |
| 基本フロー    | 1. 利用者が退会手続きへ進む。<br>2. システムが削除確認を表示する。<br>3. 利用者が削除を確定する。<br>4. システムがアカウントを削除し、ログイン表示を解除する。<br>ログイン状態でない場合は => 代替フロー1へ。<br>確認画面で取り消した場合は => 代替フロー2へ。 |
| 代替フロー    | 1. ログイン状態でない場合<br>1-1. システムが退会操作を利用できない状態で表示する。<br><br>2. 確認画面で取消を選んだ場合<br>2-1. システムが削除を行わず元の画面へ戻す。                                                  |
