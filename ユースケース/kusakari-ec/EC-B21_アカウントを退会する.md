#### EC-B21 アカウントを退会する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 退会画面で注意事項に同意したうえで退会し、アカウントを利用できない状態にする。 |
| アクター     | 利用者(購入者・出店者)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事前条件     | ログイン状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | アカウントが退会状態になって利用できなくなり、ログアウト状態になっている。 |
| 基本フロー    | 1. 利用者がアカウントのメニュー「退会」を開く(EC-C01)。<br>2. システムが「退会」画面を表示する。「退会」画面には、「退会の前にご確認ください」として退会すると元に戻せないことなどの注意事項、「注意事項を確認し、退会することに同意します」チェックボックス、「戻る」ボタン、押せない状態の「アカウントを削除する」ボタンを表示する。<br>3. 利用者が注意事項を確認し、「注意事項を確認し、退会することに同意します」チェックボックスにチェックを付ける。<br>4. システムが「アカウントを削除する」ボタンを押せる状態にする。<br>5. 利用者が「アカウントを削除する」ボタンをクリックする。<br>6. システムがログイン状態を確認する。<br>7. システムが利用者に未完了の注文がないか確認する。<br>8. 利用者が出店者の場合、システムが出品中の商品、受けた未完了の注文、未処理のキャンセル申請がないか確認する。<br>9. システムがアカウントを退会状態にし、ログアウト状態にする。<br>10. システムが「メイン」画面へ遷移し、「退会が完了しました。ご利用ありがとうございました。」と表示する。 |
| 代替フロー    | 3a. 退会をやめる場合<br>3a-1. 利用者が「戻る」ボタンをクリックするか、「退会」画面から移動する。<br>3a-2. システムがアカウントを削除せず、元の画面を表示する。<br>3a-3. ユースケースを終了する。<br><br>4a. 利用者がチェックを外した場合<br>4a-1. システムが「アカウントを削除する」ボタンを再び押せない状態にする。<br>4a-2. 基本フロー3へ戻る。<br><br>6a. セッションが切れている場合<br>6a-1. システムがアカウントを削除せず、「ログインの有効期限が切れました。もう一度ログインしてください。」と「ログインする」ボタンを表示する。<br>6a-2. 利用者が「ログインする」ボタンをクリックする。<br>6a-3. システムが「ログイン」画面を表示する。<br>6a-4. 利用者がログインする。<br>6a-5. システムが同意チェックを外した状態で「退会」画面を表示する。<br>6a-6. 基本フロー3へ戻る。<br><br>7a. 未完了の注文がある場合<br>7a-1. システムがアカウントを削除せず、「受け渡しが完了していない注文があるため退会できません。」と表示する。<br>7a-2. システムが対象の注文(注文番号と注文状態)と「注文履歴を確認する」リンクを表示する。<br>7a-3. ユースケースを終了する。<br><br>8a. 出品中の商品がある場合<br>8a-1. システムがアカウントを削除せず、「出品中の商品があるため退会できません。すべての商品を販売停止にしてから再度お試しください。」と表示する。<br>8a-2. システムが出店者専用画面の商品一覧への「商品一覧を確認する」リンクを表示する。<br>8a-3. ユースケースを終了する。<br><br>8b. 受けた未完了の注文または未処理のキャンセル申請がある場合<br>8b-1. システムがアカウントを削除せず、「引き渡しが完了していない注文、または処理していないキャンセル申請があるため退会できません。」と表示する。<br>8b-2. システムが出店者専用画面の注文一覧(キャンセル申請の処理も同じ画面で行う。EC-S08、EC-S13)への「注文一覧・キャンセル申請を確認する」リンクを表示する。<br>8b-3. ユースケースを終了する。<br><br>9a. 通信に失敗した場合<br>9a-1. システムが「退会処理に失敗しました。時間をおいて再度お試しください。」と表示する。<br>9a-2. システムがアカウントを削除せず、「退会」画面を表示したままにする。<br>9a-3. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・未ログイン時は「退会」画面への導線を表示しない。「退会」画面のURLに直接アクセスした場合は、ログイン画面へ誘導する。<br>・「未完了の注文」は、「引き渡し完了」「キャンセル済み」になっていない注文を指す。注文履歴で非表示にした注文も含む。<br>・「出品中の商品」は、自店舗で「公開中」の商品を指す。<br>・未完了の注文と出品中の商品の確認は、「退会」画面を開いた後に状況が変わる可能性があるため、「アカウントを削除する」ボタンを押した時点で行う。<br>・「受けた未完了の注文」は、自店舗の注文のうち「引き渡し完了」「キャンセル済み」になっていない注文を指す。<br>・退会しても、アカウントに紐づく注文データは注文実績のために残す。庭プロジェクト・店舗・商品のデータも残すが、退会したアカウントではログインできないため利用できない。<br>・運営者アカウントはこの画面から退会できない。 |
