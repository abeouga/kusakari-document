#### EC-B24 買い物リストを確認する(EC)

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 庭プロジェクトに配置された庭オブジェクトに紐づく商品の一覧を、在庫やカート内の点数とあわせて確認する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 事前条件     | ログイン済みである。<br>対象の庭プロジェクトが保存されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 事後条件     | 対象の庭プロジェクトの買い物リストが表示され、カートに追加する商品を選択できる状態になっている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 基本フロー    | 1. 購入者がCanvasの買い物リストまたはカート画面の「庭の買い物リスト」タブからECの買い物リストを開く。<br>2. システムが対象の庭プロジェクトに配置されている庭オブジェクトとその個数を取得する。<br>3. システムが各庭オブジェクトに紐づく商品の情報、在庫、カート内の点数を取得する。<br>4. システムが商品ごとに、チェックボックス、商品画像、商品名、数量、商品価格、小計、在庫、カート内の点数(「カートにn点」)を一覧表示する。<br>5. 購入者が買い物リストの内容を確認する。                                                                                                                                                                                                                                                                                |
| 代替フロー    | 1a. カート画面の「庭の買い物リスト」タブから開いた場合<br>1a-1. システムが購入者の保存済みの庭プロジェクトの一覧を表示する。<br>1a-2. 購入者が対象の庭プロジェクトを選ぶ。<br>1a-3. 基本フロー2へ進む。<br><br>2a. 配置されたオブジェクトがない場合<br>2a-1. システムが買い物リストが空であることを表示し、Canvasへ戻る導線を表示する。<br>2a-2. ユースケースを終了する。<br><br>2b. 庭プロジェクトが見つからない場合(削除済み、他の購入者のプロジェクトなど)<br>2b-1. システムがエラーメッセージを表示し、買い物リストを表示しない。<br>2b-2. ユースケースを終了する。<br><br>3a. 紐づく商品が存在しない場合<br>3a-1. システムがその庭オブジェクトに対応する商品がないことを表示し、チェックボックスを選択できないようにする。<br>3a-2. 基本フロー4へ進む。<br><br>4a. 購入可能な商品でない商品(販売停止、審査中など)または在庫不足の商品がある場合<br>4a-1. システムがその商品に購入できないこと、または在庫不足であることを表示する。<br>4a-2. システムがその商品のチェックボックスを選択できないようにする。<br>4a-3. 基本フロー5へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カートには商品が「カートにn点」の形で表示され、カートにない場合は表示しない。<br>・在庫不足は「在庫数 < カート内の点数+数量」の場合とする。<br>・在庫をどの店舗の在庫で判定するかは、商品と店舗の関係が決まってから決める。(要確認)<br>・配置されたオブジェクトがない場合(代替フロー2a)の扱いは未定。(要確認)<br>・庭プロジェクトが見つからない場合(代替フロー2b)の扱いは未定。(要確認) |
