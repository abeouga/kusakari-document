#### EC-B24 買い物リストを確認する(EC)

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | ECの「ショッピングカート」画面の「庭に設置したものから追加」で、庭プロジェクトに配置された庭オブジェクトに紐づく商品と、ECで買い物リストに追加した商品の一覧を、在庫やカートに入っているかとあわせて確認する。 |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 購入者アカウントでログインしている。<br>対象の庭プロジェクトが保存されている。<br>Canvasの庭シミュレーション画面で対象の庭プロジェクトを開いている。 |
| 事後条件     | 対象の庭プロジェクトの買い物リストが「庭に設置したものから追加」ダイアログに表示され、カートに追加する商品を選択できる状態になっている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 購入者がCanvasの庭シミュレーション画面で、サイドバーの「買い物リスト（n）」タブをクリックする(UC-09)。<br>2. システムが「(庭の名前)の買い物リスト」を表示する。<br>3. 購入者が「リストを確認」ボタンをクリックする。<br>4. システムがECの「ショッピングカート」画面を開き、「庭に設置したものから追加」ダイアログを、対象の庭プロジェクトを選んだ状態で表示する。ダイアログには、「庭をえらび、カートに入れる商品にチェックしてください。」と、購入者の保存済みの庭プロジェクトの一覧(サムネイル、庭の名前、商品の種類数)を表示する。<br>5. システムが選ばれた庭プロジェクトに配置されている庭オブジェクトとその個数、ECで買い物リストに追加された商品を取得する。<br>6. システムが各商品の情報、在庫、カートに入っているかを取得する。<br>7. システムがダイアログに、商品ごとにチェックボックス、商品画像、商品名、数量と在庫(「必要数 n点・店舗在庫 n点」)、小計(価格×必要数)を一覧表示する。<br>8. 購入者が買い物リストの内容を確認する。 |
| 代替フロー    | 1a. ECの「ショッピングカート」画面から開く場合<br>1a-1. 購入者が共通ヘッダーの「カート」リンクをクリックする。<br>1a-2. システムが「ショッピングカート」画面を表示する(EC-B08)。<br>1a-3. 購入者がカートの商品の一覧の下にある「庭に設置したものから追加」をクリックする。<br>1a-4. システムが「庭に設置したものから追加」ダイアログを、庭プロジェクトの一覧の先頭の庭を選んだ状態で表示する。<br>1a-5. 基本フロー5へ進む。<br><br>4a. 保存済みの庭プロジェクトがない場合<br>4a-1. システムが「庭はまだありません。Canvasで庭をつくると、ここから追加できます。」と表示する。<br>4a-2. ユースケースを終了する。<br><br>4b. 別の庭プロジェクトの買い物リストを確認する場合<br>4b-1. 購入者が庭プロジェクトの一覧から別の庭をクリックする。<br>4b-2. 基本フロー5へ戻る。<br><br>5a. 配置されたオブジェクトもECで追加した商品もない場合<br>5a-1. システムが「この庭に配置した商品はありません。」と表示する。<br>5a-2. ユースケースを終了する。<br><br>5b. 庭プロジェクトが見つからない場合(削除済み、他の購入者のプロジェクトなど)<br>5b-1. システムが「庭が見つかりません。」と表示し、買い物リストを表示しない。<br>5b-2. ユースケースを終了する。<br><br>5c. 庭シミュレーション(Canvas)に接続できない場合<br>5c-1. システムが「庭の買い物リストを取得できません。接続を確認して再試行してください。」と「再取得」ボタンを表示する。<br>5c-2. 購入者が「再取得」ボタンをクリックする。<br>5c-3. 基本フロー5へ戻る。<br><br>6a. 紐づく商品が存在しない場合<br>6a-1. システムがその庭オブジェクトに「対応する販売商品がありません」と表示し、チェックボックスを選択できないようにする。<br>6a-2. 基本フロー7へ進む。<br><br>6b. 1つの庭オブジェクトに候補の商品が複数ある場合<br>6b-1. システムが「購入商品」の選択欄(初期表示「購入商品を選択」)に候補の商品(商品名 / 価格)を表示し、選ぶまでは「購入商品を選択してください」と表示してチェックボックスを選択できないようにする。<br>6b-2. 購入者が「購入商品」から商品を選択する。<br>6b-3. 基本フロー7へ進む。<br><br>7a. 購入可能な商品でない商品(販売終了、公開停止、店舗の停止・閉鎖など)、在庫不足の商品、カートの数量と合わせて99点を超える商品がある場合<br>7a-1. システムがその商品に「販売終了」「在庫不足」「カートの数量と合わせると上限99点を超えます」のいずれかを表示する。<br>7a-2. システムがその商品のチェックボックスを選択できないようにする。<br>7a-3. 基本フロー8へ進む。<br><br>7b. すでにカートに入っている商品がある場合<br>7b-1. システムがその商品に「カートに入っています」と表示し、チェックボックスを選択できないようにする。<br>7b-2. 基本フロー8へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・在庫不足は「在庫数 < 必要数」の場合とする。<br>・数量(必要数)は配置されている庭オブジェクトの個数とする。ECで追加した商品は、庭に配置していなければ1点とする。<br>・在庫と価格は、商品が属する店舗(受取店舗)のものを表示する。<br>・表示中も、3秒ごとと画面に戻ったときに、在庫・カートの内容・庭プロジェクトの変更を反映する。<br>・「すべて選択」ボタンで、選択できる商品のチェックボックスをまとめて選択できる。<br>・「キャンセル」ボタンかダイアログを閉じる操作で、カートに追加せずにダイアログを閉じる。<br>・店舗側のアカウント(出店者のオーナー・担当者)と出店申請用アカウントでは、カートと庭の買い物リストを使えない(EC-B07)。 |
