#### EC-B24 買い物リストを確認する(EC)

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 庭プロジェクトに配置された庭オブジェクトに紐づく商品と、ECで買い物リストに追加した商品の一覧を、在庫やカート内の点数とあわせて確認する。 |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | ログイン済みである。<br>対象の庭プロジェクトが保存されている。<br>Canvasの庭シミュレーション画面で対象の庭プロジェクトを開いている。 |
| 事後条件     | 対象の庭プロジェクトの買い物リストが表示され、カートに追加する商品を選択できる状態になっている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 基本フロー    | 1. 購入者がCanvasの庭シミュレーション画面で、サイドバーの「買い物リスト（n）」タブをクリックする。<br>2. システムが「(庭の名前)の買い物リスト」を表示する。<br>3. 購入者が「ECで買い物リストを確認」ボタンをクリックする。<br>4. システムが対象の庭プロジェクトに配置されている庭オブジェクトとその個数、ECで買い物リストに追加された商品を取得する。<br>5. システムが各商品の情報、在庫、カート内の点数を取得する。<br>6. システムがECの「(庭の名前)の買い物リスト」画面に、商品ごとにチェックボックス、商品画像、商品名、数量(「必要数 n点」)、商品価格、小計、在庫(「店舗在庫 n点」)、カート内の点数(「カートにn点」)を一覧表示する。<br>7. 購入者が買い物リストの内容を確認する。 |
| 代替フロー    | 1a. ECの「ショッピングカート」画面の「庭の買い物リスト」タブから開く場合<br>1a-1. 購入者が「メイン」画面から共通ヘッダーの「カート」リンクをクリックする。<br>1a-2. システムが「ショッピングカート」画面を表示する。<br>1a-3. 購入者が「庭の買い物リスト」タブをクリックする。<br>1a-4. システムが「庭の買い物リスト」に購入者の保存済みの庭プロジェクトの一覧を表示する。<br>1a-5. 購入者が対象の庭プロジェクトの「買い物リストを開く」ボタンをクリックする。<br>1a-6. 基本フロー4へ進む。<br><br>4a. 配置されたオブジェクトもECで追加した商品もない場合<br>4a-1. システムが「この庭の買い物リストは空です。」と表示する。<br>4a-2. ユースケースを終了する。<br><br>4b. 庭プロジェクトが見つからない場合(削除済み、他の購入者のプロジェクトなど)<br>4b-1. システムが「庭が見つかりません。」と表示し、買い物リストを表示しない。<br>4b-2. ユースケースを終了する。<br><br>4c. 庭シミュレーション(Canvas)に接続できない場合<br>4c-1. システムが「庭の買い物リストを取得できません。接続を確認して再試行してください。」と「再取得」ボタンを表示する。<br>4c-2. 購入者が「再取得」ボタンをクリックする。<br>4c-3. 基本フロー4へ戻る。<br><br>5a. 紐づく商品が存在しない場合<br>5a-1. システムがその庭オブジェクトに「対応する販売商品がありません」と表示し、チェックボックスを選択できないようにする。<br>5a-2. 基本フロー6へ進む。<br><br>5b. 1つの庭オブジェクトに候補の商品が複数ある場合<br>5b-1. システムが「購入商品」の選択欄に候補の商品を表示する。<br>5b-2. 購入者が「購入商品」から商品を選択する。<br>5b-3. 基本フロー6へ進む。<br><br>6a. 購入可能な商品でない商品(販売終了、公開停止など)または在庫不足の商品がある場合<br>6a-1. システムがその商品に「販売終了」または「在庫不足」と表示する。<br>6a-2. システムがその商品のチェックボックスを選択できないようにする。<br>6a-3. 基本フロー7へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カートには商品が「カートにn点」の形で表示され、カートにない場合は表示しない。<br>・在庫不足は「在庫数 < カート内の点数+数量」の場合とする。<br>・数量は配置されている庭オブジェクトの個数とする。ECで追加した商品は、庭に配置していなければ1点とする。<br>・在庫と価格は、カートで選んでいる受取店舗(画面上の「受取店舗」)のものを表示する。<br>・表示中も、在庫・カート内の点数・庭プロジェクトの変更を定期的に反映する。<br>・チェックボックスは「全選択」「選択解除」ボタンでまとめて全選択・選択解除できる。 |
