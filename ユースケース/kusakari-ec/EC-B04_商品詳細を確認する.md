#### EC-B04 商品詳細を確認する

| 記述項目     | 記述内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| ユースケース概要 | 選択した商品の詳細を確認する。                                                       |
| アクター     | 購入者                                                                   |
| 事前条件     | 商品一覧に商品が表示されている。                                                      |
| 事後条件     | 選択した商品の詳細が表示されている。                                                    |
| 基本フロー    | 1. 購入者が商品を選択する。<br>2. システムが商品情報を表示する。<br>3. 購入者が商品情報を確認する。            |
| 代替フロー    | 2a. 商品が見つからない場合<br>2a-1. システムが商品が見つからないことを表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・購入者向けの画面には、購入可能な商品(商品審査状態が「承認」かつ販売状態が「販売中」の商品)だけを表示する。               |
