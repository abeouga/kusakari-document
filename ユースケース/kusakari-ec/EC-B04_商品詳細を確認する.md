# EC-B04 商品詳細を確認する

| 記述項目     | 記述内容                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品画像・説明・価格など、選択商品の詳細を確認する。                                                                                          |
| アクター     | 利用者（購入者）                                                                                                            |
| 事前条件     | 商品一覧に商品が表示されている。                                                                                                    |
| 事後条件     | 選択した商品の詳細が表示される。                                                                                                    |
| 基本フロー    | 1. 利用者が商品を選択する。<br>2. システムが商品情報と画像を表示する。<br>画像または商品情報を取得できない場合は => 代替フロー1へ。<br>3. 利用者が画像を切り替え、説明・価格・仕様・季節の育て方を確認する。 |
| 代替フロー    | 1. 商品が見つからないか情報を取得できない場合<br>1-1. システムが該当状態または通信エラーを表示する。                                                            |
