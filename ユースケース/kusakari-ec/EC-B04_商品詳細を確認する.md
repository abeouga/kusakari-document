#### EC-B04 商品詳細を確認する

| 記述項目     | 記述内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| ユースケース概要 | 選択した商品の詳細を確認する。                                                       |
| アクター     | 購入者                                                                   |
| 事前条件     | 「メイン」画面の商品一覧に商品が表示されている。                                                      |
| 事後条件     | 選択した商品の詳細が「植物について」ダイアログに表示されている。                                                    |
| 基本フロー    | 1. 購入者が商品一覧で対象商品の画像または商品名をクリックする。<br>2. システムが「植物について」ダイアログに商品情報を表示する。<br>3. 購入者が商品情報を確認する。            |
| 代替フロー    |  |
| 関連情報     | ・購入者向けの画面には、購入可能な商品(EC-B03)だけを表示する。 |
