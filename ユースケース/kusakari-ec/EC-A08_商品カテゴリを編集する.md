#### EC-A08 商品カテゴリを編集する

| 記述項目     | 記述内容                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者が既存のカテゴリを編集する。                                                                       |
| アクター     | 運営者                                                                                |
| 事前条件     | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。<br>編集対象のカテゴリが登録されている。 |
| 事後条件     | カテゴリ一覧に編集内容が反映されている。                                                                    |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「カテゴリ管理」を開く(EC-C02)。<br>2. システムが「カテゴリ管理」画面にカテゴリ一覧と「カテゴリ名」入力欄を表示する。<br>3. 運営者が対象カテゴリの「編集」ボタンをクリックする。<br>4. システムが現在のカテゴリ名を「カテゴリ名」入力欄に表示する。<br>5. 運営者が「カテゴリ名」入力欄のカテゴリ名を編集する。<br>6. 運営者が「保存」ボタンをクリックする。<br>7. システムがカテゴリ名を検証する。<br>8. システムがカテゴリ名を変更し、「保存しました。」を表示してカテゴリ一覧を更新する。 |
| 代替フロー    | 7a. カテゴリ名が空、30文字を超える、または同じ名前のカテゴリがすでにある場合<br>7a-1. システムが入力エラー(空白のみの場合は「カテゴリ名を入力してください。」、同じ名前がある場合は「同じカテゴリがあります。」)を表示し、変更前の内容を維持する。<br>7a-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カテゴリ名を変更すると、そのカテゴリの商品にも新しいカテゴリ名が表示される。 |
