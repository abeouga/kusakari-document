#### EC-A08 商品カテゴリを編集する

| 記述項目     | 記述内容                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者が既存のカテゴリを編集する。                                                                       |
| アクター     | 運営者                                                                                |
| 事前条件     | 運営者アカウントでログインしている。<br>カテゴリ管理画面に編集対象がある。                                                                       |
| 事後条件     | カテゴリ一覧に編集内容が反映されている。                                                                    |
| 基本フロー    | 1. 運営者が対象カテゴリの「編集」を選ぶ。<br>2. システムが現在のカテゴリ名を入力欄に表示する。<br>3. 運営者がカテゴリ名を編集して保存する。<br>4. システムがカテゴリ一覧を更新する。 |
| 代替フロー    | 3a. カテゴリ名が空、30文字を超える、または同じ名前のカテゴリがすでにある場合<br>3a-1. システムが入力エラーを表示し、変更前の内容を維持する。<br>3a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カテゴリ名を変更すると、そのカテゴリの商品にも新しいカテゴリ名が表示される。 |
