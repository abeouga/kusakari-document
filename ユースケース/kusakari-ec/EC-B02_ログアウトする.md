#### EC-B02 ログアウトする

| 記述項目     | 記述内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| ユースケース概要 | ログイン中の利用者がログアウトする。                                                          |
| アクター     | 利用者(購入者・出店者)                                                                |
| 事前条件     | ログイン状態になっている。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。                                                               |
| 事後条件     | ログアウト状態になっており、共通ヘッダーに「ログイン」ボタンが表示されている。                                       |
| 基本フロー    | 1. 利用者がアカウントのメニュー「アカウント情報」を開く(EC-C01)。<br>2. システムが「アカウント情報」画面を表示する。<br>3. 利用者が「ログアウト」ボタンをクリックする。<br>4. システムがログアウト処理を行う。<br>5. システムが「メイン」画面を表示し、共通ヘッダーに「ログイン」ボタンを表示する。 |
| 代替フロー    |  |
| 関連情報     | ・庭シミュレーション画面からアカウント情報画面へ移動するときは、庭プロジェクトの保存が終わってから移動する(UC-07)。 |
