#### EC-B02 ログアウトする

| 記述項目     | 記述内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| ユースケース概要 | ログイン中の利用者がログアウトする。                                                          |
| アクター     | 利用者(購入者・出店者)                                                                |
| 事前条件     | ログイン状態になっている。                                                               |
| 事後条件     | ログアウト状態になっており、ヘッダーに「ログイン」ボタンが表示されている。                                       |
| 基本フロー    | 1. 利用者がアカウント情報画面で「ログアウト」を選択する。<br>2. システムがログアウト処理を行う。<br>3. システムがヘッダーに「ログイン」ボタンを表示する。 |
| 代替フロー    |  |
| 関連情報     | ・庭シミュレーション画面からアカウント情報画面へ移動するときは、庭プロジェクトの保存が終わってから移動する(UC-07)。 |
