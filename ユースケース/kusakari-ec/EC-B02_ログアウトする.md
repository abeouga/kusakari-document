#### EC-B02 ログアウトする

| 記述項目     | 記述内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| ユースケース概要 | ログイン中の利用者がログアウトする。                                                          |
| アクター     | 利用者(購入者・出店者)                                                                |
| 事前条件     | ログイン状態になっている。                                                               |
| 事後条件     | ログアウト状態になっており、ヘッダーに「ログイン」ボタンが表示されている。                                       |
| 基本フロー    | 1. 利用者が「ログアウト」を選択する。<br>2. システムがログアウト処理を行う。<br>3. システムがヘッダーに「ログイン」ボタンを表示する。 |
| 代替フロー    | 1a. 庭プロジェクトの保存が完了していない場合<br>1a-1. システムが「保存されていません」と警告メッセージを表示する。<br>1a-2. 利用者がログアウトを確定すると基本フロー2へ進み、取り消すとユースケースを終了する。 |
| 関連情報     | ・保存されていない場合の警告はUC-07と同じとする。 |
