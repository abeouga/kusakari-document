#### EC-S03 商品を登録する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 新しい商品情報を登録する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 出店者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 事後条件     | 新しい商品が登録され、所属店舗で入力した在庫数・「公開中」の状態で購入者向けの画面に表示されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面を表示する。<br>3. 出店者が「商品を登録」ボタンをクリックする。<br>4. システムが「商品登録」画面を表示し、「商品情報」の入力フォームを表示する。<br>5. 出店者が「商品名」「商品番号」「商品説明」「税込価格」「在庫数」の入力欄に入力する。<br>6. 出店者が「カテゴリ」の一覧からカテゴリを選択する。<br>7. 出店者が「画像を追加」をクリックし、商品画像のファイルを選択する。<br>8. システムが画像を検証して保存し、商品画像のサムネイルを表示する。<br>9. 出店者が「サイズ」欄を開き、サイズを入力する。<br>10. 出店者が「詳しい情報」欄を開き、「生産者名」の入力欄に入力する。<br>11. 出店者が「次へ」ボタンをクリックする。<br>12. システムが商品情報の入力内容を検証し、「庭オブジェクト」の設定を表示する。<br>13. 出店者が「次へ」ボタンをクリックする。<br>14. システムが「確認」画面に入力内容を表示する。<br>15. 出店者が「出品する」ボタンをクリックする。<br>16. システムが入力内容を検証し、商品を登録する。<br>17. システムが「商品管理」画面を表示し、登録結果を表示する。 |
| 代替フロー    | 8a. 画像が6枚以上になる場合、またはPNG・JPEG・WebP以外の形式や5MBを超えるファイルの場合<br>8a-1. システムが入力エラーを表示し、画像を追加しない。<br>8a-2. 基本フロー7へ戻る。<br><br>12a. 入力値が不正な場合<br>12a-1. システムが入力エラーを表示し、次の手順へ進まない。<br>12a-2. 基本フロー5へ戻る。<br><br>16a. 入力値が不正な場合<br>16a-1. システムが入力エラーを表示し、商品を登録しない。<br>16a-2. 基本フロー5へ戻る。                                                                                                                                                                                                                                                                                                                                     |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・出店者が管理する店舗は、所属する1店舗とする。<br>・登録した商品は事前の審査なしで公開される。運営者が不適切と判断した場合は公開を停止する(EC-A10)。<br>・公開したくない場合は、登録後に販売状態を「非表示」にする(EC-S06)。                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
