#### EC-S03 商品を登録する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 新しい商品情報を登録する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| アクター     | 出店者(オーナー、MANAGER(店長)) |
| 事前条件     | 出店者(オーナー、または対象店舗のMANAGER)のアカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 新しい商品が商品番号を採番されて選択中の店舗に登録され、入力した在庫数・「公開中」の状態で保存されている。店舗が購入者に公開されていれば、購入者向けの画面に表示されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面を表示する。<br>3. 出店者が「新しい商品」ボタンをクリックする。<br>4. システムが「商品登録」画面を表示し、「商品情報」の入力フォームを表示する。<br>5. 出店者が「商品名」「商品説明」「税込価格」「在庫数」の入力欄に入力する。<br>6. 出店者が「カテゴリ」の一覧からカテゴリを選択する。<br>7. 出店者が「サイズ」欄を開き、「樹齢目安」「鉢径」を入力する。<br>8. 出店者が「詳しい情報」欄を開き、「生産者名」の入力欄に入力する。<br>9. 出店者が「次へ」ボタンをクリックする。<br>10. システムが商品情報の入力内容を検証し、「画像」の設定を表示する。<br>11. 出店者が「画像を追加」をクリックし、商品画像のファイルを選択する。<br>12. システムが画像を検証して保存し、商品画像のサムネイルを表示する。<br>13. 出店者が「次へ」ボタンをクリックする。<br>14. システムが商品画像が1枚以上あることを検証し、「庭オブジェクト」の設定を表示する。<br>15. 出店者が「植物の高さ」などの特徴を入力する。<br>16. 出店者が「次へ」ボタンをクリックする。<br>17. システムが庭オブジェクトの入力内容を検証し、「確認」画面に入力内容を表示する。<br>18. 出店者が「出品する」ボタンをクリックする。<br>19. システムが入力内容を検証し、商品番号を採番して商品を登録する。<br>20. システムが「商品管理」画面を表示し、登録結果**と商品番号**を表示する。 |
| 代替フロー    | 10a. 入力値が不正な場合（必須項目が未入力、在庫数が1未満など）<br>10a-1. システムが入力エラーを表示し、次の手順へ進まない。<br>10a-2. 基本フロー5へ戻る。<br><br>12a. 画像が6枚以上になる場合、またはPNG・JPEG・WebP以外の形式や5MBを超えるファイルの場合<br>12a-1. システムが入力エラーを表示し、画像を追加しない。<br>12a-2. 基本フロー11へ戻る。<br><br>14a. 商品画像が1枚もない場合<br>14a-1. システムが入力エラーを表示し、次の手順へ進まない。<br>14a-2. 基本フロー11へ戻る。<br><br>15a. 出店者が「AIで生成」ボタンをクリックした場合<br>15a-1. システムが1枚目の商品画像と商品情報から特徴を推定し、入力欄に反映する。<br>15a-2. 基本フロー16へ進む。<br><br>17a. 庭オブジェクトの入力値が不正な場合<br>17a-1. システムが入力エラーを表示し、次の手順へ進まない。<br>17a-2. 基本フロー15へ戻る。<br><br>19a. 入力値が不正な場合<br>19a-1. システムが入力エラーを表示し、商品を登録しない。<br>19a-2. 出店者が「前の手順へ」ボタンで戻り、基本フロー5へ戻る。<br><br>19b. 商品を登録する権限がない場合(STAFF、ロールなし)<br>19b-1. システムが「この操作の権限がありません。」と表示し、商品を登録しない。<br>19b-2. ユースケースを終了する。                                                                                                                                                |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品は1つの店舗に属する。複数の店舗を扱う出店者は、「商品管理」画面の上部で選んだ店舗に商品を登録する(EC-C03)。その店舗が購入者の受取店舗になる。<br>・商品番号は店舗の中で重ならないように採番する。<br>・商品番号はシステムが採番し、出店者は入力しない。登録後は変更できない。<br>・植物の高さは「サイズ」欄ではなく「庭オブジェクト」で入力する。<br>・登録した商品は事前の審査なしで公開される。運営者が不適切と判断した場合は公開を停止する(EC-A10)。<br>・公開したくない場合は、登録後に販売状態を「非表示」にする(EC-S06)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
