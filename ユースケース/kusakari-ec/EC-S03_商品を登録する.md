#### EC-S03 商品を登録する

| 記述項目     | 記述内容                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 新しい商品情報を登録する。                                                                                               |
| アクター     | 出店者                                                                                                         |
| 事前条件     | 出店者アカウントでログインしている。                                                                                          |
| 事後条件     | 新しい商品情報が、選んだ店舗の商品として商品審査状態「審査中」で保存されている。                                                               |
| 基本フロー    | 1. 出店者が管理する店舗を選ぶ。<br>2. 出店者が商品登録を選ぶ。<br>3. システムが商品フォームを表示する。<br>4. 出店者が商品情報(商品名、商品番号、カテゴリ、価格、登録店舗、生産者名、サイズ)を入力して保存する。<br>5. システムが保存結果を表示する。 |
| 代替フロー    | 4a. 入力値が不正な場合<br>4a-1. システムが入力エラーを表示し、商品を登録しない。<br>4a-2. 基本フロー4へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品管理画面では、最初に管理する店舗を選ぶ。<br>・登録直後の販売状態は「販売停止」、在庫数は0とする。(要確認)<br>・商品を店舗ごとに登録するか、出店者単位で登録して在庫・販売状態だけを店舗ごとに持つかは未定。(要確認) |
