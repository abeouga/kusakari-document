#### EC-S03 商品を登録する

| 記述項目     | 記述内容                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 新しい商品情報を登録する。                                                                                                                               |
| アクター     | 出店者                                                                                                                                         |
| 事前条件     | 出店者アカウントでログインしている。                                                                                                                          |
| 事後条件     | 新しい商品が登録され、所属店舗で入力した在庫数・「公開中」の状態で購入者向けの画面に表示されている。 |
| 基本フロー    | 1. 出店者が「商品一覧・登録」で商品登録を選ぶ。<br>2. システムが商品フォームを表示する。<br>3. 出店者が商品情報(商品名、商品番号、カテゴリ、価格、説明、画像、生産者名、サイズ、在庫数)を入力して保存する。<br>4. システムが保存結果を表示する。 |
| 代替フロー    | 3a. 入力値が不正な場合<br>3a-1. システムが入力エラーを表示し、商品を登録しない。<br>3a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・出店者が管理する店舗は、所属する1店舗とする。<br>・登録した商品は事前の審査なしで公開される。運営者が不適切と判断した場合は公開を停止する(EC-A10)。<br>・公開したくない場合は、登録後に販売状態を「非表示」にする(EC-S06)。 |
