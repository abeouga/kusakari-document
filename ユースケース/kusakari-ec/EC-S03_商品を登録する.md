# EC-S03 商品を登録する

| 記述項目     | 記述内容                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品管理画面から新しい商品情報を登録する。                                                                                            |
| アクター     | 出店者                                                                                                              |
| 事前条件     | 商品管理画面を利用できる。                                                                                                    |
| 事後条件     | 新しい商品情報がデータベースに保存される。                                                                                            |
| 基本フロー    | 1. 出店者が商品登録を選ぶ。<br>2. システムが商品フォームを表示する。<br>3. 出店者が商品情報を入力して保存する。<br>入力値が不正な場合は => 代替フロー1へ。<br>4. システムが保存結果を表示する。 |
| 代替フロー    | 1. 入力値が不正な場合<br>1-1. システムが入力エラーを表示し、商品を登録しない。                                                                    |
