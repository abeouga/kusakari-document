# EC-B01 ログインする

| 記述項目     | 記述内容                                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | ログインする                                                                                                                                                                                                             |
| アクター     | 利用者（購入者・事業者）                                                                                                                                                                                                       |
| 事前条件     | ユーザのアカウントがDBに存在すること<br>ログアウト状態であること                                                                                                                                                                                |
| 事後条件     | ログイン状態であり、メインメニューが表示されること                                                                                                                                                                                          |
| 基本フロー    | 1. 利用者はシステムにアクセスし、ヘッダーからログインを選択する<br>2. システムはログインポップアップを表示する<br>3. 利用者がメールアドレスとパスワードを入力してログインボタンを押す。<br>=>メールアドレス、パスワードいずれかが未入力の場合、代替フロー１へ<br>4. システムはアカウントを検索してメールアドレス、パスワードをDBと照会する。<br>=>一致するアカウントがない場合は大体フロー２へ |
| 代替フロー    | 1. メールアドレス、パスワードいずれかが未入力の場合<br>1-1. 入力フィールド下にエラーメッセージを表示する<br>1-2. 基本フロー3へ<br><br>2.一致するアカウントがない場合<br>2-1.「メールアドレスまたはパスワードが正しくありません」と表示する<br>2-2.基本フロー4へ                                                           |
