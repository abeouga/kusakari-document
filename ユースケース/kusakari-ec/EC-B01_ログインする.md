#### EC-B01 ログインする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 利用者がメールアドレスとパスワードを入力してログインする。                                                                                                                                                                                                                                                     |
| アクター     | 利用者(購入者・出店者)、運営者                                                                                                                                                                                                                                                                      |
| 事前条件     | ログアウト状態である。                                                                                                                                                                                                                                               |
| 事後条件     | ログイン状態であり、元の画面またはトップページが表示されている。                                                                                                                                                                                                                                                        |
| 基本フロー    | 1. 利用者がシステムにアクセスし、ヘッダーから「ログイン」を選択する。<br>2. システムがログイン画面を表示する。<br>3. 利用者がメールアドレスとパスワードを入力して「ログイン」ボタンを押す。<br>4. システムがメールアドレスとパスワードを照合する。<br>5. システムがログイン状態にし、元の画面またはトップページを表示する。                                                                                          |
| 代替フロー    | 3a. メールアドレス、パスワードいずれかが未入力の場合<br>3a-1. システムが未入力の項目に入力を求める表示をする。<br>3a-2. 基本フロー3へ戻る。<br><br>4a. 一致するアカウントがない場合<br>4a-1. システムが「メールアドレスまたはパスワードが正しくありません」と表示する。<br>4a-2. 基本フロー3へ戻る。<br><br>4b. 利用停止中または退会済みのアカウントの場合<br>4b-1. システムが「このアカウントは利用できません」と表示し、ログインさせない。<br>4b-2. ユースケースを終了する。<br><br>4c. メールアドレスの確認や追加の本人確認が済んでいない場合<br>4c-1. システムが認証画面で手続きを完了するよう表示する。<br>4c-2. 利用者が手続きを完了すると、基本フロー5へ進む。<br><br>4d. 短時間にログインを繰り返し失敗した場合<br>4d-1. システムが「試行回数が多すぎます。時間をおいて再試行してください」と表示する。<br>4d-2. ユースケースを終了する。 |
