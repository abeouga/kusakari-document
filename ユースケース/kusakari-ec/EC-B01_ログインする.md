#### EC-B01 ログインする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 利用者がメールアドレスとパスワードを入力してログインする。                                                                                                                                                                                                                                                     |
| アクター     | 利用者(購入者・出店者)、運営者                                                                                                                                                                                                                                                                      |
| 事前条件     | ログアウト状態である。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。                                                                                                                                                                                                                                               |
| 事後条件     | ログイン状態であり、元の画面または「メイン」画面が表示されている。                                                                                                                                                                                                                                                        |
| 基本フロー    | 1. 利用者が共通ヘッダーの「ログイン」ボタンをクリックする。<br>2. システムが「ログイン」画面を表示する。<br>3. 利用者が「メールアドレス」欄にメールアドレスを入力する。<br>4. 利用者が「パスワード」欄にパスワードを入力する。<br>5. 利用者が「ログイン」ボタンをクリックする。<br>6. システムが「メールアドレス」欄と「パスワード」欄が入力されていることを検証する。<br>7. システムがメールアドレスとパスワードを照合する。<br>8. システムがログイン状態にし、元の画面または「メイン」画面を表示する。                                                                                          |
| 代替フロー    | 6a. メールアドレス、パスワードいずれかが未入力の場合<br>6a-1. システムが未入力の項目に入力を求める表示をする。<br>6a-2. 基本フロー3へ戻る。<br><br>7a. 一致するアカウントがない場合<br>7a-1. システムが「ログイン」画面に「メールアドレスまたはパスワードが正しくありません。」と表示する。<br>7a-2. 基本フロー3へ戻る。<br><br>7b. 利用停止中または退会済みのアカウントの場合<br>7b-1. システムが「このアカウントは利用できません。」と表示し、ログインさせない。<br>7b-2. ユースケースを終了する。<br><br>7c. メールアドレスの確認や追加の本人確認が済んでいない場合<br>7c-1. システムが「追加の本人確認またはパスワード変更が必要です。認証画面で手続きを完了してください。」または「認証画面でメール確認またはパスワード再設定を完了してください。」と表示する。<br>7c-2. 利用者が「パスワードを忘れた方・追加の本人確認」リンクをクリックする。<br>7c-3. システムが認証画面を表示する。<br>7c-4. 利用者が認証画面で手続きを完了すると、基本フロー8へ進む。<br><br>7d. 短時間にログインを繰り返し失敗した場合<br>7d-1. システムが「試行回数が多すぎます。時間をおいて再試行してください。」と表示する。<br>7d-2. ユースケースを終了する。 |
