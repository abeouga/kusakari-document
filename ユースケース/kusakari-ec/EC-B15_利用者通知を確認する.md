#### EC-B15 利用者通知を確認する

| 記述項目     | 記述内容                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| ユースケース概要 | 通知の一覧と未読・既読などの表示状態を確認する。                                                     |
| アクター     | 購入者                                                                     |
| 事前条件     | ログイン状態である。                                                               |
| 事後条件     | 通知の状態が画面上に表示されている。                                                           |
| 基本フロー    | 1. 購入者が通知一覧を開く。<br>2. システムが通知を表示する。<br>3. 購入者が通知を確認し、必要に応じて既読状態を操作する。        |
| 代替フロー    | 2a. 通知がない場合<br>2a-1. システムが通知なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
