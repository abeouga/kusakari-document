#### EC-B15 利用者通知を確認する

| 記述項目     | 記述内容                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| ユースケース概要 | 通知の一覧と未読・既読などの表示状態を確認する。                                                     |
| アクター     | 購入者                                                                     |
| 事前条件     | ログイン状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | 通知の状態が画面上に表示されている。                                                           |
| 基本フロー    | 1. 購入者がアカウントのメニュー「通知一覧」を開く(EC-C01)。<br>2. システムが通知を取得し、「通知一覧」画面に通知ごとのタイトル、本文、日時と既読状態(既読の通知は「既読」、未読の通知は「既読にする」ボタン)を表示する。<br>3. 購入者が通知を確認する。<br>4. 購入者が必要に応じて、未読の通知の「既読にする」ボタンをクリックする。<br>5. システムが通知を既読にし、その通知に「既読」と表示する。 |
| 代替フロー    | 2a. 通知がない場合<br>2a-1. システムが「通知一覧」画面に「通知はありません。」と表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
