# EC-B15 利用者通知を確認する

| 記述項目     | 記述内容                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 通知の一覧と未読・既読などの表示状態を確認する。                                                                          |
| アクター     | 利用者（購入者）                                                                                          |
| 事前条件     | 利用者向け通知を表示できる。                                                                                    |
| 事後条件     | 通知の状態が画面上に表示される。                                                                                  |
| 基本フロー    | 1. 利用者が通知一覧を開く。<br>2. システムが通知を表示する。<br>通知を取得できない場合は => 代替フロー1へ。<br>3. 利用者が通知を確認し、必要に応じて既読状態を操作する。 |
| 代替フロー    | 1. 通知を取得できない場合<br>1-1. システムが通知の取得エラーまたは通知なしの状態を表示する。                                              |
