#### EC-S02 店舗プロフィールを編集する

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 店舗名・営業時間・店舗紹介などの店舗プロフィールを編集する。 |
| アクター     | 出店者(オーナー、MANAGER(店長))                                                                                       |
| 事前条件     | 出店者(オーナー、または対象店舗のMANAGER)のアカウントでログインしている。<br>「メイン」画面が表示されている。<br>対象の店舗が閉鎖済みではない。 |
| 事後条件     | 店舗紹介画面(EC-B05)に編集内容が反映されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗プロフィール」を開く(EC-C03)。<br>2. システムが「店舗プロフィール」画面に、会社名と、現在の店舗名・担当者・問い合わせメール・所在地・営業時間・店舗紹介を入力欄に表示する。運営者から警告を受けている店舗には、「警告中」のバッジと警告の理由を表示する。<br>3. 出店者が店舗名・担当者・問い合わせメール・所在地・営業時間・店舗紹介の入力欄を編集する。<br>4. 出店者が「店舗情報を保存」ボタンをクリックする。<br>5. システムが入力内容を検証する。<br>6. システムが店舗プロフィールを保存し、「保存しました。」と編集結果を表示する。 |
| 代替フロー    | 1a. 複数の店舗を扱う場合<br>1a-1. 出店者が画面上部の選択欄で、編集する店舗を選択する(EC-C03)。<br>1a-2. 基本フロー2へ進む。<br><br>1b. 「店舗一覧」から開く場合<br>1b-1. 出店者が「店舗一覧」画面で対象店舗の「店舗情報を編集」ボタンをクリックする。<br>1b-2. 基本フロー2へ進む。<br><br>5a. 入力が不正な場合(店舗名・所在地・営業時間が未入力、文字数の超過など)<br>5a-1. システムが入力エラーを表示し、変更を確定しない。<br>5a-2. 基本フロー3へ戻る。<br><br>6a. 表示した後に同じ店舗の別の担当者がプロフィールを更新していた場合<br>6a-1. システムが変更を確定せず、「店舗情報が更新されています。」と表示する。<br>6a-2. システムが最新のプロフィールを入力欄に表示し、購入者に表示される内容の再確認を求める。<br>6a-3. 基本フロー3へ戻る。<br><br>6b. 店舗プロフィールを編集する権限がない場合(STAFF、ロールなし)<br>6b-1. システムが「この操作の権限がありません。」と表示し、変更を確定しない。<br>6b-2. ユースケースを終了する。<br><br>6c. 店舗が閉鎖済みになっていた場合<br>6c-1. システムが「この店舗は閉鎖済みです。」と表示し、変更を確定しない。<br>6c-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・会社名は組織の名前で、出店申請の承認時に決まる(EC-A03)。この画面では変更できない。<br>・入力できる文字数は、店舗名・担当者100文字、問い合わせメール・所在地200文字、営業時間80文字、店舗紹介1000文字までとする。担当者・問い合わせメール・店舗紹介は任意である。<br>・店舗の作成・公開・閉鎖は、オーナーが「店舗一覧」画面で行う。<br>・閉鎖済みの店舗の担当者・問い合わせメールは、閉鎖済みになってから90日後に消す。 |
