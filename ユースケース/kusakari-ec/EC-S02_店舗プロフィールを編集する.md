#### EC-S02 店舗プロフィールを編集する

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 店舗名・営業時間・店舗紹介などの店舗プロフィールを編集する。 |
| アクター     | 出店者                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。                                                                        |
| 事後条件     | 店舗ページ(EC-B05)に編集内容が反映されている。 |
| 基本フロー    | 1. 出店者が「店舗プロフィール」を開く。<br>2. システムが現在の情報を表示する。<br>3. 出店者が店舗名・会社名・担当者・メールアドレス・所在地・営業時間・店舗紹介を編集して保存する。<br>4. システムが編集結果を表示する。 |
| 代替フロー    | 3a. 入力が不正な場合<br>3a-1. システムが入力エラーを表示し、変更を確定しない。<br>3a-2. 基本フロー3へ戻る。<br><br>3b. 表示した後に同じ店舗の別の担当者がプロフィールを更新していた場合<br>3b-1. システムが変更を確定せず、ほかの更新があったことを表示する。<br>3b-2. システムが最新のプロフィールを表示し、購入者に表示される内容の再確認を求める。<br>3b-3. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
