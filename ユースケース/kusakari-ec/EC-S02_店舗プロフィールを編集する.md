# EC-S02 店舗プロフィールを編集する

| 記述項目     | 記述内容                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 店舗紹介などのプロフィール情報を編集する。                                                                                              |
| アクター     | 出店者                                                                                                                |
| 事前条件     | 出店者向けプロフィール画面を利用できる。                                                                                               |
| 事後条件     | 紹介表示に編集内容が反映される。                                                                                                   |
| 基本フロー    | 1. 出店者がプロフィール編集を開く。<br>2. システムが現在の情報を表示する。<br>3. 出店者が紹介内容を編集して保存する。<br>入力が不正な場合は => 代替フロー1へ。<br>4. システムが編集結果を表示する。 |
| 代替フロー    | 1. 入力が不正な場合<br>1-1. システムが入力欄のエラーを表示し、変更を確定しない。                                                                     |
