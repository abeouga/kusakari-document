# EC-B14 注文キャンセルを申請する

| 記述項目     | 記述内容                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 対象注文について理由を入力し、キャンセル申請をする。                                                                                                        |
| アクター     | 利用者（購入者）                                                                                                                          |
| 事前条件     | 注文履歴または購入状況に申請対象の注文が表示されている。                                                                                                      |
| 事後条件     | 申請理由と受付状態が表示される。                                                                                                                  |
| 基本フロー    | 1. 利用者が対象注文のキャンセル申請を選ぶ。<br>2. システムが申請理由の入力欄を表示する。<br>3. 利用者が理由を入力して申請を確定する。<br>4. システムが申請を記録して受付状態を表示する。<br>対象外注文の場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 対象外注文の場合<br>1-1. 受渡済みなど申請対象外の注文では申請操作を表示しない。                                                                                   |
