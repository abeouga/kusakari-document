#### EC-B14 注文キャンセルを申請する

| 記述項目     | 記述内容                                                                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 対象注文について理由を入力し、キャンセル申請をする。                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                        |
| 事前条件     | ログイン状態である。<br>注文履歴に注文が1件以上ある。                                                                                                                                                 |
| 事後条件     | キャンセル申請がキャンセル申請状態「申請中」として保存され、出店者に通知されている。<br>注文履歴にキャンセル申請状態(「申請中」)が表示されている。                                                                                       |
| 基本フロー    | 1. 購入者が対象注文の「キャンセル申請」を選ぶ。<br>2. システムがキャンセル理由の入力欄を表示する。<br>3. 購入者が理由を入力してキャンセルを確定する。<br>4. システムがキャンセル申請を記録する。<br>5. システムが出店者にイベント通知(EC-S11)で申請を知らせる。<br>6. システムが注文履歴にキャンセル申請状態(「申請中」)を表示する。                                           |
| 代替フロー    | 1a. 申請対象外の注文の場合<br>1a-1. システムが、注文状態が「注文受付」「受取準備完了」以外(「引き渡し完了」「キャンセル済み」)の注文や、キャンセル申請状態が「申請中」の注文では申請操作を表示しない。<br>1a-2. ユースケースを終了する。<br><br>3a. 理由が未入力のまま確定した場合<br>3a-1. システムが理由の入力を求めるエラーメッセージを表示し、申請しない。<br>3a-2. 基本フロー3へ戻る。<br><br>3b. 申請をやめる場合<br>3b-1. 購入者が「戻る」を選ぶ。<br>3b-2. システムが申請せずに注文履歴を表示する。<br>3b-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・キャンセル申請は、注文の出店者がEC-S13で承認または却下する。<br>・申請の受付は出店者向けのイベント通知(EC-S11)で知らせる。<br>・処理結果(承認/却下)は利用者通知(EC-B15)とメールで知らせる。却下の場合は却下理由も通知に含める。<br>・却下されたあとは、同じ注文について再び申請できる。 |
