#### EC-B14 注文キャンセルを申請する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 対象注文について理由を入力し、キャンセル申請をする。                                                                                                                                                                                                                                                                                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 事前条件     | ログイン状態である。<br>注文履歴に注文が1件以上ある。<br>「注文履歴」画面で対象注文の詳細が開かれている。 |
| 事後条件     | キャンセル申請がキャンセル申請状態「申請中」として保存され、出店者に通知されている。<br>「注文履歴」画面の対象注文に「キャンセル申請中」が表示されている。 |
| 基本フロー    | 1. 購入者が対象注文の「注文のキャンセルを申請」をクリックする。<br>2. システムが申請欄を開き、「キャンセル理由」の選択肢(「注文内容を間違えた」「受け取りに行けなくなった」「別の商品・店舗で購入する」「その他」)、「詳細」の入力欄、「申請後は取り消せないことを確認しました」チェックボックス、押せない状態の「キャンセルを申請」ボタンを表示する。<br>3. 購入者が「キャンセル理由」からいずれかの理由を選択する。<br>4. 購入者が必要に応じて「詳細」欄に詳細を入力する。<br>5. 購入者が「申請後は取り消せないことを確認しました」チェックボックスにチェックを付ける。<br>6. システムが「キャンセルを申請」ボタンを押せる状態にする。<br>7. 購入者が「キャンセルを申請」ボタンをクリックする。<br>8. システムがキャンセル申請を記録する。<br>9. システムが出店者にイベント通知(EC-S11)で申請を知らせる。<br>10. システムが「キャンセル申請を送信しました。」と表示し、対象注文に「キャンセル申請中」を表示する。 |
| 代替フロー    | 1a. 申請対象外の注文の場合<br>1a-1. システムが、注文状態が「注文受付」以外の注文や、キャンセル申請状態が「申請中」の注文では「注文のキャンセルを申請」を表示しない。「受取準備完了」の注文では「受取準備完了後はキャンセルを申請できません。受取店舗へお問い合わせください。」、申請中の注文では「キャンセルを申請中です。店舗の回答は通知一覧でもお知らせします。」と表示する。<br>1a-2. ユースケースを終了する。<br><br>3a. 申請をやめる場合(基本フロー3〜7の間)<br>3a-1. 購入者が「注文のキャンセルを申請」をクリックして申請欄を閉じる。<br>3a-2. システムが申請せずに「注文履歴」画面を表示する。<br>3a-3. ユースケースを終了する。<br><br>6a. 理由が未選択、または同意にチェックしていない場合<br>6a-1. システムが「キャンセルを申請」ボタンを押せない状態のままにし、申請しない。<br>6a-2. 基本フロー3へ戻る。<br><br>8a. 申請前に注文状態が変わっていた場合(受取準備完了になったなど)<br>8a-1. システムが「注文状態が変わりました。最新の状態を確認してください。」と表示し、申請しない。<br>8a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・キャンセル申請は、注文の出店者がEC-S13で承認または却下する。<br>・申請の受付は出店者向けのイベント通知(EC-S11)で知らせる。<br>・処理結果(承認/却下)は利用者通知(EC-B15)で知らせる。却下の場合は店舗からの回答(却下理由)も通知に含める。<br>・承認されると注文は「キャンセル済み」になり、在庫が店舗に戻る。<br>・却下されたあとも、注文状態が「注文受付」であれば同じ注文について再び申請できる。                                                                                                                                                                                   |
