# EC-A02 アカウントの利用状況の変更

| 記述項目     | 記述内容                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| ユースケース概要 | アカウントを利用停止・解除状態にする。                                                                              |
| アクター     | 管理者（運営者）                                                                                         |
| 事前条件     | アカウント管理画面に利用中のアカウントが表示されている。                                                                     |
| 事後条件     | 対象アカウントが利用停止または利用可能として表示される。                                                                     |
| 基本フロー    | 1. 管理者が対象アカウントを選ぶ。<br>2. 管理者が利用停止または解除を選ぶ。<br>3. システムがアカウント状態を更新して表示する。<br>更新できない場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 対象アカウントが見つからない場合<br>1-1. システムが該当なしを表示し、状態を変更しない。                                              |
