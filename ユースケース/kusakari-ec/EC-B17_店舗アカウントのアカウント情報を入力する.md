# EC-B17 店舗アカウントのアカウント情報を入力する

| 記述項目 | 記述内容 |
|---|---|
| ユースケース概要 | 共通ヘッダーの出店者向けフォームで、会社・屋号、担当者などを入力する。 |
| アクター | 出店希望者 |
| 事前条件 | 共通ヘッダーのアカウント作成フォームを表示できる。 |
| 事後条件 | 入力確認メッセージまたは入力エラーが表示される。 |
| 基本フロー | 1. 出店希望者が出店者向け登録方式を選ぶ。<br>2. システムが会社・屋号、担当者名、連絡先、パスワードなどの入力欄を表示する。<br>3. 出店希望者が必須項目を入力し、送信する。<br>4. システムが入力内容の確認メッセージを表示する。<br>必須項目が不足する場合は => 代替フロー1へ。 |
| 代替フロー | 1. 必須項目が不足する場合<br>1-1. システムが不足項目または確認用パスワードの不一致を表示し、送信内容を確定しない。 |
