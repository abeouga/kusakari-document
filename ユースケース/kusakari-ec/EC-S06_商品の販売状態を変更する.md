# EC-S06 商品の販売状態を変更する

| 記述項目     | 記述内容                                                                                                                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品・店舗ごとの販売状態を切り替える。                                                                                                                                                                                              |
| アクター     | 出店者                                                                                                                                                                                                              |
| 事前条件     | 在庫管理画面に対象商品と店舗が表示されている。                                                                                                                                                                                          |
| 事後条件     | 選択した販売状態がECデータベースに保存される。                                                                                                                                                                                         |
| 基本フロー    | 1. 出店者がヘッダーの「出店者」ボタンを押す<br>2. システムが出店者専用画面を表示する。<br>3. 出品者がサイドバーの「商品一覧・登録」ボタンを押す<br>4. システムが登録している商品一覧を表示する<br>5. 出店者が対象商品・店舗の販売状態を選ぶ。<br>6. システムが変更内容を保存する。<br>保存に失敗した場合は => 代替フロー1へ。<br>7. システムが更新後の販売状態を表示する。 |
| 代替フロー    | 1. 保存に失敗した場合<br>1-1. システムが更新エラーを表示し、最新の販売状態を再取得する。                                                                                                                                                               |
