#### EC-S06 商品の販売状態を変更する

| 記述項目     | 記述内容                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 店舗での商品の販売状態(公開中・非表示)を切り替え、取り扱いをやめる商品を削除する。 |
| アクター     | 出店者(オーナー、MANAGER(店長)、STAFF)                                                                                                                                                                           |
| 事前条件     | 出店者(オーナー、または対象店舗のMANAGER・STAFF)のアカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 選択した商品の販売状態が保存されている。                                                                                                                                                       |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面に、選択中の店舗の商品一覧と、商品ごとの「公開状態」のボタン(「公開中」/「非表示」)を表示する。<br>3. 出店者が対象商品の行の「公開状態」のボタンをクリックする(「公開中」なら非表示に、「非表示」なら再公開に切り替わる)。<br>4. システムが変更内容を保存する。<br>5. システムが更新後の販売状態を表示する。 |
| 代替フロー    | 3a. 複数の商品をまとめて変更する場合<br>3a-1. 出店者が各商品のチェックボックス(または「現在ページの商品をすべて選択」)を選択し、「選択商品を非表示」または「選択商品を再公開」ボタンをクリックする。<br>3a-2. システムが「非表示の確認」または「再公開の確認」ダイアログに、対象店舗、件数、商品名、変更の内容を表示する。<br>3a-3. 出店者が「非表示を確定」または「再公開を確定」ボタンをクリックする。<br>3a-4. 基本フロー4へ進む。<br><br>3b. 取り扱いをやめる商品を削除する場合<br>3b-1. 出店者が対象商品の行の「削除」ボタン(複数の場合はチェックボックスを選択して「選択商品を削除」ボタン)をクリックする。<br>3b-2. システムが「削除の確認」ダイアログに、対象店舗、件数、商品名と、この店舗の管理一覧から削除し復元できないことを表示する。<br>3b-3. 出店者が「削除を確定」ボタンをクリックする。<br>3b-4. システムが店舗の管理一覧から商品を削除する。<br>3b-5. ユースケースを終了する。<br><br>3c. 確認ダイアログで「取消」ボタンをクリックした場合<br>3c-1. システムが販売状態を変更せず、「商品管理」画面の商品一覧を表示する。<br>3c-2. ユースケースを終了する。<br><br>4a. 保存に失敗した場合<br>4a-1. システムが更新エラーを表示し、最新の販売状態を再取得する。<br>4a-2. 基本フロー3へ戻る。<br><br>4b. 操作する権限がない場合(削除はSTAFF・ロールなし、公開状態の変更はロールなし)<br>4b-1. システムが「この操作の権限がありません。」と表示し、変更しない。<br>4b-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品一覧は25件ずつのページに分けて表示し、一括変更では表示中のページの商品を選択できる。商品名などでの検索、カテゴリ・公開状態での絞り込み、並び替え(「登録が新しい順」など)、「条件をリセット」ができる。<br>・「非表示」にした商品は購入者向けの一覧から除外され、カートに入っている場合も購入できなくなる。<br>・運営者による公開停止(EC-A10)、店舗の利用停止(EC-A11)・非公開・閉鎖、組織の受付停止・停止がされている場合は、「公開中」でも購入者向けの画面に表示しない。<br>・削除できるのはオーナーとMANAGERである。公開状態の変更はSTAFFもできる。<br>・削除しても、注文履歴には影響しない。削除した商品は、カートを開いたときにカートから外す(EC-B08)。 |
