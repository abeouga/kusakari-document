#### EC-S06 商品の販売状態を変更する

| 記述項目     | 記述内容                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品の販売状態を店舗ごとに切り替える。                                                                                                                                                           |
| アクター     | 出店者                                                                                                                                                                           |
| 事前条件     | 出店者アカウントでログインしている。<br>商品管理画面が表示されている。                                                                                                                                         |
| 事後条件     | 選択した商品・店舗の販売状態が保存されている。                                                                                                                                                       |
| 基本フロー    | 1. 出店者が管理する店舗を選ぶ。<br>2. システムが選んだ店舗の商品一覧と販売状態を表示する。<br>3. 出店者が商品の販売状態(「販売中」/「販売停止」)を変更する。またはチェックボックスで複数の商品を選択してから販売状態を一括で変更する。<br>4. システムが変更内容を保存する。<br>5. システムが更新後の販売状態を表示する。 |
| 代替フロー    | 4a. 保存に失敗した場合<br>4a-1. システムが更新エラーを表示し、最新の販売状態を再取得する。<br>4a-2. 基本フロー3へ戻る。                                                                                                      |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・同じ商品でも、店舗ごとに「販売中」/「販売停止」を設定できる。<br>・商品管理画面では、最初に管理する店舗を選ぶ。一括変更は選んだ店舗の商品に適用される。                                                                         |
