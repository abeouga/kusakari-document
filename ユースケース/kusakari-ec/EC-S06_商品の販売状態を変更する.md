#### EC-S06 商品の販売状態を変更する

| 記述項目     | 記述内容                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 所属店舗での商品の販売状態(公開中・非表示)を切り替え、取り扱いをやめる商品を削除する。 |
| アクター     | 出店者                                                                                                                                                                           |
| 事前条件     | 出店者アカウントでログインしている。<br>商品一覧または在庫・販売状態の画面が表示されている。 |
| 事後条件     | 選択した商品・店舗の販売状態が保存されている。                                                                                                                                                       |
| 基本フロー    | 1. システムが所属店舗の商品一覧と販売状態(「公開中」/「非表示」)を表示する。<br>2. 出店者が商品の「非表示にする」または「再公開する」を選ぶ。またはチェックボックスで複数の商品を選択してから販売状態を一括で変更する。<br>3. 一括で変更する場合、システムが確認を表示し、出店者が確定する。<br>4. システムが変更内容を保存する。<br>5. システムが更新後の販売状態を表示する。 |
| 代替フロー    | 2a. 取り扱いをやめる商品を削除する場合<br>2a-1. 出店者が「削除」を選ぶ。<br>2a-2. システムが元に戻せないことを示して確認を表示し、出店者が「削除を確定」を選ぶ。<br>2a-3. システムが所属店舗の管理一覧から商品を削除する。<br>2a-4. ユースケースを終了する。<br><br>3a. 一括変更の確認を取り消した場合<br>3a-1. システムが販売状態を変更せず、商品一覧を表示する。<br>3a-2. ユースケースを終了する。<br><br>4a. 保存に失敗した場合<br>4a-1. システムが更新エラーを表示し、最新の販売状態を再取得する。<br>4a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・一括変更は25件まで選択できる。<br>・「非表示」にした商品は購入者向けの一覧から除外され、カートに入っている場合も購入できなくなる。<br>・運営者による公開停止(EC-A10)や出店者の利用停止(EC-A02)がされている場合は、「公開中」でも購入者向けの画面に表示しない。<br>・削除しても、注文履歴と他店舗の販売には影響しない。 |
