#### EC-S06 商品の販売状態を変更する

| 記述項目     | 記述内容                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 所属店舗での商品の販売状態(公開中・非表示)を切り替え、取り扱いをやめる商品を削除する。 |
| アクター     | 出店者                                                                                                                                                                           |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 選択した商品・店舗の販売状態が保存されている。                                                                                                                                                       |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面に所属店舗の商品一覧と販売状態(「公開中」/「非表示」)を表示する。<br>3. 出店者が対象商品の行の「非表示にする」または「再公開する」ボタンをクリックする。複数の商品をまとめて変更する場合は、各商品のチェックボックスを選択してから「選択商品を非表示」または「選択商品を再公開」ボタンをクリックする。<br>4. 一括で変更する場合、システムが「商品状態変更の確認」ダイアログを表示する。<br>5. 一括で変更する場合、出店者が「非表示を確定」または「再公開を確定」ボタンをクリックする。<br>6. システムが変更内容を保存する。<br>7. システムが更新後の販売状態を表示する。 |
| 代替フロー    | 3a. 取り扱いをやめる商品を削除する場合<br>3a-1. 出店者が対象商品の行の「削除」ボタンをクリックする。<br>3a-2. システムが元に戻せないことを示して確認ダイアログを表示する。<br>3a-3. 出店者が「削除を確定」ボタンをクリックする。<br>3a-4. システムが所属店舗の管理一覧から商品を削除する。<br>3a-5. ユースケースを終了する。<br><br>5a. 一括変更の確認ダイアログで「取消」ボタンをクリックした場合<br>5a-1. システムが販売状態を変更せず、「商品管理」画面の商品一覧を表示する。<br>5a-2. ユースケースを終了する。<br><br>6a. 保存に失敗した場合<br>6a-1. システムが更新エラーを表示し、最新の販売状態を再取得する。<br>6a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・一括変更は25件まで選択できる。<br>・「非表示」にした商品は購入者向けの一覧から除外され、カートに入っている場合も購入できなくなる。<br>・運営者による公開停止(EC-A10)や出店者の利用停止(EC-A02)がされている場合は、「公開中」でも購入者向けの画面に表示しない。<br>・削除しても、注文履歴と他店舗の販売には影響しない。 |
