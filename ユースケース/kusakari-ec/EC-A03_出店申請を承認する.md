# EC-A03 出店申請を承認する

| 記述項目     | 記述内容                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 選択した出店申請を選び承認する。                                                                                        |
| アクター     | 管理者（運営者）                                                                                                |
| 事前条件     | 出店審査画面に申請があり、申請が表示されている。                                                                                |
| 事後条件     | 申請状態が承認として表示される。                                                                                        |
| 基本フロー    | 1. 管理者が審査対象を開く。<br>2. システムが申請を表示する。<br>3. 管理者が承認を選ぶ。<br>4. システムが申請状態を承認に更新する。<br>更新に失敗した場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 対象申請が見つからない場合<br>1-1. システムが申請なしの状態を表示する。                                                             |
