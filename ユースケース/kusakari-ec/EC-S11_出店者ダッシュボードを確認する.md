# EC-S11 出店者ダッシュボードを確認する

| 記述項目     | 記述内容                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 注文数、売上、審査待ち件数と各管理画面へのショートカットを確認する。                                                                                                           |
| アクター     | 出店者                                                                                                                                          |
| 事前条件     | 出店者向けダッシュボードを利用できる。                                                                                                                          |
| 事後条件     | 集計と各管理画面へのリンクが表示される。                                                                                                                         |
| 基本フロー    | 1. 出店者がダッシュボードを開く。<br>2. システムが注文数、売上、審査待ち件数を表示する。<br>3. 出店者が受注・注文、商品、売上・精算のショートカットを選ぶ。<br>リンク先を開けない場合は => 代替フロー1へ。<br>4. システムが対応する管理画面を表示する。 |
| 代替フロー    | 1. リンク先を開けない場合<br>1-1. システムが遷移エラーを表示し、出店者はメニューから対象画面を選び直す。                                                                                   |
