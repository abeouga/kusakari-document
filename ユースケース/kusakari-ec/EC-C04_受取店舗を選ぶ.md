#### EC-C04 受取店舗を選ぶ(子ユースケース)

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 「受取店舗を選ぶ」ダイアログで、商品を受け取る店舗を選ぶ。EC-B12から呼び出す。 |
| アクター     | 購入者 |
| 事前条件     | 「ショッピングカート」画面が表示されている。 |
| 事後条件     | 選んだ店舗が受取店舗としてカートに設定され、「ショッピングカート」画面に表示されている。 |
| 基本フロー    | 1. 購入者が「店舗受け取り」欄の「変更」ボタンをクリックする。<br>2. システムが「受取店舗を選ぶ」ダイアログに、既定の地点(「距離の基準」の「東京駅」)から近い順に受取店舗の候補を表示する。<br>3. 購入者が必要に応じて「現在地を使う」ボタンをクリックし、位置情報の利用を許可する。<br>4. システムが現在地から近い順に受取店舗の候補を並べ替えて表示する。<br>5. 購入者が受取店舗を1つ選び、その店舗の「この店舗で受け取る」ボタンをクリックする。<br>6. システムが受取店舗を変更し、選んだ店舗のボタンを「選択中」と表示する。<br>7. 購入者が「受取店舗を選ぶ」ダイアログの「閉じる」ボタンをクリックする。<br>8. システムが「ショッピングカート」画面に変更後の受取店舗と「受取店舗を変更しました。在庫を確認してください。」を表示する。 |
| 代替フロー    | 3a. 位置情報の利用を許可しない場合<br>3a-1. システムが「現在地を取得できませんでした。基準地点を選択してください。」と表示し、既定の地点から近い順の候補を表示したままにする。<br>3a-2. 基本フロー5へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・利用停止中の店舗は候補に表示しない(EC-A11)。<br>・受取店舗を変更すると、カート内の商品の在庫は変更後の店舗の在庫で確認する。 |
