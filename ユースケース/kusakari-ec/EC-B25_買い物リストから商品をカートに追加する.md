#### EC-B25 買い物リストから商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 「庭に設置したものから追加」ダイアログでチェックを付けた商品を、表示されている必要数でまとめてカートに追加する。                                                                                                                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                               |
| 事前条件     | 「ショッピングカート」画面に「庭に設置したものから追加」ダイアログが表示され、対象の庭プロジェクトの買い物リストが表示されている(EC-B24)。 |
| 事後条件     | 選択した商品のうち追加できた商品が、買い物リストの必要数でカートに追加されている。<br>追加できなかった商品とその理由が表示されている。 |
| 基本フロー    | 1. 購入者がカートに追加したい商品のチェックボックスにチェックを付ける。<br>2. システムが追加ボタンの表示を「(選択した商品の必要数の合計)点をカートに追加」に変え、押せる状態にする。<br>3. 購入者が「n点をカートに追加」ボタンをクリックする。<br>4. システムが選択された商品ごとに、購入可能な商品かどうかと在庫(カート内の点数+追加する数量)を検証する。<br>5. システムが選択された商品を、買い物リストの必要数でカートに追加する。<br>6. システムがダイアログを閉じ、「ショッピングカート」画面の上に「(庭の名前)からn種類を追加しました。」と表示して、追加した商品をカートに表示する。 |
| 代替フロー    | 2a. 商品が1つも選択されていない場合<br>2a-1. システムが「カートに追加」ボタンを押せない状態にする。<br>2a-2. 基本フロー1へ戻る。<br><br>4a. 在庫不足または購入可能でない商品が含まれる場合(買い物リスト表示後に在庫が変わった場合など)<br>4a-1. システムが追加できる商品だけをカートに追加し、ダイアログを閉じる。<br>4a-2. システムが「(庭の名前)からn種類を追加しました。」「n種類は追加できませんでした。」と、追加できなかった商品ごとに「(商品名)：(理由)」(「受取店舗の在庫が不足しています。」「販売終了または商品が見つかりません。」「追加すると商品数量の上限99点を超えます。」「カートの商品種類の上限50種類を超えます。」)を表示する。<br>4a-3. 購入者が「庭から選び直す」ボタンをクリックすると、システムが同じ庭プロジェクトを選んだ状態で「庭に設置したものから追加」ダイアログを開き、最新の在庫で買い物リストを表示する(EC-B24の基本フロー5)。<br>4a-4. 購入者が「結果を閉じる」ボタンをクリックすると、システムが結果の表示を消す。<br><br>4b. 買い物リストの表示後に庭プロジェクト・買い物リスト・カートが変更されていた場合<br>4b-1. システムがカートに追加せず、「庭の配置が変更されました。最新の買い物リストから選び直してください。」「買い物リストが更新されました。最新の内容から選び直してください。」「別の操作でカートが更新されました。最新の内容を確認してください。」のいずれかを表示する。<br>4b-2. システムがダイアログに最新の買い物リストを表示する。庭プロジェクトか買い物リストが変わっていた場合は、選択を解除する。<br>4b-3. 基本フロー1へ戻る。<br><br>5a. 通信に失敗した場合<br>5a-1. システムが通信エラー、または「選択した商品はカートに追加されていません。」を表示する。<br>5a-2. システムが選択状態を保持したまま、最新の買い物リストを表示する。<br>5a-3. 購入者が「n点をカートに追加」ボタンをもう一度クリックする。<br>5a-4. 基本フロー4へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・既にカートにある商品は選択できない(EC-B24)。<br>・「すべて選択」ボタンで、選択できる商品をまとめて選択できる。在庫不足などで選択できない商品は選択しない。<br>・カートの上限(1つの商品は99点、50種類)を超える分は追加しない。<br>・受取店舗は商品が属する店舗である(EC-B07)。 |
