#### EC-B25 買い物リストから商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 買い物リストでチェックを付けた商品を、表示されている数量でまとめてカートに追加する。                                                                                                                                                                                                                                                                                                                                      |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                        |
| 事前条件     | ECの買い物リストが表示されている。                                                                                                                                                                                                                                                                                                                                                              |
| 事後条件     | 選択した商品が、買い物リストの数量でカートに追加されている。<br>買い物リストの「カートにn点」が更新されている。                                                                                                                                                                                                                                                                                                                      |
| 基本フロー    | 1. 購入者がカートに追加したい商品のチェックボックスを選択する。<br>2. 購入者が「選択した商品をカートに追加」を選ぶ。<br>3. システムが選択された商品ごとに、購入可能な商品かどうかと在庫(カート内の点数+追加する数量)を検証する。<br>4. システムが選択された商品を、買い物リストの数量でカートに追加する。<br>5. システムが追加完了を表示し、各商品の「カートにn点」を更新してチェックを解除する。                                                                                                                                                                     |
| 代替フロー    | 1a. 商品が1つも選択されていない場合<br>1a-1. システムが「選択した商品をカートに追加」ボタンを無効化する。<br>1a-2. 基本フロー1へ戻る。<br><br>3a. 在庫不足または購入可能でない商品が含まれる場合(買い物リスト表示後に在庫が変わった場合など)<br>3a-1. システムが該当商品と理由を表示し、カートへの追加を行わない。<br>3a-2. システムが最新の在庫で買い物リストを再表示し、購入者が選択し直せるようにする。<br>3a-3. 基本フロー1へ戻る。<br><br>4a. 通信に失敗した場合<br>4a-1. システムが通信エラーを表示し、カートに追加されていないことを伝える。<br>4a-2. システムが選択状態を保持したまま、再実行を可能にする。<br>4a-3. 基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。(要確認)<br>・1件でも追加できない商品があれば全件追加しない。(要確認)<br>・在庫をどの店舗の在庫で判定するかは、商品と店舗の関係が決まってから決める。(要確認) |
