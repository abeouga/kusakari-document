#### EC-B25 買い物リストから商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 買い物リストでチェックを付けた商品を、表示されている数量でまとめてカートに追加する。                                                                                                                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                               |
| 事前条件     | ECの「(庭の名前)の買い物リスト」画面が表示されている。 |
| 事後条件     | 選択した商品のうち追加できた商品が、買い物リストの数量でカートに追加されている。<br>追加できなかった商品とその理由が表示されている。 |
| 基本フロー    | 1. 購入者がカートに追加したい商品のチェックボックスにチェックを付ける。<br>2. システムが「選択した商品をカートに追加」ボタンを押せる状態にする。<br>3. 購入者が「選択した商品をカートに追加」ボタンをクリックする。<br>4. システムが選択された商品ごとに、購入可能な商品かどうかと在庫(カート内の点数+追加する数量)を検証する。<br>5. システムが選択された商品を、買い物リストの数量でカートに追加する。<br>6. システムが「ショッピングカート」画面を表示し、「(庭の名前)からn種類を追加しました。」と追加した商品をカートに表示する。 |
| 代替フロー    | 2a. 商品が1つも選択されていない場合<br>2a-1. システムが「選択した商品をカートに追加」ボタンを押せない状態にする。<br>2a-2. 基本フロー1へ戻る。<br><br>4a. 在庫不足または購入可能でない商品が含まれる場合(買い物リスト表示後に在庫が変わった場合など)<br>4a-1. システムが追加できる商品だけをカートに追加する。<br>4a-2. システムが「n種類は追加できませんでした。」と追加できなかった商品と理由を表示し、「庭のリストを再確認」ボタンで最新の在庫の買い物リストに戻れるようにする。<br>4a-3. 1つも追加できなかった場合は、「ショッピングカート」画面に移動せず基本フロー1へ戻る。<br><br>4b. 買い物リストの表示後に庭プロジェクトが変更されていた場合<br>4b-1. システムがカートに追加せず、「庭の配置が変更されました。最新の買い物リストから選び直してください。」と表示する。<br>4b-2. システムが「庭の買い物リストが更新されました。必要な商品を選び直してください。」と最新の買い物リストを表示する。<br>4b-3. 基本フロー1へ戻る。<br><br>5a. 通信に失敗した場合<br>5a-1. システムが通信エラーと「選択した商品はカートに追加されていません。選択はそのまま残っています。」を表示する。<br>5a-2. システムが選択状態を保持したまま、「再実行」ボタンを表示する。<br>5a-3. 購入者が「再実行」ボタンをクリックする。<br>5a-4. 基本フロー4へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。<br>・「全選択」ボタンで全選択したとき、在庫不足などで選択できない商品がある場合は、「次の商品は追加できないため選択していません。」と選択されなかった商品を表示する。<br>・カートの上限(1つの商品は99点、50種類)を超える分は追加しない。 |
