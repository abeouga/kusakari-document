#### EC-B25 買い物リストから商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 買い物リストでチェックを付けた商品を、表示されている数量でまとめてカートに追加する。                                                                                                                                                                                                                                                                                                                                        |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                               |
| 事前条件     | ECの買い物リストが表示されている。                                                                                                                                                                                                                                                                                                                                                                |
| 事後条件     | 選択した商品のうち追加できた商品が、買い物リストの数量でカートに追加されている。<br>追加できなかった商品とその理由が表示されている。 |
| 基本フロー    | 1. 購入者がカートに追加したい商品のチェックボックスを選択する。<br>2. 購入者が「選択した商品をカートに追加」を選ぶ。<br>3. システムが選択された商品ごとに、購入可能な商品かどうかと在庫(カート内の点数+追加する数量)を検証する。<br>4. システムが選択された商品を、買い物リストの数量でカートに追加する。<br>5. システムがカート画面を表示し、追加した商品をカートに表示する。 |
| 代替フロー    | 1a. 商品が1つも選択されていない場合<br>1a-1. システムが「選択した商品をカートに追加」ボタンを無効化する。<br>1a-2. 基本フロー1へ戻る。<br><br>3a. 在庫不足または購入可能でない商品が含まれる場合(買い物リスト表示後に在庫が変わった場合など)<br>3a-1. システムが追加できる商品だけをカートに追加する。<br>3a-2. システムが追加できなかった商品と理由を表示し、「庭のリストを再確認」で最新の在庫の買い物リストに戻れるようにする。<br>3a-3. 1つも追加できなかった場合は、カート画面に移動せず基本フロー1へ戻る。<br><br>3b. 買い物リストの表示後に庭プロジェクトが変更されていた場合<br>3b-1. システムがカートに追加せず、最新の買い物リストを表示する。<br>3b-2. 基本フロー1へ戻る。<br><br>4a. 通信に失敗した場合<br>4a-1. システムが通信エラーを表示し、カートに追加されていないことを伝える。<br>4a-2. システムが選択状態を保持したまま、再実行を可能にする。<br>4a-3. 基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。<br>・全選択したとき、在庫不足などで選択できない商品がある場合は、選択されなかった商品があることをメッセージで表示する。<br>・カートの上限(1つの商品は99点、50種類)を超える分は追加しない。 |
