#### EC-A02 アカウントの利用状況を変更する

| 記述項目     | 記述内容                                                                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | アカウントを利用停止・解除状態にする。                                                                                                                                             |
| アクター     | 運営者                                                                                                                                                             |
| 事前条件     | 運営者アカウントでログインしている。<br>アカウント管理画面に対象のアカウントが表示されている。                                                                                                               |
| 事後条件     | 対象アカウントが利用停止または利用可能として表示されている。                                                                                                                                  |
| 基本フロー    | 1. 運営者が「会員管理」で対象アカウントを選ぶ。<br>2. 運営者が「利用を停止」または「利用を再開」を選ぶ。<br>3. システムが確認メッセージを表示する。<br>4. 運営者が確定する。<br>5. システムがアカウント状態を更新して表示する。 |
| 代替フロー    | 4a. 確定を取り消した場合<br>4a-1. システムがアカウント状態を変更せず、会員管理画面を表示する。<br>4a-2. ユースケースを終了する。<br><br>5a. 対象が運営者アカウントまたは退会済みのアカウントの場合<br>5a-1. システムが利用状況を変更できないことを表示し、アカウント状態を変更しない。<br>5a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・利用停止中のアカウントはログインできない(EC-B01)。<br>・出店者の場合、出品中の商品を購入可能な商品として扱わず、購入者向けの画面に表示しない。<br>・すでに確定した注文はキャンセルせず、そのまま受け渡しを続ける。<br>・利用停止中はログインできず通知を確認できないため、対象者への通知は送らない。 |
