#### EC-C02 管理者画面のメニューを開く(子ユースケース)

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 共通ヘッダーの「管理者画面」から、サイドバーのメニューで指定した画面(「会員管理」「商品管理」など)を開く。EC-A01〜EC-A11から呼び出す。 |
| アクター     | 運営者 |
| 事前条件     | 運営者アカウントでログインしている。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。 |
| 事後条件     | 呼び出し元で指定したメニューの画面が表示されている。 |
| 基本フロー    | 1. 運営者が共通ヘッダーの「管理者画面」リンクをクリックする。<br>2. システムが「会員管理」画面と、サイドバーの運営者メニュー(「会員管理」「商品管理」「カテゴリ管理」「出店審査」「店舗管理」「全注文管理」)を表示する。<br>3. 指定されたメニューが「会員管理」以外の場合、運営者がサイドバーの対象のメニューをクリックする。 |
| 代替フロー    | なし |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象の画面に表示する内容は、呼び出し元のユースケースの次のステップで記述する。<br>・運営者アカウント以外では、共通ヘッダーに「管理者画面」リンクを表示しない。 |
