#### EC-A01 会員を検索・確認する

| 記述項目 | 記述内容 |
| --- | --- |
| ユースケース概要 | アカウントを検索し、会員情報と現在の利用状態を確認する。 |
| アクター | 運営者 |
| 事前条件 | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件 | 検索条件に合う会員が一覧に表示されている、または「検索条件に一致する会員はありません。」が表示されている。 |
| 基本フロー | 1. 運営者が運営者画面のメニュー「会員管理」を開く(画面ID: EC-C02)。<br>2. システムが「会員管理」画面に会員の一覧(氏名、メールアドレス、アカウントの種類、利用状態)を表示する。利用状態は「利用中」「利用停止」「退会済み」のいずれかを表示する。<br>3. 運営者が「名前・メール検索」入力欄に氏名またはメールアドレスの一部を入力する。<br>4. システムが入力内容に部分一致する会員のみを一覧に表示する。 |
| 代替フロー | 2a. 会員が1人もいない場合<br>2a-1. システムが「対象の会員はありません。」を表示する。<br>2a-2. ユースケースを終了する。<br><br>3a. 入力欄が空になった場合<br>3a-1. システムが全会員の一覧を表示する。<br><br>4a. 該当会員がいない場合<br>4a-1. システムが「検索条件に一致する会員はありません。」を表示する。<br>4a-2. 運営者が検索条件を変更し、基本フロー3へ戻る。 |
| 関連情報 | ・共通代替フロー \*b を適用する。<br>・会員情報は一覧上で確認する(詳細画面は設けない)。<br>・アカウントの種類は、登録されている値(「USER」(購入者)、「SHOP_OWNER_APPLICANT」(出店申請用)、「SHOP_OWNER」(出店者のオーナー)、「SHOP_STAFF」(店舗の担当者)、「ADMIN」(運営者))をそのまま表示する。 |
