#### EC-A01 会員を検索・確認する

| 記述項目     | 記述内容                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| ユースケース概要 | アカウントを検索し、会員情報と現在の利用状態を確認する。                                                      |
| アクター     | 運営者                                                                          |
| 事前条件     | 運営者アカウントでログインしている。<br>会員管理画面を利用できる。                                                                     |
| 事後条件     | 検索条件に合うアカウントまたは該当なしが表示されている。                                                      |
| 基本フロー    | 1. 運営者が「会員管理」を開く。<br>2. システムが会員の一覧(氏名、メールアドレス、アカウントの種類、利用状態)を表示する。<br>3. 運営者が氏名またはメールアドレスの一部を検索条件に入力する。<br>4. システムが該当会員を表示する。 |
| 代替フロー    | 4a. 該当会員がいない場合<br>4a-1. システムが検索結果なしを表示する。<br>4a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・会員情報は一覧上で確認する。 |
