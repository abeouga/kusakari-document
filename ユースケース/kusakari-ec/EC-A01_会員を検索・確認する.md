#### EC-A01 会員を検索・確認する

| 記述項目     | 記述内容                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| ユースケース概要 | アカウントを検索し、会員情報と現在の利用状態を確認する。                                                      |
| アクター     | 運営者                                                                          |
| 事前条件     | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 検索条件に合うアカウントまたは該当なしが表示されている。                                                      |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「会員管理」を開く(EC-C02)。<br>2. システムが「会員管理」画面に会員の一覧(氏名、メールアドレス、アカウントの種類、利用状態)を表示する。<br>3. 運営者が「名前・メール検索」入力欄に氏名またはメールアドレスの一部を入力する。<br>4. システムが入力内容に該当する会員を表示する。 |
| 代替フロー    | 4a. 該当会員がいない場合<br>4a-1. システムが「検索条件に一致する会員はありません。」を表示する。<br>4a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・会員情報は一覧上で確認する。 |
