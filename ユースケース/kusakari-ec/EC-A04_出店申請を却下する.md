# EC-A04 出店申請を却下する

| 記述項目     | 記述内容                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 却下理由を入力し、選択した出店申請を却下する。                                                                                      |
| アクター     | 管理者（運営者）                                                                                                     |
| 事前条件     | 審査対象の申請が表示されている。                                                                                             |
| 事後条件     | 申請が却下として表示される。                                                                                               |
| 基本フロー    | 1. 管理者が審査対象を開く。<br>2. 管理者が却下を選ぶ。<br>3. 管理者が却下理由を入力して確定する。<br>理由が未入力の場合は => 代替フロー1へ。<br>4. システムが申請状態を却下に更新する。 |
| 代替フロー    | 1. 理由が未入力の場合<br>1-1. システムが理由の入力を求め、申請状態を変更しない。                                                               |
