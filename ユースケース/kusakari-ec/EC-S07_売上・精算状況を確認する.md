# EC-S07 売上・精算状況を確認する

| 記述項目     | 記述内容                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 注文に基づく売上集計・精算状態を確認する。                                                                                                                                                 |
| アクター     | 出店者                                                                                                                                                                   |
| 事前条件     | 出店者向け売上画面を利用できる。                                                                                                                                                      |
| 事後条件     | 売上集計と精算状態が表示される                                                                                                                                                       |
| 基本フロー    | 1. 出店者がヘッダーの出店者を押す<br>2. システムが出店者専用画面を表示する<br>3. 出店者がサイドバーの「売上・精算」ボタンを押す<br>4. システムが注文に基づく集計を表示する「売上・精算」画面を表示する。<br>サンプルデータがない場合は => 代替フロー1へ。<br>5. 出店者が対象期間・明細を確認する。 |
| 代替フロー    | 1. サンプルデータがない場合<br>1-1. システムが集計対象なしの状態を表示する。                                                                                                                          |
