#### EC-S07 注文実績を確認する

| 記述項目     | 記述内容                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 所属店舗の注文件数、キャンセル件数、合計注文金額を確認する。 |
| アクター     | 出店者                                                                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。                                                                                                                        |
| 事後条件     | 注文実績画面が表示されている。                                                                                                                           |
| 基本フロー    | 1. 出店者が「注文実績」を選択する。<br>2. システムが所属店舗の注文実績に関連するデータを取得する。<br>3. システムが注文件数・キャンセル件数・合計注文金額を表示する。<br>4. 出店者が注文実績を確認する。 |
| 代替フロー    | 3a. 注文がない場合<br>3a-1. システムが注文なしの状態を表示する。<br>3a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
