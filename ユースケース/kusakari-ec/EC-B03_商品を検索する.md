#### EC-B03 商品を検索する

| 記述項目     | 記述内容                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品名・商品番号・生産者名で商品を探し、条件で絞り込む。                                                                                                                                     |
| アクター     | 購入者                                                                                                                                                    |
| 事前条件     | 商品一覧を利用できる。<br>ログインは不要である。                                                                                                                                  |
| 事後条件     | 条件に合う商品一覧または選択した商品が表示されている。                                                                                                                                 |
| 基本フロー    | 1. 購入者が商品名・商品番号・生産者名のいずれかを入力するか、カテゴリ・絞り込み条件を指定する。<br>2. 購入者が必要に応じて価格順などで並べ替える。<br>3. システムが条件に合う商品を表示する。                                                               |
| 代替フロー    | 3a. 該当商品がない場合<br>3a-1. システムが該当商品なしと表示し、検索条件の変更を可能にする。<br>3a-2. 基本フロー1へ戻る。 |
| 関連情報     | ・購入者向けの画面には、購入可能な商品だけを表示する。購入可能な商品とは、選択中の受取店舗で出店者が「公開中」にしており、運営者による公開停止(EC-A10)や出店者・店舗の利用停止がされていない商品を指す。 |
