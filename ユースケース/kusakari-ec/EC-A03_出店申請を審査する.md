#### EC-A03 出店申請を審査する

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 運営者が購入者からの出店申請の内容を確認し、承認または却下する。 |
| アクター     | 運営者 |
| 事前条件     | 運営者アカウントでログインしている。<br>出店審査画面が表示されている。 |
| 事後条件     | 出店申請の出店審査状態が「承認」または「却下」として保存され、申請者にサイト内通知とメールで審査結果が通知されている。<br>承認した場合は、申請者の購入者アカウントが出店者アカウントに切り替わり、申請内容をもとに店舗が作成されている。 |
| 基本フロー    | 1. 運営者が「出店審査」を選択する。<br>2. システムが出店審査状態が「審査中」の出店申請を取得する。<br>3. システムが審査待ちの出店申請一覧(申請者名、申請日)を表示する。<br>4. 運営者が審査する申請を選ぶ。<br>5. システムが申請内容、却下理由の入力欄、「承認する」「却下する」を表示する。<br>6. 運営者が申請内容を確認し、「承認する」または「却下する」を選ぶ。却下する場合は、却下理由を入力してから「却下する」を選ぶ。<br>7. システムが出店審査状態を、選ばれた結果(「承認」/「却下」)に更新する。承認の場合は、申請者のアカウントを出店者アカウントに切り替え、申請内容をもとに店舗を作成する。<br>8. システムがサイト内通知とメールで申請者に審査結果を通知する。却下の場合は却下理由も通知に含める。<br>9. システムが審査完了メッセージを表示し、出店申請一覧を再表示する。 |
| 代替フロー    | 3a. 審査待ちの出店申請がない場合<br>3a-1. システムが「審査待ちの出店申請はありません」と表示する。<br>3a-2. ユースケースを終了する。<br><br>6a. 却下理由が未入力のまま「却下する」を選んだ場合<br>6a-1. システムが却下理由の入力を求めるエラーメッセージを表示し、出店審査状態を変更しない。<br>6a-2. 基本フロー6へ戻る。<br><br>7a. 申請がすでに処理されている場合(他の運営者が処理した、申請者が退会したなど)<br>7a-1. システムが申請がすでに処理されていることを表示し、出店審査状態を変更しない。<br>7a-2. 基本フロー2へ戻る。<br><br>7b. アカウントの切り替えまたは店舗の作成に失敗した場合<br>7b-1. システムがエラーを表示し、出店審査状態・アカウント・店舗を処理前の状態のままにする。<br>7b-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・承認時のアカウントの切り替えと店舗の作成は、出店審査状態の更新と一括で行う。どれかが失敗した場合はすべて処理前の状態に戻す。<br>・サイト内通知は申請者がEC-B15で確認する。<br>・却下理由は申請者の出店申請状況画面(EC-B18)にも表示される。<br>・作成する店舗の数や、出店者と店舗の関係は未定。(要確認) |
