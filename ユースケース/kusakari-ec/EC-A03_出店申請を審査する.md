#### EC-A03 出店申請を審査する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------- | ---- |
| ユースケース概要 | 運営者が購入者からの出店申請の内容を確認し、承認または却下する。                                                                                                                                                                                                                                                                                                                                                                                             |
| アクター     | 運営者                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 事前条件     | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 出店申請の出店審査状態が「承認」または「却下」として保存され、申請者にサイト内通知で審査結果が通知されている。<br>承認した場合は、申請者の購入者アカウントが出店者アカウントに切り替わり、申請内容をもとに店舗が作成されている。 |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「出店審査」を開く(EC-C02)。<br>2. システムが出店申請を取得する。<br>3. システムが「出店審査」画面に出店申請一覧(会社名、申請日、出店審査状態)を、審査中の申請を先にして表示する。審査中の申請ごとに、申請内容、「提出書類を確認」リンク、「却下理由」入力欄、「承認」ボタン、「却下」ボタンを表示する。<br>4. 運営者が審査する申請の「提出書類を確認」リンクをクリックする。<br>5. システムが提出書類のファイルをダウンロードする。<br>6. 運営者が申請内容と提出書類を確認し、「承認」ボタンまたは「却下」ボタンをクリックする。却下する場合は、「却下理由」入力欄に却下理由を入力してから「却下」ボタンをクリックする。<br>7. システムが出店審査状態を、選ばれた結果(「承認」/「却下」)に更新する。承認の場合は、申請者のアカウントを出店者アカウントに切り替え、申請内容をもとに店舗を作成する。<br>8. システムがサイト内通知で申請者に審査結果を通知する。却下の場合は却下理由も通知に含める。<br>9. システムが「承認しました。申請者に審査結果を通知しました。」または「却下しました。申請者に却下理由を通知しました。」を表示し、出店申請一覧を再表示する。 |
| 代替フロー    | 3a. 審査待ちの出店申請がない場合<br>3a-1. システムが「審査待ちの出店申請はありません。」を表示する。<br>3a-2. ユースケースを終了する。<br><br>6a. 却下理由が未入力のまま「却下」ボタンをクリックした場合<br>6a-1. システムが「却下する場合は却下理由を入力してください。」を表示し、出店審査状態を変更しない。<br>6a-2. 基本フロー6へ戻る。<br><br>7a. 申請がすでに処理されている場合(他の運営者が処理したなど)<br>7a-1. システムが「この申請は審査済みです。」を表示し、出店審査状態を変更しない。<br>7a-2. 基本フロー2へ戻る。<br><br>7b. アカウントの切り替えまたは店舗の作成に失敗した場合<br>7b-1. システムがエラーメッセージを表示し、出店審査状態・アカウント・店舗を処理前の状態のままにする。<br>7b-2. 基本フロー3へ戻る。<br><br>7c. 承認しようとした申請者が退会済み・利用停止中の場合<br>7c-1. システムが「申請者の利用状態が変わりました。」を表示し、申請を審査中のまま残す。<br>7c-2. 基本フロー6へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・承認時のアカウントの切り替えと店舗の作成は、出店審査状態の更新と一括で行う。どれかが失敗した場合はすべて処理前の状態に戻す。<br>・承認時に作成する店舗は、店舗名を申請した会社名とし、営業時間などは出店者がEC-S02で設定する。<br>・サイト内通知は申請者がEC-B15で確認する。<br>・却下理由は申請者の出店申請状況画面(EC-B18)にも表示される。<br>・出店者は店舗に属する形式で、商品は店舗に登録する流れとなる。 |
