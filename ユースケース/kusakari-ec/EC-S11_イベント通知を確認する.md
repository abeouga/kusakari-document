#### EC-S11 イベント通知を確認する

| 記述項目     | 記述内容                                                                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者向けのイベント通知一覧を確認する。                                                                                                                                                                                        |
| アクター     | 出店者                                                                                                                                                                                                         |
| 事前条件     | 出店者アカウントでログインしている。                                                                                                                                                                                          |
| 事後条件     | 通知が画面上に表示されている。                                                                                                                                                                                             |
| 基本フロー    | 1. 出店者が通知一覧を開き、管理する店舗を選ぶ。<br>2. システムが選んだ店舗の通知を表示する。<br>3. 出店者が通知内容を確認し、必要に応じて既読状態を操作する。                                                                                                                                                    |
| 代替フロー    | 2a. 通知がない場合<br>2a-1. システムが通知なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品審査の結果(EC-A10)も通知される。却下の場合は却下理由も通知に含める。<br>・却下の通知から対象商品の編集画面(EC-S04)へ移動できる。(要確認)<br>・購入者からの注文キャンセル申請(EC-B14)も通知される。通知からキャンセル申請の処理(EC-S13)へ移動できる。(要確認)<br>・購入者の新しい注文(EC-B12)も通知される。通知から注文詳細(EC-S08)へ移動できる。 |
