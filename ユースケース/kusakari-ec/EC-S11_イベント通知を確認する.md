#### EC-S11 通知一覧を確認する

| 記述項目     | 記述内容                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者向けのイベント通知一覧を確認する。 |
| アクター     | 出店者                                                                                                                                                                             |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 通知が画面上に表示されている。                                                                                                                                                                 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「出店者通知」を開く(EC-C03)。<br>2. システムが「出店者通知」画面に所属店舗に関する通知を表示する。<br>3. 出店者が通知内容を確認する。<br>4. 出店者が必要に応じて対象通知の「既読にする」ボタンをクリックする。<br>5. システムが通知を既読にし、「既読」と表示する。 |
| 代替フロー    | 2a. 通知がない場合<br>2a-1. システムが通知なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・購入者の新しい注文と、注文キャンセル申請が通知される。対応は「注文管理」画面(EC-S08、EC-S13)で行う。<br>・運営者による商品の公開停止・公開停止の解除(EC-A10)も、商品名と理由を含めて通知される。<br>・店舗に複数の担当者がいる場合は、担当者それぞれに通知される。 |
