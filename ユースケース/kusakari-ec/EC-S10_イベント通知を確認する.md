# EC-S10 イベント通知を確認する

| 記述項目     | 記述内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| ユースケース概要 | 出店者向けのイベント通知一覧を確認する。                                                                 |
| アクター     | 出店者                                                                                  |
| 事前条件     | 出店者向け通知画面を利用できる。                                                                     |
| 事後条件     | 通知を画面上で確認できる。                                                                        |
| 基本フロー    | 1. 出店者が通知一覧を開く。<br>2. システムが通知を表示する。<br>通知を取得できない場合は => 代替フロー1へ。<br>3. 出店者が通知内容を確認する。 |
| 代替フロー    | 1. 通知を取得できない場合<br>1-1. システムが通知なしまたは表示エラーを示す。                                         |
