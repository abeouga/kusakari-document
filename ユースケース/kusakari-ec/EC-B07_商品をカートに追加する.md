#### EC-B07 商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品詳細または商品一覧から選んだ商品をECカートへ追加する。                                                                                                                                       |
| アクター     | 購入者                                                                                                                                                             |
| 事前条件     | 購入可能な商品が表示されている。                                                                                                                                                     |
| 事後条件     | 商品と数量がECカートに保存されている。                                                                                                                                                 |
| 基本フロー    | 1. 購入者が商品と数量を指定する。<br>2. 購入者がカートへの追加を選ぶ。<br>3. システムが商品・数量を検証する。<br>4. システムがカートに商品と数量を保存する。                                                                           |
| 代替フロー    | 3a. 数量が無効または在庫不足の場合<br>3a-1. システムがエラーメッセージを表示し、追加しない。<br>3a-2. 基本フロー1へ戻る。 |
| 関連情報     | ・在庫をどの店舗の在庫で判定するかは、商品と店舗の関係が決まってから決める。(要確認)<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。(要確認) |
