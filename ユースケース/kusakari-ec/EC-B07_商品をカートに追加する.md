# EC-B07 商品をカートに追加する

| 記述項目     | 記述内容                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 商品詳細または商品一覧から選んだ商品をECカートへ追加する。                                                                                                                              |
| アクター     | 利用者（購入者）                                                                                                                                                    |
| 事前条件     | 購入可能な商品が表示されている。                                                                                                                                            |
| 事後条件     | 商品と数量がECカートに保存される。                                                                                                                                          |
| 基本フロー    | 1. 利用者が商品と数量を指定する。<br>2. 利用者がカートへの追加を選ぶ。<br>3. システムが商品・数量を検証し、カートへ保存する。<br>数量が無効または在庫不足の場合は => 代替フロー1へ<br>通信に失敗した場合は => 代替フロー2へ。<br>4. システムがカートに商品と数量を保存する。 |
| 代替フロー    | 1. 数量が無効または在庫不足の場合<br>1-1. システムが入力値または在庫のエラーメッセージを表示し、追加しない。<br><br>2. 通信に失敗した場合<br>2-1. システムが通信エラーを表示し、カートの再取得を可能にする。 |
