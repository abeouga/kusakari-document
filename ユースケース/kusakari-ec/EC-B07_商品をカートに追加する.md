#### EC-B07 商品をカートに追加する

| 記述項目     | 記述内容                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| ユースケース概要 | 商品詳細または商品一覧から選んだ商品をECカートへ追加する。                                                             |
| アクター     | 購入者                                                                                        |
| 事前条件     | 購入者アカウントでログインしている。<br>「植物について」ダイアログまたは「トップ」画面の商品一覧に、購入可能な商品が表示されている。                                                                           |
| 事後条件     | 商品と数量がECカートに保存されている。                                                                       |
| 基本フロー    | 1. 購入者が「植物について」ダイアログの「購入数量」欄に数量を入力する。<br>2. システムが数量を検証し、「カートに追加」ボタンをクリックできる状態にする。<br>3. 購入者が「カートに追加」ボタンをクリックする。<br>4. システムが商品・数量・在庫を検証する。<br>5. システムがカートに商品と数量を保存し、「カートを更新しました。」と表示する。 |
| 代替フロー    | 1a. 商品一覧から追加する場合<br>1a-1. 購入者が「メイン」画面の商品一覧で、対象商品の商品カードにある「＋」ボタン(カートに追加)をクリックする。<br>1a-2. 基本フロー4へ進む(数量は1点とする)。<br><br>1b. 未ログインの場合<br>1b-1. 購入者が商品一覧の「＋」ボタンをクリックすると、システムが「ログイン」画面を表示する。<br>1b-2. 購入者がログインすると(EC-B01)、元の画面へ戻る。<br>1b-3. 基本フロー1へ戻る。<br><br>2a. 数量が無効な場合(1未満、整数でない、在庫数または99点を超える)、または在庫が0の場合<br>2a-1. システムが「カートに追加」ボタンをクリックできない状態にする。<br>2a-2. 基本フロー1へ戻る。<br><br>4a. 数量が無効、在庫不足、または購入できなくなった商品の場合<br>4a-1. システムが「受取店舗の在庫が不足しています。」「追加すると商品数量の上限99点を超えます。」「カートの商品種類の上限50種類を超えます。」「販売終了または商品が見つかりません。」などのエラーメッセージを表示し、追加しない。<br>4a-2. 基本フロー1へ戻る。                  |
| 関連情報     | ・受取店舗は商品ごとに決まっている(商品が属する店舗)。「植物について」ダイアログには「(店舗名)で店舗受取」と、その店舗の店頭在庫を表示する。<br>・在庫は、商品の店舗(受取店舗)の在庫を使う。<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。<br>・1つの商品は99点まで、カートに入れられる商品は50種類までとする。<br>・カートはログイン中のアカウントに保存する。未ログインでは追加できず、「ログイン」画面へ移動する。<br>・店舗側のアカウント(出店者のオーナー・担当者)と出店申請用アカウントでは購入できない。これらのアカウントでは、「購入数量」欄・「カートに追加」ボタン・商品一覧の「＋」ボタン・共通ヘッダーの「カート」リンクを表示せず、「店舗・出店申請用のアカウントでは購入できません。購入は購入者のアカウントでご利用ください。」と表示する。 |
