#### EC-S08 注文一覧・詳細を確認する

| 記述項目     | 記述内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| ユースケース概要 | 所属店舗の注文の一覧と、注文ごとの明細・受取情報を確認する。 |
| アクター     | 出店者                                                                                  |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 注文の一覧と、各注文の内容が表示されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗受け取り」を開く(EC-C03)。<br>2. システムが「店舗受け取り」画面に所属店舗の注文一覧(注文番号、注文状態、注文明細、合計、受取連絡先、キャンセル申請状態)を表示する。<br>3. 出店者が必要に応じて注文状態の絞り込みボタンをクリックする。<br>4. システムが選択した注文状態の注文だけを一覧に表示する。<br>5. 出店者が引き渡し完了・キャンセル済みの注文を確認する場合は、対象注文の「詳細」をクリックする。<br>6. システムが対象注文の注文明細と受取連絡先を表示する。<br>7. 出店者が対象注文の内容を確認する。 |
| 代替フロー    | 2a. 注文がない場合<br>2a-1. システムが注文なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
