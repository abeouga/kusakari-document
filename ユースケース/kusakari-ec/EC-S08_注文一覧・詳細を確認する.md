#### EC-S08 注文一覧・詳細を確認する

| 記述項目     | 記述内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| ユースケース概要 | 注文一覧と注文詳細を確認する。                                                                      |
| アクター     | 出店者                                                                                  |
| 事前条件     | 出店者アカウントでログインしている。                                                                   |
| 事後条件     | 選択した注文の内容が表示されている。                                                                   |
| 基本フロー    | 1. 出店者が「注文一覧」を選択し、管理する店舗を選ぶ。<br>2. システムが選んだ店舗の注文一覧画面を表示する。<br>3. 出店者が対象注文を選ぶ。<br>4. システムが注文詳細を表示する。 |
| 代替フロー    | 2a. 注文がない場合<br>2a-1. システムが注文なしの状態を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
