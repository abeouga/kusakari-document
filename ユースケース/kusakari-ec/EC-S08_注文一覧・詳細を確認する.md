# EC-S08 注文一覧・詳細を確認する

| 記述項目     | 記述内容                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 出店者専用画面で注文一覧と注文詳細を確認する。                                                                                  |
| アクター     | 出店者                                                                                                      |
| 事前条件     | 出店者向け注文画面を利用できる。                                                                                         |
| 事後条件     | 選択したサンプル注文の内容が表示される。                                                                                     |
| 基本フロー    | 1. 出店者が注文一覧を開く。<br>2. システムがサンプル注文を表示する。<br>注文がない場合は => 代替フロー1へ。<br>3. 出店者が対象注文を選ぶ。<br>4. システムが注文詳細を表示する。 |
| 代替フロー    | 1. 注文がない場合<br>1-1. システムが注文なしの状態を表示する。                                                                    |
