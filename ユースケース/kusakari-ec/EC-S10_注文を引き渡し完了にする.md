#### EC-S10 注文を引き渡し完了にする

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者が商品を受け取ったことを確認し、注文の状態を「引き渡し完了」に更新する。                                                   |
| アクター     | 出店者                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。<br>管理する店舗の注文一覧画面が表示されている。<br>対象注文の状態が「受取準備完了」になっている。<br>購入者が商品を受け取ったことを確認している。 |
| 事後条件     | 注文状態が「引き渡し完了」になっている。                                                                      |
| 基本フロー    | 1. 出店者が対象注文の「引き渡し完了にする」を選択する。<br>2. システムが確認メッセージを表示する。<br>3. 出店者が確定する。<br>4. システムが注文状態を「引き渡し完了」に更新する。<br>5. システムが更新後の注文状態を表示する。    |
| 代替フロー    | 3a. 確定を取り消した場合<br>3a-1. システムが注文状態を更新せず、注文一覧を表示する。<br>3a-2. ユースケースを終了する。<br><br>4a. 対象注文の状態が「受取準備完了」でなくなっている場合(キャンセル済みなど)<br>4a-1. システムが注文状態が変更されていることを表示し、更新しない。<br>4a-2. システムが最新の注文一覧を表示する。<br>4a-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・注文状態を「引き渡し完了」に更新するには、先にEC-S09で「受取準備完了」に更新しないとできない。 |
