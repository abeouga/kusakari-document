#### EC-A10 商品の公開を停止・再開する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者が不適切な商品の公開を停止し、問題が解消した商品の公開を再開する。 |
| アクター     | 運営者                                                                                                                                                                                                                                                                                                                                                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>商品管理画面に対象の商品が表示されている。 |
| 事後条件     | 対象商品の公開状態が「公開停止中」または「公開可能」として保存され、出店者に理由が通知されている。 |
| 基本フロー    | 1. 運営者が「商品管理」を開く。<br>2. システムが商品の一覧と公開状態を表示する(EC-A06)。<br>3. 運営者が対象商品の理由を入力し、「公開を停止」または「公開停止を解除」を選ぶ。<br>4. システムが商品の公開状態を更新する。<br>5. システムが出店者向けのイベント通知(EC-S11)で、公開状態の変更と理由を通知する。<br>6. システムが更新後の公開状態を表示する。 |
| 代替フロー    | 3a. 理由が未入力の場合<br>3a-1. システムが理由の入力を求め、公開状態を変更しない。<br>3a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・出店者が登録した商品(EC-S03)は事前の審査なしで公開される。運営者は公開後に商品を確認し、必要に応じて公開を停止する。<br>・公開停止中の商品は、出店者が「公開中」にしていても購入者向けの画面に表示しない。<br>・公開停止の解除は運営者だけが行える。出店者が商品を編集しても公開停止は解除されない。 |
