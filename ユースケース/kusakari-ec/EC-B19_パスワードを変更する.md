#### EC-B19 パスワードを変更する

| 記述項目     | 記述内容                                                                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 現在のパスワードと新しいパスワードを入力し、パスワードを変更する。                                                                                                                                                         |
| アクター     | 利用者(購入者・出店者)                                                                                                                                                                              |
| 事前条件     | ログイン状態である。<br>パスワード変更フォームが表示されている。                                                                                                                                                         |
| 事後条件     | パスワードが新しいパスワードに更新され、ログアウト状態でログイン画面が表示されている。                                                                                                                                               |
| 基本フロー    | 1. 利用者が現在のパスワード、新しいパスワード、確認用パスワードを入力して送信する。<br>2. システムが現在のパスワードが正しいか確認する。<br>3. システムが新しいパスワードが8文字以上かつ確認値と一致するか検証する。<br>4. システムがパスワードを更新し、ログアウト状態にする。<br>5. システムがログイン画面と一緒に変更完了メッセージを表示する。 |
| 代替フロー    | 2a. 現在のパスワードが正しくない場合<br>2a-1. システムが「現在のパスワードが正しくありません」と表示し、パスワード変更を確定しない。<br>2a-2. 基本フロー1へ戻る。<br><br>3a. 不一致または短すぎる場合<br>3a-1. システムが入力エラーを表示し、パスワード変更を確定しない。<br>3a-2. 基本フロー1へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・変更後は新しいパスワードでログインし直す。 |
