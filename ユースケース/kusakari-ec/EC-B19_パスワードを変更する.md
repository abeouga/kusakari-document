# EC-B19 パスワードを変更する

| 記述項目 | 記述内容 |
|---|---|
| ユースケース概要 | 新しいパスワードと確認用パスワードを入力し、変更フォームを操作する。 |
| アクター | 利用者（購入者・事業者） |
| 事前条件 | パスワード変更フォームを表示できる。 |
| 事後条件 | 入力確認メッセージまたはエラーが表示される。 |
| 基本フロー | 1. 利用者が新しいパスワードと確認用パスワードを入力する。<br>2. システムが8文字以上かつ確認値と一致するか検証する。<br>不一致または短すぎる場合は => 代替フロー1へ。<br>3. 利用者が送信し、システムが入力確認メッセージを表示する。 |
| 代替フロー | 1. 不一致または短すぎる場合<br>1-1. システムが入力エラーを表示し、パスワード変更を確定しない。 |
