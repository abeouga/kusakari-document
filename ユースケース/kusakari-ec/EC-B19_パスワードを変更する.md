#### EC-B19 パスワードを変更する

| 記述項目     | 記述内容                                                                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 現在のパスワードと新しいパスワードを入力し、パスワードを変更する。                                                                                                                                                         |
| アクター     | 利用者(購入者・出店者)                                                                                                                                                                              |
| 事前条件     | ログイン状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | パスワードが新しいパスワードに更新され、ログアウト状態で「ログイン」画面が表示されている。 |
| 基本フロー    | 1. 利用者がアカウントのメニュー「パスワード変更」を開く(EC-C01)。<br>2. システムが「パスワード変更」画面を表示する。<br>3. 利用者が「現在のパスワード」に現在のパスワードを入力する。<br>4. 利用者が「新しいパスワード（8文字以上）」に新しいパスワードを入力する。<br>5. 利用者が「確認用パスワード」に新しいパスワードをもう一度入力する。<br>6. 利用者が「パスワードを変更」ボタンをクリックする。<br>7. システムが新しいパスワードが8文字以上かつ確認用パスワードと一致するか検証する。<br>8. システムが現在のパスワードが正しいか確認する。<br>9. システムがパスワードを更新し、ログアウト状態にする。<br>10. システムが「ログイン」画面と一緒に「パスワードを変更しました。新しいパスワードでログインしてください。」と表示する。 |
| 代替フロー    | 7a. 不一致または短すぎる場合<br>7a-1. システムが「新しいパスワードは8文字以上で入力してください。」または「新しいパスワードと確認用パスワードが一致しません。」と表示し、パスワード変更を確定しない。<br>7a-2. 基本フロー3へ戻る。<br><br>8a. 現在のパスワードが正しくない場合<br>8a-1. システムが「現在のパスワードが正しくありません。」と表示し、パスワード変更を確定しない。<br>8a-2. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・変更後は新しいパスワードでログインし直す。 |
