#### EC-A09 商品カテゴリを削除する

| 記述項目     | 記述内容                                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 運営者が選択したカテゴリを削除する。                                                                                                                                                             |
| アクター     | 運営者                                                                                                                                                                       |
| 事前条件     | 運営者アカウントでログインしている。<br>カテゴリ管理画面に削除対象がある。                                                                                                                                                              |
| 事後条件     | 対象カテゴリが一覧から削除されている。                                                                                                                                                            |
| 基本フロー    | 1. 運営者が削除対象のカテゴリの「削除」を選ぶ。<br>2. システムが削除の確認を表示し、運営者が削除を確定する。<br>3. システムがカテゴリ一覧から対象を削除する。 |
| 代替フロー    | 2a. 商品が紐づいているカテゴリを削除しようとした場合<br>2a-1. システムがエラーメッセージを表示してカテゴリを削除せず、一覧を再表示する。<br>2a-2. ユースケースを終了する。<br><br>2b. 削除を取り消した場合<br>2b-1. システムがカテゴリを削除せず、一覧を表示する。<br>2b-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象のカテゴリを削除するには、先に該当商品を別のカテゴリへ移す必要がある。<br>・出店者が削除した(販売を終了した)商品は、カテゴリの削除を妨げない。 |
