# EC-A09 商品カテゴリを削除する

| 記述項目     | 記述内容                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| ユースケース概要 | 管理者が選択したカテゴリを削除する。                                                                           |
| アクター     | 管理者（運営者）                                                                                     |
| 事前条件     | カテゴリ管理画面に削除対象がある。                                                                            |
| 事後条件     | 対象カテゴリが一覧から削除される。                                                                            |
| 基本フロー    | 1. 管理者が削除対象のカテゴリを選ぶ。<br>2. 管理者が削除を確定する。<br>3. システムがカテゴリ一覧から対象を削除する。<br>削除できない場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 対象が見つからない場合<br>1-1. システムがエラーを表示し、一覧を再表示する。                                                |
