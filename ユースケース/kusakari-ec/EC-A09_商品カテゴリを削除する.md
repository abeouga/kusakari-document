#### EC-A09 商品カテゴリを削除する

| 記述項目     | 記述内容                                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 運営者が選択したカテゴリを削除する。                                                                                                                                                             |
| アクター     | 運営者                                                                                                                                                                       |
| 事前条件     | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。<br>削除対象のカテゴリが登録されている。 |
| 事後条件     | 対象カテゴリが一覧から削除されている。                                                                                                                                                            |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「カテゴリ管理」を開く(EC-C02)。<br>2. システムが「カテゴリ管理」画面にカテゴリ一覧を表示する。<br>3. 運営者が削除対象のカテゴリの「削除」ボタンをクリックする。<br>4. システムが「カテゴリ削除の確認」ダイアログを表示する。<br>5. 運営者が「削除を確定」ボタンをクリックする。<br>6. システムがカテゴリを削除し、「カテゴリを削除しました。」を表示してカテゴリ一覧から対象を除く。 |
| 代替フロー    | 5a. 削除を取り消した場合<br>5a-1. 運営者が「カテゴリ削除の確認」ダイアログの「取消」ボタンをクリックする。<br>5a-2. システムがダイアログを閉じ、カテゴリを削除せず一覧を表示する。<br>5a-3. ユースケースを終了する。<br><br>6a. 商品が紐づいているカテゴリを削除しようとした場合<br>6a-1. システムが「商品で使用中のカテゴリは削除できません。先に該当商品を別のカテゴリへ移してください。」を表示してカテゴリを削除せず、一覧を再表示する。<br>6a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象のカテゴリを削除するには、先に該当商品を別のカテゴリへ移す必要がある。<br>・出店者が削除した(販売を終了した)商品は、カテゴリの削除を妨げない。 |
