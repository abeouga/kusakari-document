# EC-B06 商品詳細からCanvasを開く

| 記述項目     | 記述内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| ユースケース概要 | 商品詳細画面の案内からCanvasを開く。                                                   |
| アクター     | 利用者（購入者）                                                                |
| 事前条件     | 商品詳細にCanvasへのリンクが表示されている。                                               |
| 事後条件     | Canvasの画面が表示される。                                                        |
| 基本フロー    | 1. 利用者がCanvasへのリンクを選ぶ。<br>2. システムがCanvasを開く。<br>遷移先を開けない場合は => 代替フロー1へ。 |
| 代替フロー    | 1. Canvasを開けない場合<br>1-1. エラー画面を表示する。 |
