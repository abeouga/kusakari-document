#### EC-S04 商品情報を編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 登録済みの商品情報を変更する。                                                                                                                                                                                                                                                                                   |
| アクター     | 出店者                                                                                                                                                                                                                                                                                               |
| 事前条件     | 出店者アカウントでログインしている。<br>編集対象の商品が登録されている。                                                                                                                                                                                                                                                            |
| 事後条件     | 変更後の商品情報が保存されている。<br>却下された商品を編集した場合は、商品審査状態が「審査中」に戻っている。                                                                                                                                                                                                                                     |
| 基本フロー    | 1. 出店者が管理する店舗を選ぶ。<br>2. システムが選んだ店舗の商品一覧と、商品ごとの商品審査状態(「審査中」/「承認」/「却下」)を表示する。<br>3. 出店者が編集対象の商品を選ぶ。<br>4. システムが商品情報をフォームに表示する。商品審査状態が「却下」の商品の場合は、フォームの上に却下理由も表示する。<br>5. 出店者が情報を変更して保存する。<br>6. システムが商品情報を保存する。商品審査状態が「却下」の商品の場合は、商品審査状態を「審査中」に戻す。<br>7. システムが更新結果を表示する。商品審査状態を「審査中」に戻した場合は「再審査を申請しました」と表示する。 |
| 代替フロー    | 5a. 入力値が不正な場合<br>5a-1. システムが入力エラーを表示し、変更前の商品情報と商品審査状態を維持する。<br>5a-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品管理画面では、最初に管理する店舗を選ぶ。<br>・商品の審査はEC-A10で行う。却下理由は運営者が入力したものを表示する。<br>・審査中の商品も編集でき、商品審査状態は「審査中」のままとする。(要確認)<br>・承認済みの商品を編集したときに再審査にするかは未定。(要確認) |
