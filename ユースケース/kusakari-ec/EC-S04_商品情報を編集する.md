# EC-S04 商品情報を編集する

| 記述項目     | 記述内容                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 登録済みの商品情報を変更する。                                                                                                      |
| アクター     | 出店者（画面上の役割）                                                                                                          |
| 事前条件     | 商品管理画面に編集対象の商品がある。                                                                                                   |
| 事後条件     | 変更後の商品情報がデータベースに保存される。                                                                                               |
| 基本フロー    | 1. 出店者が編集対象の商品を選ぶ。<br>2. システムが商品情報をフォームに表示する。<br>3. 出店者が情報を変更して保存する。<br>入力値が不正な場合は => 代替フロー1へ。<br>4. システムが更新結果を表示する。 |
| 代替フロー    | 1. 入力値が不正な場合<br>1-1. システムが入力エラーを表示し、変更前の商品情報を維持する。                                                                   |
