#### EC-S04 商品情報を編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 登録済みの商品情報を変更する。                                                                                                                                                                                                                                                                                             |
| アクター     | 出店者(オーナー、MANAGER(店長)、STAFF)                                                                                                                                                                                                                                                                                                         |
| 事前条件     | 出店者(オーナー、または対象店舗のMANAGER・STAFF)のアカウントでログインしている。<br>「メイン」画面が表示されている。<br>編集対象の商品が登録されている。 |
| 事後条件     | 変更後の商品情報が保存されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「商品管理」を開く(EC-C03)。<br>2. システムが「商品管理」画面を表示し、選択中の店舗の商品一覧と、商品ごとの販売状態を表示する。運営者から警告・公開停止を受けている商品がある場合は、一覧の上の「運営からの警告・停止」欄に商品名と理由を表示し、一覧の行に「警告中」「運営により公開停止中」のバッジを表示する。<br>3. 出店者が編集対象の商品の行の「編集」ボタンをクリックする。<br>4. システムが商品情報を編集フォームに表示し、「変更前の在庫数」を表示する。<br>5. 出店者が編集フォームの入力欄で商品情報を変更する。<br>6. 出店者が「変更を保存」ボタンをクリックする。<br>7. システムが入力内容を検証する。<br>8. システムが商品情報を保存する。<br>9. システムが「商品管理」画面に更新結果を表示する。 |
| 代替フロー    | 7a. 入力値が不正な場合<br>7a-1. システムが入力エラーを表示し、変更前の商品情報を維持する。<br>7a-2. 基本フロー5へ戻る。<br><br>8a. 削除した商品の場合<br>8a-1. システムが取り扱いを終了した商品であることを表示し、変更しない。<br>8a-2. ユースケースを終了する。<br><br>8b. フォームを開いた後に在庫数が変わっていた場合(注文による引き当てなど)<br>8b-1. システムが変更を保存せず、最新の在庫数を表示して再確認を求める。<br>8b-2. 基本フロー5へ戻る。<br><br>8c. 商品を編集する権限がない場合(ロールなし)<br>8c-1. システムが「この操作の権限がありません。」と表示し、変更しない。<br>8c-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・担当する店舗の商品だけを編集できる。STAFFも価格を含めて編集できる。<br>・編集を中止する場合は「戻る」ボタンで商品一覧へ戻る。<br>・運営者から警告・公開停止を受けた商品は、その理由がイベント通知(EC-S11)で届く。商品を編集しても、警告も公開停止も解除されない(EC-A10)。 |
