#### EC-S04 商品情報を編集する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 登録済みの商品情報を変更する。                                                                                                                                                                                                                                                                                             |
| アクター     | 出店者                                                                                                                                                                                                                                                                                                         |
| 事前条件     | 出店者アカウントでログインしている。<br>編集対象の商品が登録されている。                                                                                                                                                                                                                                                                      |
| 事後条件     | 変更後の商品情報が保存されている。 |
| 基本フロー    | 1. 出店者が「商品一覧・登録」を開く。<br>2. システムが所属店舗の商品一覧と、商品ごとの販売状態を表示する。<br>3. 出店者が編集対象の商品を選ぶ。<br>4. システムが商品情報をフォームに表示する。<br>5. 出店者が情報を変更して保存する。<br>6. システムが商品情報を保存する。<br>7. システムが更新結果を表示する。 |
| 代替フロー    | 5a. 入力値が不正な場合<br>5a-1. システムが入力エラーを表示し、変更前の商品情報を維持する。<br>5a-2. 基本フロー5へ戻る。<br><br>6a. 削除した商品の場合<br>6a-1. システムが取り扱いを終了した商品であることを表示し、変更しない。<br>6a-2. ユースケースを終了する。<br><br>6b. フォームを開いた後に在庫数が変わっていた場合(注文による引き当てなど)<br>6b-1. システムが変更を保存せず、最新の在庫数を表示して再確認を求める。<br>6b-2. 基本フロー5へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・自店舗の商品だけを編集できる。<br>・運営者に公開を停止された商品は、停止の理由がイベント通知(EC-S11)で届く。商品を編集しても公開停止は解除されない(EC-A10)。 |
