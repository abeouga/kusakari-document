# EC-A05 店舗情報を確認する

| 記述項目     | 記述内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| ユースケース概要 | 管理者向け画面で店舗情報を確認する。                                                                   |
| アクター     | 管理者（運営者）                                                                             |
| 事前条件     | 店舗一覧を利用できる。                                                                          |
| 事後条件     | 選択した店舗情報が表示される。                                                                      |
| 基本フロー    | 1. 管理者が店舗一覧を開く。<br>2. システムが店舗を表示する。<br>対象がない場合は => 代替フロー1へ。<br>3. 管理者が対象を選び、情報を確認する。 |
| 代替フロー    | 1. 対象がない場合<br>1-1. システムが対象店舗なしを表示する。                                                 |
