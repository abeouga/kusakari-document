#### EC-A05 店舗情報を確認する

| 記述項目     | 記述内容                                                         |
| -------- | ------------------------------------------------------------ |
| ユースケース概要 | 運営者向け画面で店舗情報を確認する。                                           |
| アクター     | 運営者                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件     | 店舗の一覧と各店舗の情報が表示されている。 |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「店舗管理」を開く(EC-C02)。<br>2. システムが「店舗管理」画面に店舗の一覧(店舗名、メールアドレス、所在地、利用状態)を表示する。<br>3. 運営者が対象の店舗の情報を確認する。 |
| 代替フロー    | 2a. 店舗がない場合<br>2a-1. システムが「対象の店舗はありません。」を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・店舗の利用の停止・再開はEC-A11で行う。 |
