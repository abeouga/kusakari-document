#### EC-A05 店舗情報を確認する

| 記述項目     | 記述内容                                                         |
| -------- | ------------------------------------------------------------ |
| ユースケース概要 | 運営者向け画面で店舗の一覧と各店舗の状態を確認する。                                           |
| アクター     | 運営者                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件     | 店舗の一覧と各店舗の情報が表示されている。 |
| 基本フロー    | 1. 運営者が運営者画面のメニュー「店舗管理」を開く(EC-C02)。<br>2. システムが「店舗管理」画面に店舗の一覧(店舗名、会社名、所在地、状態、「注文実績を見る」リンク)を表示する。状態は「公開中」「非公開」「運営により停止中」「閉鎖中(オーナーが開始・未完了の注文 N件)」「閉鎖中(運営が開始・未完了の注文 N件)」「閉鎖済み」のいずれかを表示する。警告中の店舗には「警告中」のバッジと警告の理由を表示する。<br>3. 運営者が必要に応じて「店舗名・会社名・所在地で検索」入力欄に店舗名・会社名・所在地の一部を入力する。<br>4. システムが入力内容に部分一致する店舗のみを一覧に表示する。<br>5. 運営者が対象の店舗の情報を確認する。 |
| 代替フロー    | 2a. 店舗がない場合<br>2a-1. システムが「対象の店舗はありません。」を表示する。<br>2a-2. ユースケースを終了する。<br><br>4a. 該当する店舗がない場合<br>4a-1. システムが「検索条件に一致する店舗はありません。」を表示する。<br>4a-2. 基本フロー3へ戻る。<br><br>5a. 店舗の注文実績を確認する場合<br>5a-1. 運営者が対象店舗の「注文実績を見る」リンクをクリックする。<br>5a-2. システムが「店舗の注文実績」画面に、店舗名、注文数・支払い待ち・キャンセル・キャンセル申請中の件数、注文金額・販売手数料・差引額の合計、注文ごとの一覧(注文番号、注文日時、状態、支払方法、注文金額、手数料率、販売手数料、差引額)を表示する。閉鎖済みの店舗には「閉鎖済み」と、読み取り専用である旨を表示する。<br>5a-3. 運営者が「店舗管理へ戻る」リンクをクリックすると、基本フロー2へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・店舗への警告と、店舗の利用の停止・再開はEC-A11で行う。<br>・「店舗管理」画面では、店舗の閉鎖、閉鎖の取り消し、閉鎖中の店舗の未完了の注文のまとめてキャンセルもできる。<br>・販売手数料の表示はEC-S07の関連情報を参照。 |
