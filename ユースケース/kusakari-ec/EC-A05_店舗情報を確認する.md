#### EC-A05 店舗情報を確認する

| 記述項目     | 記述内容                                                         |
| -------- | ------------------------------------------------------------ |
| ユースケース概要 | 運営者向け画面で店舗情報を確認する。                                           |
| アクター     | 運営者                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>店舗一覧を利用できる。                                                  |
| 事後条件     | 選択した店舗情報が表示されている。                                            |
| 基本フロー    | 1. 運営者が店舗一覧を開く。<br>2. システムが店舗を表示する。<br>3. 運営者が対象を選び、情報を確認する。 |
| 代替フロー    | 2a. 対象がない場合<br>2a-1. システムが対象店舗なしを表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
