# EC-B22 受取状況を確認する

| 記述項目     | 記述内容                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 注文の受取情報を確認する。                                                                                                                                |
| アクター     | 利用者（購入者）                                                                                                                                     |
| 事前条件     | 購入状況の画面を利用できる。                                                                                                                               |
| 事後条件     | 注文の表示内容を確認できる。                                                                                                                               |
| 基本フロー    | 1. 利用者が履歴を開く<br>2. システムは履歴画面を表示する<br>3. 利用者が履歴一覧から購入状況を開く<br>4. システムは注文内容と配送状況、配送会社、追跡番号を表示する<br>表示対象がない場合は => 代替フロー1へ。<br>5. 利用者が表示内容を確認する。 |
| 代替フロー    | 1. 表示対象がない場合<br>1-1. システムが表示対象なしの状態を示す。                                                                                                      |
