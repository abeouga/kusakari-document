# EC-B23 利用ガイド・利用方法を確認する

| 記述項目     | 記述内容                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 利用ガイド・利用方法を読む                                                                                       |
| アクター     | 利用者                                                                                                 |
| 事前条件     | サービス案内(kusakariについて)がヘッダーに表示されている。                                                                  |
| 事後条件     | 利用ガイド・利用方法が表示される。                                                                                   |
| 基本フロー    | 1. 「kusakariについて」を選ぶ。<br>2. 利用ガイド・利用方法をポップアップする。<br>3. 利用者が内容を確認して案内を閉じる。<br>表示に失敗した場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 案内を表示できない場合<br>1-1. システムがエラーを示して元の画面へ戻す。                                                         |
