#### EC-B23 利用ガイド・利用方法を確認する

| 記述項目     | 記述内容                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| ユースケース概要 | ヘッダーの「kusakariについて」から、利用ガイド・利用方法を確認する。                                                |
| アクター     | 利用者(購入者・出店者)                                                                                   |
| 事前条件     | サービス案内(「kusakariについて」)がヘッダーに表示されている。                                                  |
| 事後条件     | 利用ガイド・利用方法が表示されている。                                                                   |
| 基本フロー    | 1. 利用者が「kusakariについて」を選ぶ。<br>2. システムが利用ガイド・利用方法をポップアップで表示する。<br>3. 利用者が内容を確認して案内を閉じる。 |
