#### EC-S09 注文を受取準備完了にする

| 記述項目     | 記述内容                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 注文の状態を「受取準備完了」に更新し、購入者に通知する。                                                                             |
| アクター     | 出店者                                                                                                      |
| 事前条件     | 出店者アカウントでログインしている。<br>管理する店舗の注文一覧画面が表示されている。<br>対象注文の状態が「注文受付」になっている。                                            |
| 事後条件     | 注文状態が「受取準備完了」になり、購入者にサイト内通知とメールで通知されている。                                                            |
| 基本フロー    | 1. 出店者が対象注文の「受取準備完了にする」を選択する。<br>2. システムが確認メッセージを表示する。<br>3. 出店者が確定する。<br>4. システムが注文状態を「受取準備完了」に更新する。<br>5. システムがサイト内通知とメールで購入者に受取準備完了を通知する。 |
| 代替フロー    | 3a. 確定を取り消した場合<br>3a-1. システムが注文状態を更新せず、注文一覧を表示する。<br>3a-2. ユースケースを終了する。<br><br>4a. 対象注文の状態が「注文受付」でなくなっている場合(キャンセル済みなど)<br>4a-1. システムが注文状態が変更されていることを表示し、更新しない。<br>4a-2. システムが最新の注文一覧を表示する。<br>4a-3. ユースケースを終了する。<br><br>5a. 通知に失敗した場合<br>5a-1. システムが注文状態を「受取準備完了」のままにし、通知を再送する。<br>5a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・受取準備完了にした注文は、EC-S10で「引き渡し完了」に更新する。<br>・サイト内通知は購入者がEC-B15で確認する。 |
