#### EC-A06 商品情報を確認する

| 記述項目     | 記述内容                                                           |
| -------- | -------------------------------------------------------------- |
| ユースケース概要 | 運営者向け画面で商品の一覧と公開状態を確認する。 |
| アクター     | 運営者                                                       |
| 事前条件     | 運営者アカウントでログインしている。<br>「トップ」画面が表示されている。 |
| 事後条件     | 商品の一覧と各商品の公開状態が表示されている。 |
| 基本フロー    | 1. 運営者が運営者画面のメニュー「商品管理」を開く(EC-C02)。<br>2. システムが「商品管理」画面に商品の一覧と、商品ごとの商品名、店舗名、公開状態(「公開可能」/「公開停止中」/「販売終了」)を表示する。警告中の商品には「警告中」のバッジと警告の理由を表示する。<br>3. 運営者が対象商品の状態を確認する。<br>4. 運営者が必要に応じて対象商品の「警告・停止の履歴」を開く。<br>5. システムが警告・警告の解除・停止・再開の履歴を、新しい順に日時・操作した運営者・理由とともに表示する。 |
| 代替フロー    | 2a. 商品がない場合<br>2a-1. システムが「対象の商品はありません。」を表示する。<br>2a-2. ユースケースを終了する。<br><br>5a. 履歴がない場合<br>5a-1. システムが「履歴はありません。」を表示する。<br>5a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品への警告と、商品の公開の停止・再開はEC-A10で行う。 |
