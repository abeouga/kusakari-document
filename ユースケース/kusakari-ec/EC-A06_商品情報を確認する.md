#### EC-A06 商品情報を確認する

| 記述項目     | 記述内容                                                           |
| -------- | -------------------------------------------------------------- |
| ユースケース概要 | 運営者向け画面で商品の一覧と公開状態を確認する。 |
| アクター     | 運営者                                                       |
| 事前条件     | 運営者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 商品の一覧と各商品の公開状態が表示されている。 |
| 基本フロー    | 1. 運営者が管理者画面のメニュー「商品管理」を開く(EC-C02)。<br>2. システムが「商品管理」画面に商品の一覧と、商品ごとの公開状態(「公開可能」/「公開停止中」/「販売終了」)を表示する。<br>3. 運営者が対象商品の状態を確認する。 |
| 代替フロー    | 2a. 商品がない場合<br>2a-1. システムが「対象の商品はありません。」を表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・商品の公開の停止・再開はEC-A10で行う。 |
