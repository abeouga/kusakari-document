#### EC-A10 商品を審査する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 運営者が出店者の登録した商品の内容を確認し、承認または却下する。                                                                                                                                                                                                                                                                                                                                                        |
| アクター     | 運営者                                                                                                                                                                                                                                                                                                                                                                                     |
| 事前条件     | 運営者アカウントでログインしている。<br>商品審査画面を利用できる。                                                                                                                                                                                                                                                                                                                                                     |
| 事後条件     | 対象商品の商品審査状態が「承認」または「却下」として保存され、出店者に審査結果が通知されている。                                                                                                                                                                                                                                                                                                                                        |
| 基本フロー    | 1. 運営者が「商品審査」を選択する。<br>2. システムが商品審査状態が「審査中」の商品を取得する。<br>3. システムが審査待ち商品一覧(商品名、店舗名、申請日)を表示する。<br>4. 運営者が審査対象の商品を選ぶ。<br>5. システムが商品の詳細、却下理由の入力欄、「承認する」「却下する」を表示する。<br>6. 運営者が商品の内容を確認し、「承認する」または「却下する」を選ぶ。却下する場合は、却下理由を入力してから「却下する」を選ぶ。<br>7. システムが商品の商品審査状態を、選ばれた結果(「承認」/「却下」)に更新する。<br>8. システムが出店者向けのイベント通知(EC-S11)で審査結果を通知する。却下の場合は却下理由も通知に含める。<br>9. システムが審査完了メッセージを表示し、審査待ち商品一覧を再表示する。 |
| 代替フロー    | 3a. 審査待ちの商品がない場合<br>3a-1. システムが「審査待ちの商品はありません」と表示する。<br>3a-2. ユースケースを終了する。<br><br>6a. 却下理由が未入力のまま「却下する」を選んだ場合<br>6a-1. システムが却下理由の入力を求めるエラーメッセージを表示し、商品審査状態を変更しない。<br>6a-2. 基本フロー6へ戻る。                                                                                                                                                                                                   |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・EC-S03で登録された商品は商品審査状態が「審査中」となり、承認されるまで購入者向けの画面には表示しない。<br>・却下された商品は、出店者がEC-S04で修正すると再び「審査中」になる。<br>・審査結果は出店者向けのイベント通知(EC-S11)で知らせる。<br>・商品の商品審査状態はEC-A06でも確認できる。                                                                                                                                                                                                 |
