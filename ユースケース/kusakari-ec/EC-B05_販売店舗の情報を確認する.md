# EC-B05 販売店舗の情報を確認する

| 記述項目     | 記述内容                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| ユースケース概要 | 商品を販売する店舗の詳細情報を確認する。                                                            |
| アクター     | 利用者（購入者）                                                                        |
| 事前条件     | 商品詳細に販売店舗へのリンクが表示されている。                                                         |
| 事後条件     | 取得できた店舗情報または情報がない状態が表示される。                                                      |
| 基本フロー    | 1. 利用者が販売店舗の紹介を選ぶ。<br>2. システムが店舗名・住所など取得可能な情報を表示する。<br>情報を取得できない場合は => 代替フロー1へ。 |
| 代替フロー    | 1. 店舗情報が取得できない場合<br>1-1. システムはエラーメッセージを表示する |
