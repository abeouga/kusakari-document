#### EC-B05 販売店舗の情報を確認する

| 記述項目     | 記述内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| ユースケース概要 | 商品を販売する店舗の詳細情報を確認する。                                                 |
| アクター     | 購入者                                                             |
| 事前条件     | 商品詳細に販売店舗へのリンクが表示されている。                                              |
| 事後条件     | 取得できた店舗情報または情報がない状態が表示されている。                                         |
| 基本フロー    | 1. 購入者が商品詳細で「販売店舗の紹介」を選ぶ。<br>2. システムが店舗名・住所・営業時間・店舗紹介・営業状態を表示する。 |
| 代替フロー    | 2a. 店舗が見つからない場合<br>2a-1. システムが店舗が見つからないことを表示し、再取得を可能にする。<br>2a-2. ユースケースを終了する。 |
