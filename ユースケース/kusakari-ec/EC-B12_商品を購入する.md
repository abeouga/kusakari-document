# EC-B12 商品を購入する

| 記述項目     | 記述内容             |
| ----------- | -------------------- |
| ユースケース概要 | 受取店舗を指定し、カート内容・受取店舗・支払方法を確認して注文する。                                |
| アクター     | 利用者（購入者）                                                    |
| 事前条件     | カートに商品が1つ以上存在する            |
| 事後条件     | 選択店舗がカートの受取店舗として設定される。<br>成功時は注文完了画面が表示され、注文明細が記録される。                               |
| 基本フロー    | 1. システムがカート画面を表示する。<br>2. 利用者が受取店舗を選ぶ。（位置情報の利用を許可した場合は距離順、許可しない場合は店舗一覧の順に候補が表示される）<br>3. 利用者が支払方法、受取者名、電話番号、メールアドレスを入力または、アカウント情報から選択する。<br>4. 利用者が受取・配送希望日と希望時間帯を入力する。<br>5. 利用者が注文内容確認を選ぶ。<br>6. システムが注文金額と在庫を再確認する。<br>在庫不足・在庫競合・入力不備がある場合は => 代替フロー1へ。<br>7. 利用者が注文確定を選ぶ。<br>8. システムが在庫を更新し、注文明細を保存する。<br>保存に失敗した場合は => 代替フロー2へ。<br>9. システムが注文結果を表示する。 |
| 代替フロー    | 1. 在庫不足・在庫競合・入力不備がある場合<br>1-1. システムが注文を拒否し、カートや入力内容の再確認を促すエラーメッセージを表示する。<br><br>2. 保存に失敗した場合<br>2-1. システムが「注文失敗」を表示し、在庫とカートを更新して再操作できるようにする。  |
