#### EC-B12 商品を購入する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 受取店舗と支払方法を指定し、カート内の商品を店舗受け取りで注文する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 事前条件     | ログイン状態である。<br>カートに商品が1つ以上存在する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 事後条件     | 成功時は注文が注文状態「注文受付」で購入者のアカウントに紐づいて記録され、在庫が減り、出店者に新しい注文が通知され、注文完了画面が表示されている。<br>失敗時は注文が行われず、カートの内容が維持されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 基本フロー    | 1. 購入者がヘッダーの「カート」ボタンを選ぶ。<br>2. システムがカート画面を表示する<br>3.「注文内容を確認する」ボタンを選ぶ<br>4. 購入者が受取店舗を1つ選び、「この店舗で受け取る」を選ぶ(位置情報の利用を許可した場合は現在地から、許可しない場合は既定の地点から近い順に候補が表示される)。<br>5. 購入者が支払方法を一覧から選択する。<br>6. 購入者が「お支払い・受け取りの確認」を選ぶ。<br>7. システムが在庫と価格を確認し、注文内容(商品・受取店舗・受取連絡先・支払方法・合計)を表示する。<br>8. 購入者が「注文を確定する」を選ぶ。<br>9. システムが在庫を引き当て、注文明細を注文状態「注文受付」で保存し、カートを空にする。<br>10. システムが出店者に新しい注文をイベント通知(EC-S11)で知らせる。<br>11. システムが注文完了画面に注文番号を表示する。                                                                                                                                                                                                                            |
| 代替フロー    | 7a. 在庫不足・購入可能でない商品がある場合<br>7a-1. システムが注文を拒否し、該当する商品を示してエラーメッセージを表示する。<br>7a-2. 購入者がカートを修正する。<br>7a-3. 基本フロー5へ戻る。<br><br>7b. カートに入れた後に商品の価格が変わっていた場合<br>7b-1. システムが注文を確定せず、価格が変わったことを表示して最新の価格でカートを表示する。<br>7b-2. 購入者が内容を確認する。<br>7b-3. 基本フロー5へ戻る。<br><br>9a. 在庫の引き当てに失敗した場合(直前に他の購入者が購入した場合など)<br>9a-1. システムが注文と在庫の減算を保存せず、「在庫が変更されました」と表示する。<br>9a-2. システムがカートと在庫を最新の内容に取り直して表示する。<br>9a-3. 購入者がカートを修正する。<br>9a-4. 基本フロー5へ戻る。<br><br>9b. 選んだ受取店舗が利用停止になっていた場合<br>9b-1. システムが注文を保存せず、受取店舗を選び直すよう表示する。<br>9b-2. 基本フロー3へ戻る。<br><br>9c. 保存に失敗した場合<br>9c-1. システムが注文も在庫の減算も保存せず、「注文失敗」を表示する。<br>9c-2. システムがカートの内容を維持したまま再操作できるようにする。<br>9c-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カート内の商品は、すべて選んだ受取店舗の在庫から購入する。1回の注文の受取店舗は1つとする。<br>・受取連絡先(お名前・電話番号)はアカウントに登録した内容を使う。登録は任意で、未登録でも店頭で注文番号を伝えて受け取れる。<br>・受取希望日時は指定しない。受け取りの準備ができたら利用者通知(EC-B15)で知らせる(EC-S09)。<br>・支払方法は注文に記録し、実際の支払いは本システムでは扱わない。<br>・「注文を確定する」を続けて押しても、注文は1件だけ記録する。<br>・保存した注文明細は注文履歴に表示される。<br>・注文状態は「注文受付」→「受取準備完了」(EC-S09)→「引き渡し完了」(EC-S10)と進む。キャンセル申請が承認されると「キャンセル済み」(EC-S13)になる。<br>・在庫の引き当てでは、同じ在庫を同時に引き当てないようにしてから数量を確認する。不足する場合は在庫不足として扱い、注文も在庫の減算も保存しない。                                                                                                                                                                                 |
