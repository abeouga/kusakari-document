#### EC-B12 商品を購入する

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 受取店舗と支払方法を指定して決済し、カート内の商品を注文する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 事前条件     | ログイン状態である。<br>カートに商品が1つ以上存在する。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 事後条件     | 成功時は決済が完了し、注文が注文状態「注文受付」で購入者のアカウントに紐づいて記録され、出店者に新しい注文が通知され、注文完了画面が表示されている。<br>失敗時は決済・注文が行われず、カートの内容が維持されている。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 基本フロー    | 1. 購入者がヘッダーの「カート」ボタンを選ぶ。<br>2. システムがカート画面を表示する。<br>3. 購入者が受取店舗を1つ選ぶ(位置情報の利用を許可した場合は距離順、許可しない場合は店舗一覧の順に候補が表示される)。<br>4. 購入者が受取者名、電話番号、メールアドレスを入力する。<br>5. 購入者が支払方法を一覧から選択する。<br>6. 購入者が受取希望日と希望時間帯を入力する。<br>7. 購入者が「注文内容確認」を選ぶ。<br>8. システムが在庫と入力内容を確認し、注文内容(商品・受取店舗・支払合計)を表示する。<br>9. 購入者が「注文確定」を選ぶ。<br>10. システムが在庫を引き当て、支払合計で決済を実行する。<br>11. システムが注文明細を注文状態「注文受付」で保存し、カートを空にする。<br>12. システムが出店者に新しい注文をイベント通知(EC-S11)で知らせる。<br>13. システムが注文完了画面に注文番号を表示する。                                                                                                                                                                                   |
| 代替フロー    | 8a. 在庫不足・在庫競合・購入可能でない商品・入力不備がある場合<br>8a-1. システムが注文を拒否し、該当する商品または入力項目を示してエラーメッセージを表示する。<br>8a-2. 購入者がカートまたは入力内容を修正する。<br>8a-3. 基本フロー7へ戻る。<br><br>10a. 在庫の引き当てに失敗した場合(直前に他の購入者が購入した場合など)<br>10a-1. システムが注文と在庫の減算を保存せず、「在庫が変更されました」と表示する。<br>10a-2. システムがカートと在庫を最新の内容に取り直して表示する。<br>10a-3. 購入者がカートを修正する。<br>10a-4. 基本フロー7へ戻る。<br><br>10b. 決済に失敗した場合<br>10b-1. システムが引き当てた在庫を戻し、「決済に失敗しました」と理由(カード利用不可・残高不足・通信エラーなど)を表示する。<br>10b-2. システムが入力内容を保持したまま支払方法の選択欄を表示する。<br>10b-3. 購入者が支払方法を選び直す。<br>10b-4. 基本フロー7へ戻る。<br><br>11a. 保存に失敗した場合<br>11a-1. システムが実行した決済を取り消し、引き当てた在庫を戻す。<br>11a-2. システムが「注文失敗」を表示し、カートの内容を維持したまま再操作できるようにする。<br>11a-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・カート内の商品が複数の出店者にまたがる場合も、受取店舗は1つにまとめる。まとめる方法は未決定。<br>・保存した注文明細は注文履歴に表示される。<br>・注文状態は「注文受付」→「受取準備完了」(EC-S09)→「引き渡し完了」(EC-S10)と進む。キャンセル申請が承認されると「キャンセル済み」(EC-S13)になる。<br>・在庫の引き当てでは、同じ在庫を同時に引き当てないようにしてから数量を確認する。不足する場合は在庫不足として扱い、注文も在庫の減算も保存しない。 |
