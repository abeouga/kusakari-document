#### EC-B16 一般アカウントを登録する

| 記述項目     | 記述内容                                                                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者としてメールアドレス・パスワードを入力し、アカウントを登録する。 |
| アクター     | 購入者                                                                                                                                                                                    |
| 事前条件     | ログアウト状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | アカウントが保存され、登録したアカウントでログイン状態になっている。                                                                                                                                                     |
| 基本フロー    | 1. 購入者が「メイン」画面から共通ヘッダーの「ログイン」をクリックする。<br>2. システムが「ログイン」画面を表示する。<br>3. 購入者が「新規登録」ボタンをクリックする。<br>4. システムが認証サービスのアカウント登録画面を表示する。<br>5. 購入者がメールアドレスを入力する。<br>6. 購入者がパスワードを入力する。<br>7. 購入者がアカウント登録画面の登録ボタンをクリックする。<br>8. システムが入力形式(パスワードは8文字以上)とメールアドレスの重複を確認する。<br>9. システムが入力されたメールアドレスに確認コードを送信し、確認コード入力画面を表示する。<br>10. 購入者がメールに届いた確認コードを入力する。<br>11. 購入者が確認コード入力画面の確認ボタンをクリックする。<br>12. システムがアカウントを保存してログイン状態にし、「メイン」画面を表示する。 |
| 代替フロー    | 8a. 無効な値または重複がある場合<br>8a-1. システムが入力エラーまたはメールアドレス重複を表示し、登録しない。<br>8a-2. 基本フロー5へ戻る。<br><br>11a. 確認コードが無効または有効期限切れの場合<br>11a-1. システムがエラーを表示し、確認コードの再入力または再送を可能にする。<br>11a-2. 基本フロー10へ戻る。 |
| 関連情報     | ・アカウント登録・確認コードの画面は認証サービスの画面で行う。<br>・お名前は登録しない。画面上の表示名にはメールアドレスを使う。<br>・メールアドレスの確認が済むまでは、ECにログインできない(EC-B01)。 |
