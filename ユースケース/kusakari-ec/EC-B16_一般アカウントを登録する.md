#### EC-B16 一般アカウントを登録する

| 記述項目     | 記述内容                                                                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者としてメールアドレス・パスワードを入力し、アカウントを登録する。 |
| アクター     | 購入者                                                                                                                                                                                    |
| 事前条件     | ログアウト状態である。 |
| 事後条件     | アカウントが保存され、登録したアカウントでログイン状態になっている。                                                                                                                                                     |
| 基本フロー    | 1. 購入者がログイン画面の「新規登録」を選ぶ。<br>2. システムがアカウント登録画面を表示する。<br>3. 購入者がメールアドレス・パスワードを入力して登録を送信する。<br>4. システムが入力形式(パスワードは8文字以上)とメールアドレスの重複を確認する。<br>5. システムが入力されたメールアドレスに確認コードを送信し、確認コード入力画面を表示する。<br>6. 購入者がメールに届いた確認コードを入力する。<br>7. システムがアカウントを保存し、ログイン状態にする。 |
| 代替フロー    | 4a. 無効な値または重複がある場合<br>4a-1. システムが入力エラーまたはメールアドレス重複を表示し、登録しない。<br>4a-2. 基本フロー3へ戻る。<br><br>6a. 確認コードが無効または有効期限切れの場合<br>6a-1. システムがエラーを表示し、確認コードの再入力または再送を可能にする。<br>6a-2. 基本フロー6へ戻る。 |
| 関連情報     | ・アカウント登録・確認コードの画面は認証サービスの画面で行う。<br>・お名前は登録しない。画面上の表示名にはメールアドレスを使う。<br>・メールアドレスの確認が済むまでは、ECにログインできない(EC-B01)。 |
