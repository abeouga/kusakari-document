#### EC-B16 一般アカウントを登録する

| 記述項目     | 記述内容                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者としてお名前・メールアドレス・パスワードを入力し、アカウントを登録する。                                                                                                                               |
| アクター     | 購入者                                                                                                                                                              |
| 事前条件     | ログアウト状態である。<br>登録フォームを利用できる。                                                                                                                                            |
| 事後条件     | アカウントが保存され、登録したアカウントでログイン状態になっている。                                                                                                                               |
| 基本フロー    | 1. 購入者がアカウント管理画面または共通ヘッダーの登録フォームを開く。<br>2. 購入者がお名前・メールアドレス・パスワードを入力して登録を送信する。<br>3. システムが入力形式(パスワードは8文字以上)とメールアドレスの重複を確認する。<br>4. システムがアカウントを保存し、ログイン状態にする。<br>5. システムが登録完了メッセージを表示する。 |
| 代替フロー    | 3a. 無効な値または重複がある場合<br>3a-1. システムが入力エラーまたはメールアドレス重複を表示し、登録しない。<br>3a-2. 基本フロー2へ戻る。 |
| 関連情報     | ・パスワードの規則はEC-B19と同じ(8文字以上)とする。<br>・メールアドレスの到達確認(確認コードの送信など)を行うかは未定。(要確認) |
