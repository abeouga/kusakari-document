# EC-B16 一般アカウントを登録する

| 記述項目     | 記述内容                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 一般利用者としてアカウント画面または共通ヘッダーの登録フォームに情報を入力する。                                                                                                         |
| アクター     | 利用者（購入希望者）                                                                                                                                       |
| 事前条件     | 登録フォームを利用できる。                                                                                                                                    |
| 事後条件     | アカウント画面では利用者とログイン状態が追加され、共通ヘッダーでは入力確認メッセージが表示される。                                                                                                |
| 基本フロー    | 1. 利用者がお名前・メールアドレス・パスワードを入力する。<br>2. システムが形式とメールアドレス重複を確認する。<br>無効な値または重複がある場合は => 代替フロー1へ。<br>3. 利用者が登録を送信する。<br>4. システムが登録結果または入力確認メッセージを表示する。 |
| 代替フロー    | 1. 無効な値または重複がある場合<br>1-1. システムが入力エラーまたはメールアドレス重複を表示し、登録しない。                                                                                      |
