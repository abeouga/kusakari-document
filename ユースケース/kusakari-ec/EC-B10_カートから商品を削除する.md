#### EC-B10 カートから商品を削除する

| 記述項目     | 記述内容                                                                      |
| -------- | ------------------------------------------------------------------------- |
| ユースケース概要 | カートから選択した商品を削除する。                                                         |
| アクター     | 購入者                                                                  |
| 事前条件     | カートに対象商品がある。                                                              |
| 事後条件     | 対象商品がカートから削除され、合計が更新されている。                                                |
| 基本フロー    | 1. 購入者が対象商品の削除を選ぶ。<br>2. システムが削除内容を反映する。<br>3. システムが更新後のカートを表示する。         |
| 代替フロー    | 2a. 削除に失敗した場合<br>2a-1. システムが削除エラーを表示し、最新のカートを再取得する。<br>2a-2. ユースケースを終了する。 |
