# EC-B10 カートから商品を削除する

| 記述項目 | 記述内容 |
|---|---|
| ユースケース概要 | カートから選択した商品を削除する。 |
| アクター | 利用者（購入者） |
| 事前条件 | カートに対象商品がある。 |
| 事後条件 | 対象商品がカートから削除され、合計が更新される。 |
| 基本フロー | 1. 利用者が対象商品の削除を選ぶ。<br>2. システムが削除内容を反映する。<br>削除に失敗した場合は => 代替フロー1へ。<br>3. システムが更新後のカートを表示する。 |
| 代替フロー | 1. 削除に失敗した場合<br>1-1. システムが削除エラーを表示し、最新のカートを再取得する。 |
