#### EC-B13 注文履歴を確認する

| 記述項目     | 記述内容                                                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 注文履歴を確認し、注文ごとの受渡状況とキャンセル申請状態を確認する。                                                                                                                         |
| アクター     | 購入者                                                                                                                                               |
| 事前条件     | ログイン状態である。                                                                                                                                             |
| 事後条件     | アカウントに紐付く注文履歴が表示されている。                                                                                                                                 |
| 基本フロー    | 1. 購入者が注文履歴を開く。<br>2. システムがアカウントに紐付く注文を取得する。<br>3. システムが注文履歴の一覧を表示する。<br>4. 購入者が一覧から注文を選ぶ。<br>5. システムが注文内容と受渡状況、受取店舗、受取希望日時、キャンセル申請状態(却下の場合は却下理由)を表示する。<br>6. 購入者が表示内容を確認する。 |
| 代替フロー    | 2a. 注文件数が0件の場合<br>2a-1. システムが注文がないことを示すメッセージを表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・受渡状況は出店者がEC-S09(受取準備完了)、EC-S10(引き渡し完了)で更新する。 |
