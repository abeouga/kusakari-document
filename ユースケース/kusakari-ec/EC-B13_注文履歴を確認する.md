#### EC-B13 注文履歴を確認する

| 記述項目     | 記述内容                                                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 注文履歴を確認し、注文ごとの受渡状況とキャンセル申請状態を確認する。                                                                                                                         |
| アクター     | 購入者                                                                                                                                               |
| 事前条件     | ログイン状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | アカウントに紐付く注文履歴が表示されている。                                                                                                                                 |
| 基本フロー    | 1. 購入者が「メイン」画面から共通ヘッダーの「注文履歴」リンクをクリックする。<br>2. システムがアカウントに紐付く注文を取得する。<br>3. システムが「注文履歴」画面に、注文ごとの注文日時、注文状態、商品画像、商品名、受取店舗、個数、注文番号、合計金額を一覧表示する。<br>4. 購入者が必要に応じて、注文状態の絞り込みボタン(「すべて」「注文受付」「受取準備完了」「引き渡し完了」「キャンセル」)のいずれかをクリックする。<br>5. システムが選んだ注文状態の注文だけを一覧に表示する。<br>6. 購入者が一覧から確認したい注文をクリックする。<br>7. システムが注文の詳細を開き、注文した商品、小計・合計、「受け取り」欄(受取店舗、「準備完了日時」、「引き渡し完了日時」)、キャンセル申請状態(申請中は「キャンセル申請中」、承認・却下は「キャンセル申請（承認/却下）」と理由。却下の場合は「店舗からの回答」)を表示する。<br>8. 購入者が表示内容を確認する。 |
| 代替フロー    | 2a. 注文件数が0件の場合<br>2a-1. システムが「注文履歴」画面に「注文はありません。」と表示する。<br>2a-2. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・受渡状況は出店者がEC-S09(受取準備完了)、EC-S10(引き渡し完了)で更新する。<br>・注文履歴では、注文の詳細にある「受取連絡先を編集」で受取連絡先の編集と、「購入履歴を非表示にする」で購入履歴の非表示もできる。非表示にしても注文そのものは取り消されない。 |
