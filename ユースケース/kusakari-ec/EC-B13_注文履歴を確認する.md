# EC-B13 注文履歴を確認する

| 記述項目     | 記述内容                                                                                        |
| -------- | ------------------------------------------------------------------------------------------- |
| ユースケース概要 | 注文履歴を確認する。                                                                                  |
| アクター     | 利用者（購入者）                                                                                    |
| 事前条件     | 注文を確定したことある                                                                                 |
| 事後条件     | アカウントに紐付く注文履歴が表示される。                                                                        |
| 基本フロー    | 1. 利用者が注文履歴を開く。<br>2. システムがアカウントに紐付く注文を取得する。<br>取得に失敗した場合は => 代替フロー1へ。<br>3. 利用者が注文内容を確認する。 |
| 代替フロー    | 1. 取得に失敗した場合<br>1-1. システムが取得エラーを表示し、再試行できるようにする。                                            |
