#### EC-B13 注文履歴を確認する

| 記述項目     | 記述内容                                                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 注文履歴を確認し、注文ごとの受渡状況とキャンセル申請状態を確認する。                                                                                                                         |
| アクター     | 購入者                                                                                                                                               |
| 事前条件     | ログイン状態である。<br>「メイン」画面が表示されている。 |
| 事後条件     | アカウントに紐付く注文履歴が表示されている。                                                                                                                                 |
| 基本フロー    | 1. 購入者が共通ヘッダーの「注文履歴」リンクをクリックする。<br>2. システムがアカウントに紐付く注文を取得する。<br>3. システムが「注文履歴」画面に、注文ごとの注文日時、注文状態(「支払い待ち」「注文受付」「受取準備完了」「引き渡し完了」「キャンセル」)、商品画像、商品名、受取店舗、個数、注文番号、合計金額を一覧表示する。キャンセル申請中の注文には「キャンセル申請中」、返金が済んだ注文には「返金済み」も表示する。<br>4. 購入者が必要に応じて、注文状態の絞り込みボタン(「すべて」「注文受付」「受取準備完了」「引き渡し完了」「キャンセル」)のいずれかをクリックする。<br>5. システムが選んだ注文状態の注文だけを一覧に表示する。<br>6. 購入者が一覧から確認したい注文をクリックする。<br>7. システムが注文の詳細を開き、注文した商品(商品名、商品番号、単価×個数、金額)、合計、お支払い方法(カードの場合は支払いの状態「支払い待ち」「支払い済み」「支払いの失敗」「期限切れ」、返金がある場合は返金の状態「返金の処理中」「返金済み」「返金の失敗」)、「受け取り」欄(受取店舗、所在地・営業時間、「準備完了日時」、「引き渡し完了日時」)、キャンセル申請状態(承認・却下は「キャンセル申請（承認/却下）」と理由。回答がある場合は「店舗からの回答」)を表示する。<br>8. 購入者が表示内容を確認する。 |
| 代替フロー    | 2a. 注文件数が0件の場合<br>2a-1. システムが「注文履歴」画面に「注文はありません。」と表示する。<br>2a-2. ユースケースを終了する。<br><br>7a. 受取店舗が閉鎖中で、受け取り前(「注文受付」「受取準備完了」)の注文の場合<br>7a-1. システムが「受け取り」欄に「この店舗は閉鎖予定です。お早めにお受け取りください。」と表示する。<br>7a-2. 基本フロー8へ進む。<br><br>7b. 運営者が注文をキャンセルした場合(店舗の閉鎖・組織の停止によるまとめてキャンセル)<br>7b-1. システムが「この注文は出店者からキャンセルされました（運営から：(理由)）」と表示する。<br>7b-2. 基本フロー8へ進む。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・受渡状況は出店者がEC-S09(受取準備完了)、EC-S10(引き渡し完了)で更新する。<br>・注文履歴では、注文の詳細にある「受取連絡先を編集」で受取連絡先の編集と、「購入履歴を非表示にする」で購入履歴の非表示もできる。非表示にしても注文・在庫・出店者の受注記録は変わらない。<br>・注文受付の注文では、詳細から「注文のキャンセルを申請」できる(EC-B14)。<br>・店舗側のアカウント(出店者のオーナー・担当者)と出店申請用アカウントでは、注文履歴の代わりに「店舗・出店申請用のアカウントでは購入できません。購入は購入者のアカウントでご利用ください。」を表示する。 |
