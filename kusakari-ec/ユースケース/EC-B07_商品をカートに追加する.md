#### EC-B07 商品をカートに追加する

| 記述項目     | 記述内容                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| ユースケース概要 | 商品詳細または商品一覧から選んだ商品をECカートへ追加する。                                                             |
| アクター     | 購入者                                                                                        |
| 事前条件     | 「植物について」ダイアログまたは「トップ」画面の商品一覧に、購入可能な商品が表示されている。                                                                           |
| 事後条件     | 商品と数量がECカートに保存されている。                                                                       |
| 基本フロー    | 1. 購入者が「植物について」ダイアログの「購入数量」欄に数量を入力する。<br>2. システムが数量を検証し、「カートに追加」ボタンをクリックできる状態にする。<br>3. 購入者が「カートに追加」ボタンをクリックする。<br>4. システムが商品・数量を検証する。<br>5. システムがカートに商品と数量を保存し、「カートを更新しました。」と表示する。 |
| 代替フロー    | 1a. 商品一覧から追加する場合<br>1a-1. 購入者が「メイン」画面の商品一覧で、対象商品の商品カードにある「＋」ボタン(カートに追加)をクリックする。<br>1a-2. 基本フロー4へ進む(数量は1点とする)。<br><br>2a. 数量が無効な場合(1未満、整数でない、在庫数または99点を超える)<br>2a-1. システムが「カートに追加」ボタンをクリックできない状態にする。<br>2a-2. 基本フロー1へ戻る。<br><br>4a. 数量が無効または在庫不足の場合<br>4a-1. システムが「選択した店舗の在庫が不足しています。」などのエラーメッセージを表示し、追加しない。<br>4a-2. 基本フロー1へ戻る。                  |
| 関連情報     | ・在庫は、カートで選んでいる受取店舗の在庫を使う。<br>・既にカートにある商品を追加した場合は、カートの数量に加算する。<br>・1つの商品は99点まで、カートに入れられる商品は50種類までとする。<br>・ログインしていなくてもカートに追加できる。ログインすると、そのカートを引き継ぐ。ログインせずにページを再読み込みすると、カートの内容は失われる。 |
