#### EC-B23 利用ガイド・利用方法を確認する

| 記述項目     | 記述内容                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| ユースケース概要 | 共通ヘッダーの「Kusakariについて」から、利用ガイド・利用方法を確認する。 |
| アクター     | 利用者(購入者・出店者)                                                                                   |
| 事前条件     | 共通ヘッダーに「Kusakariについて」が表示されている。 |
| 事後条件     | 利用ガイド・利用方法が表示されている。                                                                   |
| 基本フロー    | 1. 利用者が共通ヘッダーの「Kusakariについて」をクリックする。<br>2. システムが「メイン」画面の上に「Kusakariについて」ポップアップを開き、利用ガイド・利用方法(「お買い物の流れ」「お買い物について」「材料リストについて」)を表示する。<br>3. 利用者が内容を確認する。<br>4. 利用者がポップアップの「閉じる」ボタンをクリックする。<br>5. システムがポップアップを閉じ、「メイン」画面を表示する。 |
