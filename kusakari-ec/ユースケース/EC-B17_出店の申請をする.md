#### EC-B17 出店の申請をする

| 記述項目     | 記述内容                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ユースケース概要 | 出店申請画面で必要な情報を入力し出店の申請をする。                                                                                                                                                                                                                                                                                                                                                                                                |
| アクター     | 購入者                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 事前条件     | 購入者アカウントでログインしている。<br>出店申請をしていない、または前回の申請が却下されている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 出店申請情報が出店審査状態「審査中」として保存され、「出店申請を受け付けました」が表示されている。 |
| 基本フロー    | 1. 購入者がアカウントのメニュー「出店申請」を開く(EC-C01)。<br>2. システムが「出店申請」画面を表示する。<br>3. 購入者が「会社・事業者名」「担当者名」「連絡先メール」「所在地」「電話番号」を入力する。<br>4. 購入者が「希望出店プラン」から「スタンダード」または「生産者直販」を選択する。<br>5. 購入者が「事業確認書類（PDF・PNG・JPEG、5MB以内）」で書類のファイルを選択する。<br>6. 購入者が「確認画面へ」ボタンをクリックする。<br>7. システムが入力内容を検証する。<br>8. システムが「入力内容の確認」に入力した出店申請情報を表示する。<br>9. 購入者が入力情報を確認する。<br>10. 購入者が「申請する」ボタンをクリックする。<br>11. システムが出店申請情報を保存し、「出店申請を受け付けました」と「審査結果は通知でお知らせします。」を表示する。 |
| 代替フロー    | 7a. 必須項目が不足する場合<br>7a-1. システムが「未入力の項目があります：(不足項目)」と表示し、申請を受け付けない。<br>7a-2. システムが入力内容を残したまま「出店申請」画面の入力欄を表示する。<br>7a-3. 基本フロー3へ戻る。<br><br>7b. 入力形式が不正な場合<br>7b-1. システムが入力エラー(「連絡先メールの形式が正しくありません。」「電話番号は数字・＋・括弧・ハイフンで入力してください。」「事業確認書類は5MB以内のファイルを選択してください。」)を表示する。<br>7b-2. システムが入力内容を残したまま「出店申請」画面の入力欄を表示する。<br>7b-3. 基本フロー3へ戻る。<br><br>10a. 入力内容を修正する場合<br>10a-1. 購入者が「入力内容の確認」で「修正する」ボタンをクリックする。<br>10a-2. システムが入力内容を残したまま「出店申請」画面の入力欄を表示する。<br>10a-3. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・サイドバーのリンクの表示(「出店申請」／「出店申請状況」)はEC-B18の関連情報を参照。<br>・再申請の場合は「出店申請状況」画面の「再申請する」から基本フロー3に入り、前回の申請内容が入った状態で「出店申請」画面を表示する。事業確認書類はもう一度選択する。 |
