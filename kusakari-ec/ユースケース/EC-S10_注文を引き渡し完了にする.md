#### EC-S10 注文を引き渡し完了にする

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 購入者が商品を受け取ったことを確認し、注文の状態を「引き渡し完了」に更新する。                                                   |
| アクター     | 出店者                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。<br>対象注文の状態が「受取準備完了」になっている。<br>購入者が商品を受け取ったことを確認している。 |
| 事後条件     | 注文状態が「引き渡し完了」になり、購入者にサイト内通知で通知されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗受け取り」を開く(EC-C03)。<br>2. システムが「店舗受け取り」画面に所属店舗の注文一覧を表示する。<br>3. 出店者が対象注文の「引き渡し完了にする」ボタンをクリックする。<br>4. システムが「引き渡し完了の確認」ダイアログを表示する。<br>5. 出店者が「引き渡し完了を確定」ボタンをクリックする。<br>6. システムが注文状態を「引き渡し完了」に更新する。<br>7. システムがサイト内通知で購入者に引き渡し完了を通知し、更新後の注文状態を表示する。 |
| 代替フロー    | 5a. 確認ダイアログで「取消」ボタンをクリックした場合<br>5a-1. システムが注文状態を更新せず、「店舗受け取り」画面の注文一覧を表示する。<br>5a-2. ユースケースを終了する。<br><br>6a. 対象注文の状態が「受取準備完了」でなくなっている場合(キャンセル済みなど)<br>6a-1. システムが注文状態が変更されていることを表示し、更新しない。<br>6a-2. システムが最新の注文一覧を表示する。<br>6a-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・注文状態を「引き渡し完了」に更新するには、先にEC-S09で「受取準備完了」に更新しないとできない。 |
