#### EC-S02 店舗プロフィールを編集する

| 記述項目     | 記述内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| ユースケース概要 | 店舗名・営業時間・店舗紹介などの店舗プロフィールを編集する。 |
| アクター     | 出店者                                                                                       |
| 事前条件     | 出店者アカウントでログインしている。<br>「メイン」画面が表示されている。 |
| 事後条件     | 店舗ページ(EC-B05)に編集内容が反映されている。 |
| 基本フロー    | 1. 出店者が出店者画面のメニュー「店舗プロフィール」を開く(EC-C03)。<br>2. システムが「店舗プロフィール」画面を表示し、現在の店舗名・会社名・担当者・問い合わせメール・所在地・営業時間・店舗紹介を入力欄に表示する。<br>3. 出店者が店舗名・会社名・担当者・問い合わせメール・所在地・営業時間・店舗紹介の入力欄を編集する。<br>4. 出店者が「店舗情報を保存」ボタンをクリックする。<br>5. システムが入力内容を検証する。<br>6. システムが店舗プロフィールを保存し、編集結果を表示する。 |
| 代替フロー    | 5a. 入力が不正な場合<br>5a-1. システムが入力エラーを表示し、変更を確定しない。<br>5a-2. 基本フロー3へ戻る。<br><br>6a. 表示した後に同じ店舗の別の担当者がプロフィールを更新していた場合<br>6a-1. システムが変更を確定せず、ほかの更新があったことを表示する。<br>6a-2. システムが最新のプロフィールを入力欄に表示し、購入者に表示される内容の再確認を求める。<br>6a-3. 基本フロー3へ戻る。 |
| 関連情報     | ・共通代替フロー *b を適用する。 |
