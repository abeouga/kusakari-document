#### EC-B12 商品を購入する

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 支払方法を指定し、カート内の商品を店舗受け取りで注文する。 |
| アクター     | 購入者 |
| 事前条件     | ログイン状態である。<br>カートに商品が1つ以上存在する。各商品は、カートに追加したときの受取店舗に紐づいている。<br>共通ヘッダーのある画面(「トップ」画面など)が表示されている。 |
| 事後条件     | 成功時は、受取店舗ごとの注文が注文状態「注文受付」で購入者のアカウントに紐づいて記録されている。また、在庫が減ってカートが空になり、購入者と出店者にサイト内通知が届き、「注文を保存しました」画面が表示されている。<br>失敗時は注文が行われず、カートの内容が維持されている。 |
| 基本フロー    | 1. 購入者が共通ヘッダーの「カート」リンクをクリックする。<br>2. システムが「ショッピングカート」画面に、商品ごとの受取店舗・数量・金額と「ご請求内容」を表示する。<br>3. 購入者が「注文内容を確認する」ボタンをクリックする。<br>4. システムが最新のカートを取得し、「お支払い・受け取りの確認」画面に「受け取り店舗とご注文商品」(受取店舗ごと)、「受け取る方」「お支払い方法」「ご請求内容」を表示する。<br>5. 購入者が「お支払い方法」の一覧(店舗でお支払い、クレジットカード、PayPay、楽天ペイ)から1つ選択する。<br>6. 購入者が「注文を確定する」ボタンをクリックする。<br>7. システムがカートの内容・在庫・合計金額を確認して在庫を引き当て、受取店舗ごとに注文を注文状態「注文受付」で保存し、カートを空にする。<br>8. システムがサイト内通知で、購入者に「ご注文を受け付けました」、出店者に「新しい注文が届きました」(EC-S11)を知らせる。<br>9. システムが「注文を保存しました」画面に、注文ごとの注文番号・受取店舗・お支払い方法・ご注文商品・合計を表示する。 |
| 代替フロー    | 2a. 在庫不足、または購入できない商品がある場合<br>2a-1. システムが該当する商品に「在庫不足（現在 N 点）」と表示し、「注文内容を確認する」ボタンを押せない状態にする。<br>2a-2. 購入者がカートを修正する(EC-B09、EC-B10)。<br>2a-3. 基本フロー2へ戻る。<br><br>4a. 最新のカートで在庫不足になっていた場合<br>4a-1. システムが該当する商品に「在庫不足（現在 N 点）」と表示し、「注文を確定する」ボタンを押せない状態にする。<br>4a-2. 購入者が「カートに戻る」ボタンをクリックする。<br>4a-3. 代替フロー2aへ進む。<br><br>7a. 別の操作でカートが更新されていた場合<br>7a-1. システムが注文を保存せず、「別の操作でカートが更新されました。最新の内容を確認してください。」と表示して、最新のカートで確認画面を表示する。<br>7a-2. 基本フロー5へ戻る。<br><br>7b. カートに入れた後に商品の価格が変わっていた場合<br>7b-1. システムが注文を保存せず、「価格が変更されました。合計金額を確認してください。」と表示して、最新の価格で確認画面を表示する。<br>7b-2. 基本フロー5へ戻る。<br><br>7c. 在庫の引き当てに失敗した場合(直前に他の購入者が購入した場合など)<br>7c-1. システムが注文も在庫の減算も保存せず、「在庫が変更されました。数量を変更してください。」と表示する。<br>7c-2. システムが最新のカートと在庫を表示し、「注文を確定する」ボタンを押せない状態にする。<br>7c-3. 購入者が「カートに戻る」ボタンをクリックする。<br>7c-4. 代替フロー2aへ進む。<br><br>7d. 受取店舗が受付を停止していた場合<br>7d-1. システムが注文を保存せず、「(店舗名)は受付を停止しています。」と表示する。<br>7d-2. 購入者が「カートに戻る」ボタンをクリックする。<br>7d-3. 購入者が該当する商品を削除し(EC-B10)、別の受取店舗で追加し直す(EC-B07)。<br>7d-4. 基本フロー2へ戻る。<br><br>7e. 保存に失敗した場合<br>7e-1. システムが注文も在庫の減算も保存せず、「保存処理を完了できませんでした。時間をおいて再試行してください。」と表示する。<br>7e-2. システムがカートの内容を維持したまま、「注文を確定する」ボタンを再びクリックできるようにする。<br>7e-3. ユースケースを終了する。 |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・受取店舗はカートに追加するときに商品ごとに決まる(EC-B07)。購入手続きの中では選ばない。<br>・カートに複数の受取店舗の商品がある場合は、受取店舗ごとに注文を分けて保存し、それぞれの店舗の在庫から引き当てる。完了画面には「受取店舗ごとにN件の注文に分けて保存しました。」と表示する。<br>・受取料金は無料とする。<br>・受取連絡先(お名前・電話番号)はアカウントに登録した内容を使う。確認画面の「受取連絡先を変更」から変更できる。登録は任意で、未登録でも店頭で注文番号を伝えれば受け取れる。<br>・受取希望日時は指定しない。受け取りの準備ができたら利用者通知(EC-B15)で知らせる(EC-S09)。<br>・支払方法はデモで、注文に記録するだけとする。カード番号などは入力せず、実際の請求も発生しない。<br>・「注文を確定する」を続けて押したり、保存失敗の後に再試行したりしても、同じ注文は1回だけ記録する。<br>・保存した注文は注文履歴に表示される。<br>・注文状態は「注文受付」→「受取準備完了」(EC-S09)→「引き渡し完了」(EC-S10)と進む。キャンセル申請が承認されると「キャンセル済み」(EC-S13)になる。<br>・在庫の引き当てでは、同じ在庫を同時に引き当てないようにしてから数量を確認する。不足する場合は在庫不足として扱い、注文も在庫の減算も保存しない。 |
