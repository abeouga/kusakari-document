#### EC-C01 アカウントのメニューを開く(子ユースケース)

| 記述項目     | 記述内容 |
| -------- | ---- |
| ユースケース概要 | 共通ヘッダーの「アカウント」から、サイドバーのメニューで指定した画面(「通知一覧」「パスワード変更」など)を開く。EC-B02、EC-B15、EC-B17、EC-B18、EC-B19、EC-B21から呼び出す。 |
| アクター     | 利用者 |
| 事前条件     | ログイン状態である。<br>共通ヘッダーのある画面(「メイン」画面など)が表示されている。 |
| 事後条件     | 呼び出し元で指定したメニューの画面が表示されている。 |
| 基本フロー    | 1. 利用者が共通ヘッダーの「アカウント」リンクをクリックする。<br>2. システムが「アカウント情報」画面と、サイドバーのメニュー(「マイページ」「アカウント設定」、購入者アカウントの場合は「出店をご検討の方」)を表示する。<br>3. 指定されたメニューが「アカウント情報」以外の場合、利用者がサイドバーの対象のメニュー(「通知一覧」「出店申請」「出店申請状況」「パスワード変更」「退会」など)をクリックする。 |
| 代替フロー    | なし |
| 関連情報     | ・共通代替フロー *b を適用する。<br>・対象の画面に表示する内容は、呼び出し元のユースケースの次のステップで記述する。<br>・「出店をご検討の方」のリンクの表示(「出店申請」／「出店申請状況」)はEC-B18の関連情報を参照。 |
